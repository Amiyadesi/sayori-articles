# 私について（2026年11月）

`Amiya_desi` です。19歳、デジタルメディア技術専攻の学生です

今は主に Godot を使ってゲームを開発していて、これまでに十数回の Game Jam に参加しました。いつか本当の意味で自分だけのメタゲームを作りたいと思っています。ただ、今のところはまだ、腰を据えて長く作り続けたいと思える作品を探している最中です

ゲーム開発のほかにも、AI、Webサイト、サーバー、オープンソースプロジェクト、動画制作、資産運用なんかに手を出してきましたし、今はイラストや編曲も勉強しています

触れてきたものは結構多いんですが、極めたと言えるものはほとんどない気がします（

## Amiya_desi について

`Amiya_desi` という名前には、実はそこまで大した由来はありません

`Amia` は、以前 暁山瑞希（Akiyama Mizuki）が好きでゲームで使っていたネット上の名前です。その後 `desu` という語尾が気に入ったんですが、耳があまり良くなかったせいで、両方とも聞き間違えてしまいました

当時、プログラマーのユーザー名は大小の英字と数字、それに `_` しか使えないと聞いていて、数字を適当に足すのも違うなと思ったので、間にアンダースコアを1つ入れました

今思えば、これってただの snake_case 命名ですね

```
Amia + desu + snake_case = Amiya_desi
```

正しい日本語というわけではありませんが、これだけ長く使っていると、もうこれが自分自身になってしまいました

## これまでの歩み

最初にゲームを作りたいと思ったきっかけは、たぶん『Undertale』です。あの作品に衝撃と感動を受けて、しかもたった一人で作られたらしいと聞いて、「もしかしたら自分にもできるかも……」と思ったのが始まりでした

中学の頃はノートにゲームの設定を書き留めたりもしていましたが、実際に手を動かすまでには至りませんでした

その後、17歳になってようやく Python を学び始め、Godot をインストールしてチュートリアルに沿ってミニゲームを作り、やがて Game Jam に参加するようになりました

ただ、その前に自分にとってかなり大きな影響を与えた出来事が1つあります

16歳のとき、階段を上ったのをきっかけに突然ダイエットを決意しました。食事制限とグラウンドを数周走るところから始めて、少しずつ3キロ、5キロ、ついには10キロまで走れるようになり、半年ほどで25キロ減量しました

やり方はあまり科学的ではなかったし遠回りもしましたが、少なくとも「自分でも一つのことを継続してやり遂げられるんだ」と気づくことができました

のちにゲーム開発に挑戦するときも、このときの経験を引き合いに出して自分を納得させました

その後は、ゲームを作るために AI に触れ、開発リソースを探すためにいろいろなインターネットコミュニティに入り、そうしたコミュニティがきっかけでサーバーやドメイン、個人ブログ、オープンソースプロジェクトにも手を出し、昔の自分なら絶対にやらないと思っていたようなことまでいろいろと学ぶようになりました……

最終的には動画を作ったり、記事を書いたり、リソースをまとめたりまで始めて……

今振り返ると、一つの沼から別の沼へと飛び移り続けていて、前の沼を埋めきる前にまた何か面白そうなものを見つけては飛び込んでいる気がします

でも、そういうところは自分でも結構気に入っています

いろいろなものに触れて、コードや記事、プロジェクト、経験も少しは積み上がってきました。これからもきっと、もっと多くのことを学び続けると思います

学ぶこと自体が楽しいと感じるからです。以前できなかったことができるようになるのは、やっぱり気持ちがいいので

## 創作活動について

今は個人サイト [Amiya's Desk](https://sayori.org/) と、[ブログ](https://blog.sayori.org/) を運営しています

ブログはもうほとんど自分の本拠地みたいになっています

開発ログ、技術チュートリアル、個人的な思考、日常の記録、さらにはふと書きたくなった変な文章まで、なんでも放り込んでいます

ほかにも動画制作に挑戦したり、オープンソースプロジェクトをメンテナンスしたり、たまに見つけた便利なリソースを整理して共有したりしています

自分の手が届く範囲で、誰かの役に少しでも立てたらいいなと思っています

というのも、自分が最初にいろいろなことを学び始めたときも、インターネット上で他の人が無料で公開してくれていたチュートリアルやツール、リソースに助けられて少しずつ歩み出せたからです

自分が学んだことを書き残すことで、後から来る人の助けになるなら、それはとても素敵なことだと思います

ブログを今後どんな方向に育てていくかは、まだ決めていません。そのうち自然と立ち位置が見つかるかもしれませんし、ずっと探し続けることになるかもしれません

### ゲームについて

今でもまだ、自分が納得できて Steam にリリースできるようなゲームは作れていません

十数回の Game Jam に参加してそれなりにプロジェクトも作ってきましたが、最初に自分が作りたいと思ったようなゲームには、まだまだ程遠い気がします

最近も長期プロジェクトを開発しているのですが、なかなか納得のいく答えが出せません

最近はすでに作り込んだ設計をかなり白紙に戻して、ゲームプレイそのものから考え直すことまで検討し始めています

正直、かなりしんどいです。せっかく時間をかけて実装した機能なので

今はもう AI が技術的な作業の多くを手伝ってくれて、コードも速く書けるし機能も次々と実装できます。でも、ゲームが本当に面白いかどうかは、結局のところ自分で体験してみるしかありません

自分はいったいどうやって AI と付き合っていくべきなのかも、改めて考えるようになりました

以前は「とにかく形にできるか」ばかりを気にしていましたが、今は「作ったあとに本当に面白いか」、そして「自分がそれらの技術を本当に理解し、自分のものにできているか」まで考えなければなりません

たぶん、こういうところがゲーム開発の難しさなんだと思います

自分はまだまだ未熟すぎますね（

それでも諦めたくはありません。ゲームを作ることは最初からの願いの一つですし、誰かが入り込み、探索し、体験できる世界を創り出すというのは、今でもとても魅力的なことだと思っています

特にメタゲームは、そもそも自分に衝撃を与えてくれたのが UT（Undertale）だったので

ゲームと現実の境界を打ち破るような作品が大好きですし、いつか自分も、誰かの心を動かすような世界を創り出せたらと願っています

## 生活とこれからについて

これからどうやって安定した収入を得ていくか、まだ考えがまとまっていません

コードは少し書けるし、それなりにいろいろ作ってはきましたが、こうしたスキルや作品を頼りにどうやって長く生活していくかについては、具体的な計画がまだありません

そろそろ安定した収入につながる逃げ道というか、現実的な選択肢も考えておくべきなのかもしれません

ただ、物質的な生活に対する欲求はそこまで高くありません

リスクに備えられるだけの貯蓄があって、日々の生活に困らず、毎日生き残るためだけに神経をすり減らさずに済むこと。そのうえで、自由に学び、創作し、自分の好きなことを研究できれば十分です

我ながら少し甘いというか、理想主義的なところがあるとは思います

現実の生活には結局お金が必要ですし、ゲームだって作りたいと思ったからといって必ずうまくいくわけではないし、ましてやそれで食べていける保証なんてありません

それでも、ずっと学び続け、創作を続け、たまに自分でも心から納得できるものを一つ作れるなら、そんな人生も悪くないなと思います

それと、私は死ぬのが怖いです

死んでしまったら、もう二度と学び続けることも、創作することも、体験することもできなくなるからです

世界にはまだ見たことのないものがたくさんあるし、学んでいない知識も、体験していない作品も山ほどあります。未来にどんな面白い技術が登場するのかと想像するだけでも、すごくワクワクします

残念ながら、人間の時間は限られています

もっとも、今はまだ19歳で経験していないことも多いので、これから先こうした問題に対する考え方も変わっていくのかもしれません

それから、自分は誰かと感情豊かにやり取りしながら、同時に頭の中ではその感情や会話を冷静に分析しているようなところがあるのに気づきました

考えることも自分の思考を分析することも好きですが、結局のところその分析も自分の頭の中の営みにすぎないので、完全な中立なんてまず無理でしょう

だからこそ、私にとってこういう文章を書くことは、ちょうどいい感情の吐き出し口にもなっています

## また今度、自己紹介しよう

7月に書いた自己紹介を読み返してみると、ほんの数ヶ月しか経っていないのに、いろいろなことに対する自分の考え方がすでに変わっていることに気づきました

資産運用に触れたり、さらに多くのことに手を出したりしながら、開発にも長い時間向き合ってきました

今でも さより（Sayori）、暁山瑞希（Akiyama Mizuki）、初音ミク、ニーゴ（25時）、『Undertale』、『DDLC』、そしてこれまで心を動かされたたくさんのバーチャルな世界が大好きです

今でもゲームを作りたいし、あちこちで新しいことを学ぶのも好きです

今の生活には、授業、試験、筋トレ、ゲーム開発、ブログ、動画制作、そしてまだ終わっていないたくさんの計画が詰まっています

将来自分がどんな姿になっているのか、今やっているこれらのことが最後にどんな結果につながるのかは分かりません

数ヶ月後には、自分でも納得のいくゲームを完成させているかもしれません

あるいは、まだ同じプロジェクトに悪戦苦闘していて、さらに新しい沼をいくつか掘っているかもしれません

まあ、そのときになったらまた考えればいいかと思っています

この自己紹介に記録されているのは、**2026年11月の私** です

この先また新しい経験をして、新しい考えが生まれたり、単に前に書いたことが今の自分に合わなくなったと感じたりしたら、また新しく書けばいいだけです

なにせ私は、一度書いてしまったら二度と更新されない README ではありませんから（笑）
