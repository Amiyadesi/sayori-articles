# 開頭
既然要繼續遊戲開發了，在開發前先整理一下手中的戰備吧！把我項目中常用的插件整理出來，放在這裏，[Godot Asset Store](https://store.godotengine.org/)，目前官方最新的插件商店，也可以在這裏找到很多有用的插件，然後再補充一個國內的Godot社區，[開源項目 - GodotHub](https://godothub.com/oss)，這裏面有支持taptap和微信抖音小遊戲的插件

# DialogueManager
[nathanhoad/godot_dialogue_manager: A powerful nonlinear dialogue system for Godot](https://github.com/nathanhoad/godot_dialogue_manager)，我最喜歡用的對話插件，雖然也有其他很優秀的比如[dialogic-godot/dialogic: 💬 Create Dialogs, Visual Novels, RPGs, and manage Characters with Godot to create your Game!](https://github.com/dialogic-godot/dialogic)和國內GodotHub的[Konado](https://godothub.com/oss/konado/zh/2.4/)，不過站長最習慣用的就是這個了，這個能夠更簡單的實現高度自定義化

# SceneManager
[m-canton/godot-scene-manager: Scene Manager Plugin for Godot.](https://github.com/m-canton/godot-scene-manager)，站長用的是這個版本，個人感覺還是挺好用的，我記得github上面還有兩個百star的scene-manager插件，下次看看

# RichText2
[RichTextLabel2 - Godot Asset Library](https://godotengine.org/asset-library/asset/3254)
這個我習慣結合上面的DialogueManager裏的對話使用，能夠做出非常酷炫的各種文字效果，下次補一張gif圖在這裏

# PhantomCamera
幽靈相機除了臃腫（當然可以自己剪切掉一些），剩下的就只有方便好用了，[ramokz/phantom-camera: A Camera addon for Godot 4. Inspired by Cinemachine.](https://github.com/ramokz/phantom-camera)，地址在這裏

# SoundManager
如果你的遊戲沒有到要上FMod這種程度但是又想更好的控制音頻，那麼[nathanhoad/godot_sound_manager: A simple music and sound effect player for the Godot Engine](https://github.com/nathanhoad/godot_sound_manager)會是你很好的選擇

# EnhanceSaveSystem
王婆賣瓜，自賣自誇（霧），這個是站長自己氛圍結合人工編程出來的存檔插件，廣泛運用於自己的項目中，個人感覺還是比較方便的模塊式存檔系統，並且比較方便的插入hook之類的，也支持各種加密存檔[Amiyadesi/enhance_save_system](https://github.com/Amiyadesi/enhance_save_system)

# GodotSteam
[Welcome To GodotSteam - GodotSteam](https://godotsteam.com/)，大名鼎鼎的GodotSteam插件，可以說想上steam的話這個肯定是要研究研究了

# 最後
隨着unity的不斷神祕操作，導致Godot在近幾年變得愈發大衆，我覺得也是值得的；這個開源引擎再當今的AI時代也是更加出彩，因爲它和AI的相性非常的高；總之如果你喜歡開源自由，或者就是想要嘗試一個新的引擎，Godot肯定是一個很好的選擇；而如果你想要用來做一些作品的話，那麼合理的藉助插件的力量也是理所應當的！
