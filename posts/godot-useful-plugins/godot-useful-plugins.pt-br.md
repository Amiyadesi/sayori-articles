# Começo
Já que vou retomar o desenvolvimento de jogos, bora organizar o arsenal antes de começar! Vou deixar aqui os plugins que costumo usar nos meus projetos: a [Godot Asset Store](https://store.godotengine.org/), que é a loja oficial mais recente e onde dá pra achar vários plugins úteis, e também uma comunidade chinesa de Godot, o [开源项目 - GodotHub](https://godothub.com/oss), que tem plugins com suporte a taptap e minijogos do WeChat e Douyin.

# DialogueManager
O [nathanhoad/godot_dialogue_manager: A powerful nonlinear dialogue system for Godot](https://github.com/nathanhoad/godot_dialogue_manager) é o meu plugin de diálogos favorito. Até existem outros bem legais, como o [dialogic-godot/dialogic: 💬 Create Dialogs, Visual Novels, RPGs, and manage Characters with Godot to create your Game!](https://github.com/dialogic-godot/dialogic) e o [Konado](https://godothub.com/oss/konado/zh/2.4/) do GodotHub chinês, mas o que eu mais tenho costume de usar é esse aqui mesmo — ele facilita bastante alcançar um nível alto de personalização.

# SceneManager
O [m-canton/godot-scene-manager: Scene Manager Plugin for Godot.](https://github.com/m-canton/godot-scene-manager) é a versão que eu uso; acho bem prático no geral. Lembro que no GitHub existem mais dois plugins de scene-manager com mais de cem estrelas — qualquer dia desses eu dou uma olhada.

# RichText2
[RichTextLabel2 - Godot Asset Library](https://godotengine.org/asset-library/asset/3254)
Costumo usar junto com as falas do DialogueManager ali de cima pra fazer vários efeitos de texto bem estilosos — depois eu coloco um GIF aqui.

# PhantomCamera
Tirando o fato de ser meio inchado (claro que dá pra podar algumas coisas), o que sobra da câmera fantasma é só praticidade: [ramokz/phantom-camera: A Camera addon for Godot 4. Inspired by Cinemachine.](https://github.com/ramokz/phantom-camera), o link tá aqui.

# SoundManager
Se o seu jogo ainda não precisa meter um FMod da vida, mas você quer um controle melhor do áudio, o [nathanhoad/godot_sound_manager: A simple music and sound effect player for the Godot Engine](https://github.com/nathanhoad/godot_sound_manager) vai ser uma ótima pedida.

# EnhanceSaveSystem
Puxando a sardinha pro meu lado (meio que num modo *vibe coding* misturado com programação manual), esse é o plugin de save que eu mesmo fiz e uso bastante nos meus projetos. Acho um sistema de save modular bem prático, fácil de encaixar hook e afins, e ainda suporta vários tipos de criptografia de save: [Amiyadesi/enhance_save_system](https://github.com/Amiyadesi/enhance_save_system).

# GodotSteam
[Welcome To GodotSteam - GodotSteam](https://godotsteam.com/), o famosíssimo plugin GodotSteam — se a ideia é publicar na Steam, com certeza vale dar uma estudada nele.

# Por fim
Com as várias decisões misteriosas da Unity, o Godot ficou cada vez mais popular nos últimos anos, e eu acho que por merecer; nessa era atual de IA, essa engine open-source brilha ainda mais porque combina muito bem com IA. Resumindo: se você curte liberdade open-source ou só quer testar uma engine nova, o Godot com certeza é uma baita opção; e se quiser fazer alguns projetos com ele, apoiar-se nos plugins certos é mais do que natural!
