# 起因
今天早上做了一个噩梦

梦里的我似乎失去了保护自己所拥有之物的能力：自己的物品被随意拿走，自己的电脑被他人控制，甚至连自己的名义都能够被随意使用

我试图反抗，却始终无法改变什么

最终，我在梦中歇斯底里地呐喊，明明想要撕心裂肺地喊出声音，却发现自己根本发不出声

直到现实中的我终于喊了出来，才从梦里惊醒

醒来后，心脏仍然剧烈跳动。过了一会儿，我才重新意识到自己早已是一名大学生，此刻正躺在寝室的床上

这让我想到了自己现在的处境——于是，我打算写一篇文章，好好回顾一下

# 现状

仔细回想，我发现自从高中以后，自己建立的大部分人际关系，似乎都与我的能力、知识、兴趣或者曾经提供过的资源和帮助有关

- 一位朋友，是因为我曾经安慰过他，才慢慢建立了友谊
- 一位大学里认识的同学，是因为我在军训自我介绍时提到了自己正在开发游戏，才有了之后的交流
- 我建立的社群，其成员大多也是因为看到我制作的项目、编写的教程或分享的内容，才逐渐聚集起来
- 最近也有人邀请我一起创办社团，对方明确表示，正是因为认可我的能力，才想到了与我合作
- 甚至一些曾经比较特殊的人际关系，似乎也离不开我能够提供的交流价值

我很高兴自己的能力能够成为认识别人的契机

而且随着知识和能力的增长，我确实逐渐接触到了更多优秀的人

这似乎形成了一条相当清晰的路径：

**学习知识、积累能力、创造作品、获得认可，然后进入更广阔的社交圈，认识更多优秀的人**

至少对我来说，这条路径是真实而有效的

但也正因为如此，我似乎越来越难想象，如果有一天我不再拥有这些能力和资源，别人还有什么理由愿意接近我

# 我是如何看待别人的？

更有意思的是，我自己似乎也在用相似的标准看待别人

面对技术能力暂时不如我的人，我通常愿意认真交流，如果对方有需要，也会主动讲解自己知道的知识——这时候，我往往更接近一个指导者的角色
![[Pasted image 20261018122805.png]]


面对技术水平与我相近的人，我通常会很有兴趣了解对方研究的领域，询问一些自己不熟悉领域的问题。而在交流之外，我有时也会暗自较劲
![[Pasted image 20261018122918.png]]


至于那些比我优秀得多的同龄人……我常常会产生一种相当复杂的感受

我会由衷地欣赏他们的作品和能力，甚至主动表达自己的憧憬
![[Pasted image 20261018123000.png]]

但与此同时，又会感到某种难以言说的酸涩

明明我们年龄相近，为什么对方已经能够创造出如此优秀的成果？

为什么对方已经拥有圈内的知名度、成熟的技术和令人羡慕的作品，而我似乎还在为一些基本的问题苦恼？

我会因为发现优秀的人而兴奋，也会因为意识到自己与他们之间的差距而沮丧——甚至有时，我会在看到别人的项目后，突然产生一种不服输的冲动，想要证明自己同样能够做到

然后不知不觉地改变了原本的计划，把大量时间投入到一个临时出现的项目中....

我知道这种行为太不合理了——但那种想要追赶别人、证明自己能力的冲动，确实很难忽视

而这也让我意识到：我似乎总是在根据一个人的能力，寻找自己与对方相处的位置

- 我能教给对方什么？
- 我们可以交换什么知识和资源？
- 对方有哪些值得我学习的地方？
- 我又需要付出多少努力，才能达到对方的水平？

我很难完全不考虑这些问题......

# 我为什么如此重视价值？

除了技术能力之外，我还有一个习惯，就是不断收集、整理和分享各种资源。

我编写教程，整理导航网站，分享自己发现的工具、项目和信息

我确实很喜欢帮助别人

看到自己写的教程解决了别人的问题，或者自己分享的资源恰好帮助到了有需要的人，我会感到开心

与此同时，我也希望自己的付出能够获得感谢、认可，甚至因此认识更多人

我希望别人觉得我是一个有用的人——而资源、知识、技术和作品，恰好是一些相对明确的东西。

它们可以被积累，可以被展示，也可以被交换，在某种程度上，这些东西成为了我的筹码

当我想认识一个新朋友时，如果我能够帮助对方解决问题，我就有了一个交流的理由

当我想认识某个技术很厉害的人时，如果我拥有对方可能感兴趣的知识或项目，我似乎也就有了与对方交流的机会

相比之下，单纯地走过去说一句「我想和你成为朋友」，反而让我感到有些不知所措——我不知道对方为什么应该接受，我也不知道自己凭什么获得这样的关系

毕竟，别人似乎并不缺少朋友，更不缺少认识新人的机会——那么，我有什么特别之处呢？

这时候，能力和资源便成了一个相对容易理解的答案

至少我能够明确地告诉自己，我可以为对方提供些什么

**相比那些无法确定的感情与好意，这些能够握在手里的东西，确实更容易让我感到安心**

# 如果有一天，我不再有价值呢？

最近，我突然开始认真考虑这个问题

如果我有一天技术力下降，不再编写教程，不再分享资源，甚至没有能力继续制作自己的游戏……

现在认识我的那些人，还会愿意和我交流吗？

那些因为欣赏我的能力而认识我的朋友，还会把我当成朋友吗？

如果有一天，我不再能够给别人提供帮助，反而需要别人照顾，我又会处在怎样的位置？

我发现自己很难回答

而且，我也开始意识到，别人最初因为我的能力而认识我，并不意味着之后的关系一定只能靠能力维持

但问题是，我不知道这些关系究竟已经发展到了什么程度

也不知道如果失去了最初吸引别人的那些东西，它们会发生怎样的变化

我很少真正尝试过这种情况

# 一些暂时没有答案的困惑

写到这里，我发现自己似乎陷入了某种矛盾

一方面，我确实相信能力、资源和利益在人际关系中的重要性

我的许多经历都支持这种判断

我可以说，正是因为不断提升自己的能力，我才拥有了今天的许多机会，也认识了现在这些优秀的人

所以，我很难轻易否定这套认知

另一方面，我又确实希望人与人之间能够存在一些不完全依赖能力和利益的关系

我希望别人能够认可我的作品，但也希望他们能够接受那个暂时没有好作品的我

我希望成为一个能够帮助别人的人，但也希望自己在需要帮助的时候，不必先思考能够拿出什么作为交换

我希望自己变得足够优秀，可以与那些令我憧憬的同龄人并肩交流

但我又担心，即使真的走到了那一步，我仍然会继续遇见更加优秀的人，然后重新开始怀疑自己的价值

还有一个更加令我困惑的问题：

**我究竟是在追求自己真正热爱的能力与创造，还是已经习惯了依靠不断提升能力，来获得被认可的安全感？**

我想，这两种动机大概都有

我很喜欢创作，也很喜欢探索知识，这些兴趣并不虚假

但我也确实渴望成为一个被认可、被需要、被认真对待的人

直到现在，我仍然不知道该如何把它们完全区分开来——或许也没有必要强行区分

总之，这就是我目前的一些想法

我尚且无法想象，一个没有什么能力、无法提供什么价值的自己，究竟能够因为什么被别人喜欢

而对于自己已经建立的那些关系，我也还没有足够的答案

先记录到这里吧
