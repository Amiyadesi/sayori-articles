# 起因
今天早上做了一個噩夢

夢裡的我似乎失去了保護自己所擁有之物的能力：自己的物品被隨意拿走，自己的電腦被他人控制，甚至連自己的名義都能夠被隨意使用

我試圖反抗，卻始終無法改變什麼

最終，我在夢中歇斯底里地吶喊，明明想要撕心裂肺地喊出聲音，卻發現自己根本發不出聲

直到現實中的我終於喊了出來，才從夢裡驚醒

醒來後，心臟仍然劇烈跳動。過了一會兒，我才重新意識到自己早已是一名大學生，此刻正躺在寢室的床上

這讓我想到了自己現在的處境——於是，我打算寫一篇文章，好好回顧一下

# 現狀

仔細回想，我發現自從高中以後，自己建立的大部分人際關係，似乎都與我的能力、知識、興趣或者曾經提供過的資源和幫助有關

- 一位朋友，是因為我曾經安慰過他，才慢慢建立了友誼
- 一位大學裡認識的同學，是因為我在軍訓自我介紹時提到了自己正在開發遊戲，才有了之後的交流
- 我建立的社群，其成員大多也是因為看到我製作的項目、編寫的教程或分享的內容，才逐漸聚集起來
- 最近也有人邀請我一起創辦社團，對方明確表示，正是因為認可我的能力，才想到了與我合作
- 甚至一些曾經比較特殊的人際關係，似乎也離不開我能夠提供的交流價值

我很高興自己的能力能夠成為認識別人的契機

而且隨著知識和能力的增長，我確實逐漸接觸到了更多優秀的人

這似乎形成了一條相當清晰的路徑：

**學習知識、積累能力、創造作品、獲得認可，然後進入更廣闊的社交圈，認識更多優秀的人**

至少對我來說，這條路徑是真實而有效的

但也正因為如此，我似乎越來越難想像，如果有一天我不再擁有這些能力和資源，別人還有什麼理由願意接近我

# 我是如何看待別人的？

更有意思的是，我自己似乎也在用相似的標準看待別人

面對技術能力暫時不如我的人，我通常願意認真交流，如果對方有需要，也會主動講解自己知道的知識——這時候，我往往更接近一個指導者的角色
![[Pasted image 20261018122805.png]]


面對技術水平與我相近的人，我通常會很有興趣瞭解對方研究的領域，詢問一些自己不熟悉領域的問題。而在交流之外，我有時也會暗自較勁
![[Pasted image 20261018122918.png]]


至於那些比我優秀得多的同齡人……我常常會產生一種相當複雜的感受

我會由衷地欣賞他們的作品和能力，甚至主動表達自己的憧憬
![[Pasted image 20261018123000.png]]

但與此同時，又會感到某種難以言說的酸澀

明明我們年齡相近，為什麼對方已經能夠創造出如此優秀的成果？

為什麼對方已經擁有圈內的知名度、成熟的技術和令人羨慕的作品，而我似乎還在為一些基本的問題苦惱？

我會因為發現優秀的人而興奮，也會因為意識到自己與他們之間的差距而沮喪——甚至有時，我會在看到別人的項目後，突然產生一種不服輸的衝動，想要證明自己同樣能夠做到

然後不知不覺地改變了原本的計劃，把大量時間投入到一個臨時出現的項目中....

我知道這種行為太不合理了——但那種想要追趕別人、證明自己能力的衝動，確實很難忽視

而這也讓我意識到：我似乎總是在根據一個人的能力，尋找自己與對方相處的位置

- 我能教給對方什麼？
- 我們可以交換什麼知識和資源？
- 對方有哪些值得我學習的地方？
- 我又需要付出多少努力，才能達到對方的水平？

我很難完全不考慮這些問題......

# 我為什麼如此重視價值？

除了技術能力之外，我還有一個習慣，就是不斷收集、整理和分享各種資源。

我編寫教程，整理導航網站，分享自己發現的工具、項目和信息

我確實很喜歡幫助別人

看到自己寫的教程解決了別人的問題，或者自己分享的資源恰好幫助到了有需要的人，我會感到開心

與此同時，我也希望自己的付出能夠獲得感謝、認可，甚至因此認識更多人

我希望別人覺得我是一個有用的人——而資源、知識、技術和作品，恰好是一些相對明確的東西。

它們可以被積累，可以被展示，也可以被交換，在某種程度上，這些東西成為了我的籌碼

當我想認識一個新朋友時，如果我能夠幫助對方解決問題，我就有了一個交流的理由

當我想認識某個技術很厲害的人時，如果我擁有對方可能感興趣的知識或項目，我似乎也就有了與對方交流的機會

相比之下，單純地走過去說一句「我想和你成為朋友」，反而讓我感到有些不知所措——我不知道對方為什麼應該接受，我也不知道自己憑什麼獲得這樣的關係

畢竟，別人似乎並不缺少朋友，更不缺少認識新人的機會——那麼，我有什麼特別之處呢？

這時候，能力和資源便成了一個相對容易理解的答案

至少我能夠明確地告訴自己，我可以為對方提供些什麼

**相比那些無法確定的感情與好意，這些能夠握在手裡的東西，確實更容易讓我感到安心**

# 如果有一天，我不再有價值呢？

最近，我突然開始認真考慮這個問題

如果我有一天技術力下降，不再編寫教程，不再分享資源，甚至沒有能力繼續製作自己的遊戲……

現在認識我的那些人，還會願意和我交流嗎？

那些因為欣賞我的能力而認識我的朋友，還會把我當成朋友嗎？

如果有一天，我不再能夠給別人提供幫助，反而需要別人照顧，我又會處在怎樣的位置？

我發現自己很難回答

而且，我也開始意識到，別人最初因為我的能力而認識我，並不意味著之後的關係一定只能靠能力維持

但問題是，我不知道這些關係究竟已經發展到了什麼程度

也不知道如果失去了最初吸引別人的那些東西，它們會發生怎樣的變化

我很少真正嘗試過這種情況

# 一些暫時沒有答案的困惑

寫到這裡，我發現自己似乎陷入了某種矛盾

一方面，我確實相信能力、資源和利益在人際關係中的重要性

我的許多經歷都支持這種判斷

我可以說，正是因為不斷提升自己的能力，我才擁有了今天的許多機會，也認識了現在這些優秀的人

所以，我很難輕易否定這套認知

另一方面，我又確實希望人與人之間能夠存在一些不完全依賴能力和利益的關係

我希望別人能夠認可我的作品，但也希望他們能夠接受那個暫時沒有好作品的我

我希望成為一個能夠幫助別人的人，但也希望自己在需要幫助的時候，不必先思考能夠拿出什麼作為交換

我希望自己變得足夠優秀，可以與那些令我憧憬的同齡人並肩交流

但我又擔心，即使真的走到了那一步，我仍然會繼續遇見更加優秀的人，然後重新開始懷疑自己的價值

還有一個更加令我困惑的問題：

**我究竟是在追求自己真正熱愛的能力與創造，還是已經習慣了依靠不斷提升能力，來獲得被認可的安全感？**

我想，這兩種動機大概都有

我很喜歡創作，也很喜歡探索知識，這些興趣並不虛假

但我也確實渴望成為一個被認可、被需要、被認真對待的人

直到現在，我仍然不知道該如何把它們完全區分開來——或許也沒有必要強行區分

總之，這就是我目前的一些想法

我尚且無法想像，一個沒有什麼能力、無法提供什麼價值的自己，究竟能夠因為什麼被別人喜歡

而對於自己已經建立的那些關係，我也還沒有足夠的答案

先記錄到這裡吧
