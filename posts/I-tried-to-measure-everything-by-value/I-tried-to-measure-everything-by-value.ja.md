# きっかけ
今朝、悪夢を見た

夢の中の自分は、持っているものを守る力を失っているようだった。自分の物は勝手に持ち去られ、パソコンは他人に操作され、自分の名義までも勝手に使われてしまう

抵抗しようとしても、何も変えられない

やがて夢の中でヒステリックに叫び声をあげようとする。張り裂けそうなほど声を出したいのに、まったく声が出ない

現実に自分が声を出せたところで、ようやく夢から飛び起きた

目が覚めても心臓はまだ激しく脈打っていた。しばらくして、自分がすでに大学生で、いま寮のベッドに横たわっているのだとやっと気づいた

そこから今の自分の境遇を思い浮かべ――ふりかえりを兼ねて、ひとつの記事を書いてみることにした

# 現状

よく思い返してみると、高校以降に築いた人間関係の多くが、自分の能力や知識、興味、あるいはこれまでに差し出したリソースや助けと結びついている気がする

- かつて慰めたことをきっかけに、少しずつ友情が育っていった友人がいる
- 大学で知り合った同級生とは、軍訓の自己紹介でゲームを作っていると話したことからやり取りが始まった
- 自分が作ったコミュニティのメンバーも、制作したプロジェクトや書いたチュートリアル、共有した発信を見て集まってきた人が大半だ
- 最近もサークルを一緒に立ち上げようと誘われたが、相手ははっきり自分の能力を認めたうえで声をかけてくれたと言っていた
- 少し特殊な関係性だったものも、自分が提供できるやり取りの価値と切り離せなかったように思う

自分の能力が人と知り合うきっかけになるのは、素直にうれしい

それに知識や能力が伸びるにつれて、より優秀な人たちと関わる機会も着実に増えてきた

そこにはかなりはっきりしたルートがあるように見える

**知識を学び、能力を蓄え、作品を生み出し、認められて、より広い交友圏に入り、優秀な人たちと知り合う**

少なくとも自分にとっては、この道筋はリアルで確かなものだった

けれど、だからこそ想像しづらくなっている。もしある日、こうした能力やリソースを失ったら、人に近づいてもらう理由がほかにあるのだろうか、と

# 自分は他人をどう見ているのか？

さらに面白いのは、自分自身も似たような物差しで他人を見ているらしいことだ

技術力がまだ自分より下の相手に対しては、たいてい落ち着いて話せるし、求められれば知っている知識を自分から解説することもある――このとき自分は、どちらかといえば指導役に近い
![[Pasted image 20261018122805.png]]


技術水準が自分と近い相手には、相手が研究している分野を知りたくなり、自分の不慣れな領域について質問することが多い。やり取りの外側で、ひそかに張り合ってしまうこともある
![[Pasted image 20261018122918.png]]


そして、自分よりずっと優秀な同年代に対しては……かなり複雑な感情を抱きがちだ

相手の作品や能力を心からすごいと思うし、自分から憧れを口にすることもある
![[Pasted image 20261018123000.png]]

けれど同時に、言葉にしづらいほろ苦さもある

同じくらいの年なのに、なぜ相手はもうあんなに立派な成果を出せるのだろう？

なぜ相手は界隈での知名度や熟練の技術、うらやましいほどの作品を持っているのに、自分はまだ基本的なことでつまずいて悩んでいるのだろう？

すごい人を見つけて高揚するし、自分との差を自覚して落ち込む――さらには、他人のプロジェクトを見た拍子に、自分にもできると証明したいという負けず嫌いの衝動が突然わいてくることもある

そうして気づかないうちに当初の予定を変え、突発的に始めたプロジェクトに膨大な時間を注ぎ込んでしまう……

こんな動き方が無茶なのはわかっている――それでも、人に追いつきたい、自分の能力を証明したいという衝動は、なかなか無視できない

このことから見えてきたのは、自分がいつも相手の能力をもとに、その人とどんな位置で関わるかを探っているということだ

- 自分は相手に何を教えられるか？
- どんな知識やリソースを交換できるか？
- 相手のどんなところから学べるか？
- 相手のレベルに届くには、どれだけの努力が必要か？

こうしたことをまったく考えずにいるのは、自分にはかなり難しい……

# なぜここまで価値を重視するのか？

技術力に加えて、自分にはさまざまなリソースを集め、整理し、共有する習慣がある

チュートリアルを書き、ナビゲーションサイトを整え、見つけたツールやプロジェクトや情報をシェアする

人を助けること自体は、本当に好きだ

書いたチュートリアルで誰かの困りごとが解けたり、共有したリソースがちょうど必要な人の役に立ったりすると、うれしい気持ちになる

それと同時に、自分の手間や労力が感謝や評価につながり、さらには人とのつながりにもなってほしいという気持ちもある

自分が「役に立つ人間だ」と思われたい――そしてリソースや知識、技術や作品というのは、比較的わかりやすい手札だ

積み上げられるし、見せられるし、交換もできる。ある意味で、それらが自分の切り札になっている

新しい友達と知り合いたいとき、相手の課題を解決できれば話す口実ができる

技術力の高い人と知り合いたいとき、相手が興味を持ちそうな知識やプロジェクトを持っていれば、話しかけるきっかけが生まれる

それと比べると、ただ近づいて「友達になってください」と言うのは、むしろどうしていいかわからなくなる――なぜ相手がそれを受け入れるべきなのか、自分にそんな関係を得る資格があるのか、見当がつかないからだ

そもそも他人には友達がいくらでもいるし、新しい人と出会う機会にも困っていないはずだ――だとしたら、自分にどんな特別さがあるのだろう？

そんなとき、能力やリソースは納得しやすい答えになる

少なくとも、相手に何を出せるかを自分自身にはっきり言えるからだ

**確かでない感情や好意と比べると、手元に握っておけるもののほうが、やはり安心しやすい**

# もしある日、自分に価値がなくなったら？

最近になって、このことを急にまじめに考えるようになった

もしある日、技術力が落ち、チュートリアルも書かなくなり、リソースも共有しなくなり、自分のゲームを作り続ける力すらなくなったら……

いま自分を知っている人たちは、それでも話してくれるだろうか？

自分の能力に惹かれて知り合った友人たちは、それでも自分を友人として扱ってくれるだろうか？

もしある日、人に手を差し伸べる側ではなくなり、逆に世話を焼かれる側になったら、自分はどんな立ち位置になるのだろう？

すぐに答えを出すのは難しい

それに、最初は能力をきっかけに知り合ったとしても、その後の関係まで能力だけで保たれるわけではない、ということも少しずつわかってきた

ただ問題は、それらの関係がどこまで深まっているのか、自分にはわからないことだ

最初に人を引きつけていたものを失ったとき、関係がどう変わるのかもわからない

そういう場面を、これまでほとんど本気で経験したことがないからだ

# まだ答えの出ないモヤモヤ

ここまで書いてみて、自分がちょっとした矛盾のなかにいることに気づく

一方で、人間関係における能力やリソース、利得の重みは、やはり信じている

これまでの経験の多くが、その見方を裏づけているからだ

能力を磨き続けてきたからこそ、今の多くのチャンスや、いま出会えている優秀な人たちとつながれたと言える

だからこそ、この認識をかんたんに否定することはできない

もう一方で、能力や利得だけに頼らない関係が人と人のあいだにあってほしいとも、確かに願っている

自分の作品を認めてほしいけれど、まだいい作品がない状態の自分も受け入れてほしい

人を助けられる存在になりたいけれど、自分が助けを必要とするときに、見返りとして何を出せるかを先に考えなくてもすむようにしたい

憧れの同年代と肩を並べて話せるくらい優秀になりたい

けれど同時に、たとえそこにたどり着いたとしても、またさらに優秀な人と出会い、自分の価値を疑い直すのではないかという怖さもある

そして、もうひとつ悩ましい問いがある

**自分が追い求めているのは、心から好きな能力やものづくりなのか、それとも能力を高め続けることで得られる「認められる安心感」に慣れきってしまっただけなのか？**

たぶん、その両方の動機があるのだろう

ものづくりも好きだし、知識を探るのも好きで、その興味自体は嘘ではない

けれど同時に、認められ、必要とされ、ちゃんと向き合ってもらえる存在になりたいという渇望も確かにある

いまのところ、その二つをきれいには切り分けられないし――無理に切り分ける必要もないのかもしれない

いずれにせよ、これが今の自分の考えだ

大した能力もなく、何の価値も差し出せない自分が、いったい何によって人に好かれ得るのか、まだ想像がつかない

そして、すでに築いてきた関係についても、まだ十分な答えは持っていない

ひとまず、ここまでに記録しておこう
