最近、Riseupのセキュリティリソースの中でかなり長いリストを見つけた

[ラジカル・サーバー - riseup.net](https://riseup.net/zh/security/resources/radical-servers)

リストに載っているプロジェクトの多くは、非営利団体、自律的な技術グループ、協同組合、あるいはボランティアのコレクティブによって運営されていて、社会運動や草の根組織、非営利プロジェクト、そしてプライバシーを重視する人々にネットワークインフラを提供している

メールやメーリングリスト、Webホスティングを提供している団体もあれば、VPN、XMPP、Matrix、Etherpad、ファイル共有、コードホスティング、あるいはコミュニティネットワークを維持しているところもある

このリストを見て、インターネットの片隅にあるもう一つの公共サービスの姿を初めて割と全体的に見渡せた気がする

## なぜRiseupはこれらを「ラジカル・サーバー」と呼ぶのか

Riseupによるこのリストの説明はとてもストレートだ

反資本主義、反ヒエラルキー、自律、フェミニズム、あるいはその他のラディカルな技術プロジェクトを収録している、と書かれている

草の根の活動家に無料や相互扶助のサービスを提供するグループもあれば、プライバシーや自由ソフトウェア、分散化により重点を置くグループもある

共通点は技術スタックではなく、金儲けを第一の目的にしていないことだ

またRiseupは、このリストが公式のお墨付きを意味するわけではないことも明記している

各団体が所在する地域や法的環境、ログポリシー、登録方法、稼働状況はそれぞれ異なるため、利用前には各自で利用規約やプライバシーポリシーを読む必要がある

## このリストには何が載っているのか

ページは World Wide、South America、Europe、North America、そして In memoriam に分類されている

世界規模のプロジェクトには、hackerspaces.org、HackThisSite、Indymedia、Take Back The Tech などがある

それぞれコミュニティスペース、サイバーセキュリティ学習、インディペンデントメディア、女性に対するデジタル暴力への反対といった領域に寄っている

南米のセクションには Codigosur と Colnodo が挙げられている

これらの団体は社会運動や非営利グループ向けに、ホスティング、メール、メーリングリスト、ストリーミング、共同編集、技術サポートなどを提供している

ヨーロッパのセクションは数が一番多い

ここには Disroot、Framasoft、GreenNet、NoLog.cz、systemli、Syster Server、Koumbit など、方向性の異なるさまざまな団体が並んでいる

提供しているサービスの幅もかなり広い

- メールとメーリングリスト
- Webサイト、ブログ、Wiki、フォーラムのホスティング
- XMPP、Matrix、Mumble、ビデオ会議
- Etherpad、CryptPad などのコラボレーションツール
- Git、プロジェクト管理、ファイル共有
- VPN、DNS、コミュニティネットワーク、仮想サーバー
- 社会運動やフェミニズム団体、非営利プロジェクト向けの技術サポート

北米のセクションには Riseup 自身のほか、Koumbit や Anarchy Planet などのプロジェクトも収録されている

ページの最後には In memoriam というグループも残されている

すでに停止したかメンテナンスモードのみになったプロジェクトだが、歴史から単純に消し去られてはいない

このセクションはとても大切だ。公共サービスには終わりが来るもので、メンテナーの離脱や資金の変化、法的リスクによって、かつて頼りになった入り口が消えてしまうこともある。これこそが公益事業が背負わざるを得ないリスクなんだなと思う

## 個別に知っておく価値のあるいくつかのプロジェクト

### Disroot

[Disroot](https://disroot.org/) はアムステルダムを拠点とする非営利財団で、ボランティアによって運営され、コミュニティの支援に支えられている

メール、ファイル、チャット、共同編集ドキュメント、暗号化ペーストビン、連合型ネットワークツールを一つのオープンなサービス群にまとめている

以前、単独で記事を書いたこともある：[[disroot-open-services-note|Disroot：インターネットの古き良き理想を思わせるオープンソースサービス集]]

### Framasoft

[Framasoft](https://framasoft.org/) はフランス発の団体で、自由ソフトウェアやオープン教育、分散型インターネットの普及に長年取り組んでいる

中央集権型プラットフォームの代替となる公共ツールを数多く作ってきたほか、ソフトウェアやドキュメント、教育リソースのメンテナンスも続けている

### systemli と NoLog.cz

[systemli](https://www.systemli.org/) は政治活動家や社会運動向けに、プライバシーを重視した通信サービスを提供している

[NoLog.cz](https://nolog.cz/) はチェコの活動家技術コレクティブで、Matrix、ファイル共有、共同編集ドキュメント、動画、その他の自由ソフトウェアサービスを提供している

この手の組織は通常、誰にでも無制限のリソースを提供すると約束したりはせず、支援対象や申請方法、利用の境界線をとても明確に書いている

### GreenNet と Koumbit

[GreenNet](https://www.greennet.org.uk/) は平和、環境、人権団体向けにインターネットサービスやWebサイト、ホスティングのサポートを提供している

[Koumbit](https://www.koumbit.org/) はモントリオールの非営利団体で、コミュニティグループや社会正義プロジェクトに自由ソフトウェアの技術サービスを提供しており、連帯ホスティングプログラムも持っている

これらを見て改めて気づかされるのは、公益的な技術サービスが必ずしもすべて無料とは限らないということだ

適正な料金設定、内部補助、寄付、ボランティア労働のどれもが、サービスを維持するための手段になり得る

## このリストを使う前に確認しておくべき3つのこと

2026年7月19日に実際にこのリストへアクセスしてみたところ、ディレクトリには依然として World Wide、South America、Europe、North America、In memoriam が含まれていた

ただ、これはRiseupのディレクトリページが現在アクセス可能であることを証明するだけで、リストにあるすべての団体のサービスが今も開放されている保証にはならない

第一に、プロジェクトが現在も稼働しているか確認すること

このページには過去の項目も残っているため、一部のサービス説明や利用枠はすでに古くなっている可能性がある

第二に、誰が申請対象になるのか確認すること

一部のサービスは特定の地域、社会運動、非営利団体、あるいは招待されたユーザーのみを対象としており、無料と書いてあるからといって誰でも登録できるわけではない

第三に、法律とデータの境界線を確認すること

プライバシーに配慮しているからといって、絶対的な匿名性が保証されるわけではないし、バックアップやアカウント復旧、現地の法律を無視していいことにもならない

重要なデータはやはり自分で暗号化バックアップを取っておくべきで、特定の単一組織を「永遠に閉鎖されないインフラ」だと思い込んではいけない

## このリストから何を学べるか

自分は sayori.org を公益団体として登記しているわけではないし、こうした団体のような資金やメンバー、長期的な運営経験もない

だから、自分の小さなサービスを Riseup や Disroot と同じスケールで並べて比べるつもりはない

学べるのは、サービス対象をどう説明し、境界線をどう公開し、寄付に頼りながら悪用を制限し、そしてサービスが停止する可能性をどう正直に認めるかという姿勢だ

入り口ばかりをどんどん増やすよりも、自分が本当にメンテナンスし続けられる少数のサービスを残していきたい

## sayori.org で現在公開しているサービス

全体のステータスは [sayori.org 公共サービス案内](https://sayori.org/zh/services/) にまとめている

### GeoScore Web監査

[GeoScore](https://geo.sayori.org/) は登録不要で使える SEO と GEO のファクト監査ツールだ

公開Webページを対象に、サイトプロファイル、サンプリングページ、検証エビデンス、優先修正項目、Markdownレポートを整理してくれる

対象サイトを自動で書き換えることはないし、予測結果を「実際のAI引用率」のように見せかけることもしない

### GeoScore 公開監査 API

現在、公開 API サービスも一つ提供できている

入り口は [geo-api.sayori.org](https://geo-api.sayori.org/) だ

GeoScore の安定した公開インターフェースを提供しており、公開ドメインの監査実行、デプロイメタデータの読み取り、PageSpeed エビデンスの取得、そして既存の監査結果をもとにした Evidence Map や FixPack の生成ができる

API のリクエスト構造、レスポンス、エラーコードは [OpenAPI ドキュメント](https://geo-api.sayori.org/openapi.json) に記載しており、中国語の利用ガイドは [GeoScore Docs](https://geo.sayori.org/docs) にある

最小構成のサイト監査リクエストは以下の通り

```bash
curl "https://geo-api.sayori.org/api/audit/example.com"
```

このエンドポイントは Server-Sent Events ストリームを返し、サイトモードでは最大5つの HTML ページをサンプリングする

実行制限は [`/api/meta`](https://geo-api.sayori.org/api/meta) のオンライン結果に準拠する

受け付けるのはパブリックな hostname のみで、localhost、プライベートIPアドレス、IP literal、あるいは任意のプロキシリクエストには対応していない

公開 API もベストエフォート方式で運用しており、クォータ切れ、悪用、あるいはアップストリームの障害が発生した際にはレート制限や一時停止を行う

### Amiyaのホワイトボード

[Amiyaのホワイトボード](https://board.sayori.org/) は登録不要の軽量なブラウザホワイトボードだ

ちょっとした図を描いたり、ラフスケッチを整理したり、ページ構成を説明したり、誰かにそのまま開ける共同作業用のキャンバスを送ったりするのに向いている。一時的にフローチャートを描いたり、自分の思考を整理して見せたりするのには結構便利だ

ホワイトボードもベストエフォートで維持しているため、重要な内容の長期保存は保証していない。残しておきたい結果は利用者自身でエクスポートしてほしい

### ブログ、RSS、フィードバック

[ブログ](https://blog.sayori.org/) と [RSS](https://blog.sayori.org/rss.xml) では、記事やチュートリアル、プロジェクトの記録を公開している

掲示板とメールでは、サービスの不具合報告や改善提案を受け付けている

## Search Gateway の境界線

[Search Gateway](https://github.com/Amiyadesi/search-gateway) は引き続きオープンソースであり、セルフホストが可能で、互換 API や MCP での接続方法も提供している

ただし `search.sayori.org` は管理人用の内部インスタンスであり、認証が必要で、匿名呼び出しや共有トークン、公開検索枠は提供していない

公開の GeoScore API と内部の Search Gateway は分けて説明する必要がある

前者は誰でも呼び出せる公共サービスであり、後者はセルフホスト可能なソフトウェア兼プライベートインフラだ

## 次のステップ

このラジカル・サーバーのリストはこれからも整理を続けて、現在も稼働していて、中国語ユーザーにも理解しやすく、サービスの境界線がはっきり書かれている団体を優先的に確認していきたい

自分のサイトについては、まず GeoScore のWeb版、公開監査 API、ブログ、RSS を安定して維持することを優先する

もし今後、サイトの健康診断の相互扶助や静的サイトの公開サポート、あるいは少量の検索エビデンス枠などを追加するとしても、まずは招待制・上限付き・手動対応という形で始めるつもりだ

できる限り自分の力を尽くして、誰かの役に立てればと思う
