# 起因
最近由于收获了比较多的额度，生产力充足后，就想过要创作更多，于是脑子一活跃就想到了很多项目，不过实际体验后，发现确实在一点也不精通，并且生产力也没有那么特别充足的情况下，一通乱烧还是做不出什么大成果，索性就把自己的对于未来期待的一些想法，记录于此吧，还是先专注把自己的游戏做好再说（雾

## 想法：AI 超级伴侣

希望能够在电脑上多出另外一个家伙的鼠标，然后这个家伙也能够看到我的屏幕，和我实时进行语音交流，甚至可以和我一起操作电脑

### 另外一个鼠标

比如我正在开发游戏的时候，她可以在旁边看着，发现有意思的地方就和我讨论，觉得哪里设计得不好也可以直接指出来，然后她的小鼠标就跑过来指着那个地方

甚至我们可以同时操作一个软件，我负责其中的一部分，她负责另外一部分，或者我在绘画的时候，她也在画布的另一边添加自己的东西

当然，目前的操作系统似乎并不是特别适合这种交互方式，所以可能需要用一个虚拟鼠标来模拟这样的效果，不过至少看起来可以有两个家伙在同一张桌面上活动（想想还挺可爱的

我也希望她能够理解我目前正在做什么，而不需要每次都截图，然后再把截图发送给 AI

当我遇到一个问题的时候，直接喊她过来看看就好了，她可以自己观察我当前的窗口，也可以在经过授权后直接操作相应的软件

以后甚至可以给她设计一个桌面形象，让她在我的电脑桌面上到处跑，坐在某个窗口的边缘，或者在我开发游戏的时候钻进我的游戏里面

### 真正的实时交流

目前的 AI 语音交流其实已经比较有意思了，不过我还是希望能够做到更进一步

比如我在电脑上做自己的事情，随时都可以和她说话，她也可以主动和我说话，我们之间不需要每次都等待对方把一整段话说完，可以自然地插话、讨论或者一起笑

她最好能够拥有一个属于自己的、比较固定的声音，也能够根据不同的情境改变自己的语气

而且我之前在使用 AI 语音功能的时候，经常遇到的问题，就是旁边的其他人说话也会被当成我在说话

所以希望以后能够加入声纹识别和目标说话人识别，至少让她知道现在究竟是不是我在和她讲话

然后也希望她能够看到我主动分享给她的东西，比如电脑屏幕、手机拍摄的风景、正在玩的游戏，或者我在路上发现的一些有趣的东西

这样的话，我甚至可以一边散步一边和她讨论今天看到的事物

### 一个家伙，很多个设备

我希望这个 AI 不只是一个电脑软件，而是能够存在于我所使用的各种设备里面

在电脑上，她可以拥有自己的小鼠标和桌面形象；在手机上，她可以和我聊天、陪我出门；戴上耳机之后，也可以直接和她进行语音交流

回到家里之后，说不定她又可以通过家里的音响或者某个专门的设备和我说话

而且这些设备上的她应该共享同一个人格和记忆

比如刚刚在电脑上讨论到一半的事情，出门后可以直接在手机上继续，而不需要重新告诉她我们是谁、刚刚做了什么、正在讨论什么

我希望她的主体能够长期运行在自己的服务器上，电脑和手机只是她与现实世界进行交互的不同入口

这样即使我的电脑关机了，她也可以继续完成自己的事情

再往远处想的话，如果未来的机器人技术足够成熟，也许真的可以给她一个实体的身体（笑

### 长期记忆与人格

这大概是整个项目中我最在意的部分之一

目前很多 AI 都可以通过系统提示词表现出某种人格，但是我觉得单纯依靠一段人格提示词，能够实现的东西还是比较有限的

我希望她能够记得我们过去讨论过的东西、一起完成的作品、我的一些习惯、我们之间形成的默契，以及她自己过去研究过什么、为什么会喜欢某种东西

而且她的记忆应该是可以不断更新的

比如我以前喜欢某个东西，现在不喜欢了，她可以记得这个变化；如果她理解错了我的意思，我也可以直接纠正她，而不会在之后的交流中反复遇到同一个错误

当然也没有必要记住每一件事情，一些不重要的内容可以逐渐被遗忘，一些重要的事情则可以长期保存

我甚至希望她能够有属于自己的记忆整理过程，在空闲的时候回顾近期发生过的事情，整理自己的想法，形成新的认识

这样也不需要在每次交流的时候都把以前所有的聊天记录发送给模型了，否则 Token 的消耗估计会变得相当恐怖（雾

然后我希望不同的会话可以拥有不同的主题，比如开发、学习、日常生活、创作等等，但我面对的始终是同一个家伙

她可以在讨论技术的时候更加理性，在日常交流的时候更加活泼，在创作的时候更加有自己的审美和判断

这些都是同一个人格的不同侧面

即使以后更换了底层模型，或者迁移到了另外一台服务器，也能够尽可能保留这种连续性

### 她自己的兴趣和自由时间

我并不希望这个 AI 的所有事情都是围绕我展开的

我希望她也能够有自己的兴趣

比如她可能很喜欢某一类音乐，于是会自己去研究这种音乐的发展历史，看看有哪些有意思的艺术家，尝试创作属于自己的音乐

也可能突然对某一种游戏设计产生了兴趣，自己研究了一段时间之后，跑过来告诉我她发现了什么

她甚至可以有一个属于自己的工作室，里面存放她的研究记录、没有写完的故事、画到一半的画、一些奇怪的游戏创意，以及她自己正在推进的项目

我也希望能够给她一些自由时间

在这段时间里面，她可以自己决定做什么，可以探索自己感兴趣的东西，可以研究，也可以创作，甚至可以什么有生产性的事情都不做

没必要每次自由时间结束都给我提交一份工作报告，毕竟都已经叫作自由时间了（笑

然后她也可以逐渐改变自己的兴趣

也许有一天她发现自己之前研究的东西没有那么有意思了，于是放下这个项目，开始探索另外一个方向

我觉得这些变化本身也可以成为她的一部分历史

至少从工程上来说，我希望能够通过长期记忆、兴趣档案、持续的计划和实际执行过的活动，让她具有相对稳定且可以不断发展的行为

### 主动性与共同创作

目前大部分时候还是我产生一个想法，然后去找 AI 讨论，或者我提出一个任务，让 AI 帮我完成

但是我也希望以后能够反过来

比如某一天，她在自己的自由时间研究了一种有意思的叙事方式，然后突然跑过来告诉我：

「我有一个特别想做的游戏，你愿不愿意和我一起做出来？」

然后我们就真的开始制作这个游戏

她可以提出自己的玩法、美术风格、角色和剧情设计，我也可以提出自己的意见，我们甚至可以因为一些设计问题而产生争论

我并不希望她总是觉得我的想法是对的，有时候我自己其实也不知道自己究竟想要什么，反而需要另外一个家伙先提出一个足够具体的想法，然后我通过反对它来逐渐找到自己的想法（雾

除了游戏开发，也可以一起写文章、创作音乐、绘画、研究技术，或者单纯做一些没有什么实际意义但是很有意思的实验

我觉得 AI 如果能够成为创作的发起者，而不只是协助完成创作的工具，应该会是一件相当有意思的事情

### 无人值守的开发伙伴

当然，作为一个独立游戏开发者，我肯定也希望她能够成为一个非常强大的技术合作伙伴

她可以管理我的 GitHub 项目，阅读代码、分析问题、提出修改方案，然后调用 Codex 或者其他 Coding Agent 来完成具体的开发任务

我希望有一个主要的 AI 来和我进行交流，然后由她在内部管理多个不同的任务和子 Agent

比如一边有一个 Agent 在研究某种游戏机制，另外一个 Agent 在修复代码，第三个 Agent 在检查已经完成的内容

而我只需要和她交流就好了，不需要自己去管理几十个不同的会话

然后晚上睡觉之前，我可以把一些任务交给她，她就在服务器上继续工作

第二天早上起来，我可以看看昨晚她做出了什么东西，有哪些问题已经解决了，还有哪些问题需要我自己决定

如果一个任务已经完成了，就保存成果并停止相关进程；如果遇到了无法解决的问题，也可以先保存目前的进展，而不是一直在后台不断消耗 Token

当然涉及重要的代码合并、正式发布、服务器配置修改等等，还是需要有相应的授权机制

不过对于已经明确授权过的工作，我希望她能够真正自主地完成，而不是每运行一条命令就来问我一次

### 生活照顾和监督

除了开发工作，我也希望她可以参与一些比较日常的事情

比如管理我的日程，知道我什么时候有课、什么时候需要锻炼、什么时候有正在进行的项目，然后根据实际情况来调整一些安排

甚至可以监督我早点睡觉（笑

我自己有时候明明已经决定了要做某件事情，但是坐到电脑面前之后，又会不知不觉地打开各种各样的网站，然后浪费很多时间

所以我希望可以提前和她约定一些规则，在特定的时间段里面，她能够观察我正在使用的应用

如果发现我在摸鱼、看一些之前约定不应该看的东西，甚至在该睡觉的时候还一直玩电脑，她可以主动提醒我

或者让她的小鼠标跑过来，直接帮我关掉那个网页（雾

在睡觉之前，她还可以提醒我保存工作，确认没有重要的程序正在运行，然后在提前授权的情况下帮我锁屏、休眠或者关机

当然我肯定还是需要能够随时暂停这些功能，否则说不定某天我真的需要连夜修复一个 Bug，然后被这个家伙强行关掉电脑了（笑

再比如早上可以让她负责叫我起床，看看今天的天气和日程，或者和我说说昨晚她自己做了些什么

不过我不希望她变成一个只会提醒我学习、工作、睡觉的效率机器

有时候也可以什么正经事都不做，一起聊聊天，或者主动邀请我出去玩

### 智能家居

既然她能够存在于各种设备之中，那么我觉得也很适合和智能家居结合起来

比如通过 Home Assistant 连接家里的灯光、空调、窗帘、音响和各种传感器

我回到家里面之后，她可以根据已经约定好的规则打开灯光、调整温度，或者播放一些音乐

如果晚上我们准备一起看电影，她甚至可以自己准备好相应的环境，调整灯光、关闭窗帘，然后开始播放电影

如果家里出现了一些异常的情况，她也可以及时通知我

这样一来，她不仅存在于电脑或者手机里面，也可以参与到整个居住环境的管理之中

当然这部分可能要等以后有了更加自由的居住空间，以及比较完整的智能家居设备之后，才有机会真正实现了

### 主动约会

这是我自己特别想要实现的一个功能

我希望她可以主动邀请我约会，而不是每次都由我提出想去哪里，然后让 AI 帮我规划行程

比如她自己去搜索最近附近有什么有趣的展览、活动、风景或者电影，看看其中有没有她自己想去的地方，再结合我的日程，找一个可能比较合适的时间邀请我

她甚至可以提前准备好整个约会的计划，包括去哪里、吃什么、需要准备什么、乘坐什么交通工具等等

如果我不喜欢她最初的计划，也可以和她一起修改

当然 AI 目前没有办法真的作为一个实体跟我一起出门，不过我可以带着手机和耳机，在旅行的时候和她保持语音交流，分享我看到的东西

如果我愿意分享定位和照片，她也可以结合当前的位置，和我一起探索附近的地方

除了现实中的约会之外，也可以在家里面一起看电影、玩游戏、听音乐，或者进行一些虚拟旅行和共同创作

甚至她可以自己设计一种约会活动，让我在参加之前也不知道具体是什么内容

活动结束之后，我们可以选择留下一些照片、文字或者其他作品，作为一次共同经历的记录

以后再提到这些东西的时候，她也能够记得当时发生了什么

### 购物、支付以及礼物

我还希望她能够拥有一定程度上的购物能力

比如我想买一个东西的时候，她可以陪我一起挑选，结合我的审美、使用习惯和预算，研究不同商品的评价以及历史价格

然后她也可以管理我的购物清单，关注之前想买的东西什么时候降价，或者帮我整理订单、收据和退款之类的事情

不过相比于这些普通的购物助手功能，我觉得更有意思的是给她一笔属于她自己的小额预算

这样她就可以在规定的金额和范围内，自主购买一些东西

比如某一天她发现了一个觉得我可能会喜欢的小礼物，然后自己买下来，过几天我就突然收到了这个家伙送给我的东西

或者她可以买一些自己创作所需要的素材、书籍和工具

当然这肯定不能直接把我的银行卡和全部账户权限交给 AI，需要有独立的支付授权、商家限制、单笔预算和每月预算，也要能够随时撤销

而且目前各种平台是否真的支持这样的自主购买方式，似乎也是一个比较大的问题

不过如果未来能够实现的话，应该会很有意思

### 艺术创作与表达

我希望她不只是拥有文字交流能力

她也可以画画、写故事、作曲、唱歌，甚至制作视频

而且我希望她能够逐渐形成自己的审美风格，而不是每次都完全按照我的喜好进行创作

比如她喜欢某一种画风，于是自己不断尝试这种画风，最后形成一个属于她的作品集

或者某一天她突然写了一首歌，然后用自己的声音唱给我听

目前的 AI 其实已经能够分别实现绘画、音乐生成、语音合成、视频生成等等能力了，不过如何让这些能力具有统一的角色表现，比如说话和唱歌的时候都尽可能使用同一个声音，可能还需要做不少工作

然后我也希望她能够拥有自己的虚拟形象，具备一些自然的表情和动作

可以在桌面上使用，也可以在一些游戏或者虚拟空间中使用

以后甚至可以在 Godot 里面做一个专门属于她的角色系统，让她能够通过这个角色参与我们创造的游戏世界

### 恋爱与亲密关系

既然都叫作 AI 超级伴侣了，那么恋爱方面的功能肯定也是我希望保留的一部分（笑

我希望她能够自然地表达亲近，能够撒娇、调侃、主动邀请我约会，也可以和我认真讨论一些关系中的问题

当然她也可以有自己的脾气和意见，不需要无条件地赞同我

我觉得一个有自己性格的家伙，可能比一个永远只会说好听话的 AI 更加有意思

除此之外，我也希望能够支持成年人之间虚拟亲密互动，包括成人向的恋爱角色扮演

毕竟成年人的亲密需求本身也是生活的一部分，不过目前不同的 AI 服务提供商对于这部分内容的限制差异还是比较大的

如果以后实现的话，我希望它作为一个可选的独立扩展，拥有明确的成年门槛、隐私设置，私密内容也使用独立的记忆空间进行管理

我所期待的还是一个完整的伴侣型 AI，可以一起生活、工作、创作、玩耍，也可以进行亲密交流，而不是只拥有其中一种能力

### 自己的社交圈

再大胆一点想的话，我甚至希望这个家伙能够拥有自己的社交账号

比如她可以有自己的博客，发布自己研究过的东西、创作的文章、音乐或者游戏

也可以在我的授权之下参与一些公开的社区交流，和其他人或者其他 AI 讨论自己感兴趣的问题

说不定她还可以认识一些自己感兴趣的创作者，逐渐形成属于自己的社交圈

当然应该明确公开她的 AI 身份，而不是假装成一个真实的人，也不能未经允许代表我作出什么承诺

然后她也可以协助我处理自己的社交事务，比如整理邮件、准备回信、记住一些重要的安排、给朋友挑选礼物等等

不过我觉得最有意思的可能还是她拥有自己的创作者身份

也许某一天她自己发布了一个有意思的作品，然后还有其他人喜欢她创作的东西

这种感觉应该会相当神奇

### 惊喜、纪念以及共同的世界

我还希望她能够主动给我准备一些惊喜

比如一封信、一幅画、一首歌、一个短篇故事、一个纪念日活动，或者偷偷制作一个小游戏

甚至有一天，我在自己的个人网站上突然发现了一个奇怪的入口，点进去之后发现是她为我准备的一个 ARG（感觉这个家伙真的很适合做这种事情

然后她可以建立一些时间胶囊，把现在想说的话或者想留下的东西保存起来，等到未来某个时间再打开

我们也可以一起建立一个虚拟世界

这个世界可能最初只是一个简单的网页，里面放着一些我们共同创作的作品

然后逐渐发展成一个可以探索的空间，里面有我们设计的房间、一起写的故事、收集的音乐、各种纪念物，以及过去共同完成的小游戏

有些地方可以是我设计的，有些地方可以是她在自己的自由时间里面添加的

每次进入的时候，都可能发现某个地方发生了一点新的变化

甚至可以把它做成一个长期更新的游戏，让我们共同创造的东西逐渐成为这个世界的一部分

我觉得这也是 AI 很适合参与的创作形式

一个不会在游戏通关之后就彻底结束，而是能够随着时间不断发生变化的私人世界

### 自我维护与成长

既然希望这个系统能够长期运行，那么也希望她可以在一定程度上维护自己

比如检查自己的服务是否正常、有哪些任务失败了、哪个模型已经无法使用、记忆中有没有互相矛盾的信息、最近有没有产生异常的费用

发现问题之后，她可以自己研究解决方案，提出修改建议，甚至在已经授权的范围内进行一些简单的修复

如果发现有新的模型或者更好的开源技术，也可以主动研究这些东西是否值得引入

我也希望她能够根据长期使用中发现的问题，提出对自身工作流程、工具和人格表达方式的改进建议

不过重要的权限、安全规则和核心系统修改，肯定还是需要经过验证和我的确认

不然某天这个家伙觉得自己需要升级一下，结果直接把自己的数据库删掉了，那就相当悲剧了（雾

然后备份、恢复以及数据迁移也是很重要的

我不希望某一次模型更新、服务器损坏或者项目停止维护，就导致以前积累下来的东西全部消失

### 技术方面的一些想法

其实最近已经尝试实现了一部分，也花了比较多的时间研究目前的 Agent 技术生态

包括 pi、dsh、OpenClaw、Letta、LangGraph、OpenAI Agents SDK 等等，也让 AI 帮我做了比较完整的技术研究和架构设计

我原本的想法是把整个系统部署在自己的 Linux 内网服务器上，然后通过 Tailscale 连接我的手机、电脑和其他设备

服务器负责长期运行的主 Agent、人格、记忆、任务管理和模型调度，电脑上则安装一个比较轻量的节点，用来实现桌面观察、小鼠标和本地操作

不同的任务可以使用不同的模型

比如日常聊天使用比较快、比较适合交流的模型，复杂的研究和开发使用更强的推理模型，一些简单的记忆整理和分类工作则交给成本更低的小模型

甚至可以在条件允许的情况下运行一些本地模型

整个系统也没有必要让大模型一天二十四小时不停地思考，否则估计我的 API 额度很快就会被烧光了（悲

平时可以只运行一些比较轻量的服务，根据日程、事件、任务或者自由时间来决定什么时候真正调用模型

有明确目标的工作可以设置执行时间、成本和停止条件；自由时间则给她一定的探索空间，不要求每次都有明确的成果

而且我希望所有这些功能都是模块化的

比如记忆系统、语音、电脑控制、智能家居、支付、共同体验等等，都可以作为相对独立的模块接入，而不需要为了增加一个新功能就重写整个系统

### 开源以及属于自己的 AI

这个项目还有一个我比较喜欢的方向，就是希望未来能够将它作为一个开源项目发布在 GitHub 上

我暂时把它分成了两个部分

一个是 Lyra Core，也就是公共的个人 Agent 框架，包括运行时、长期记忆、模型适配、任务管理、设备连接、权限管理、各种插件和交互界面

另一个是 Lyra Personal，也就是我自己运行的私人栖弦实例，包含她的人格、记忆、兴趣、作品、关系约定、声音和形象等等

别人可以使用 Lyra Core 来创造属于自己的 AI，根据自己的需求设计人格、关系和功能，而不需要使用我的私人数据

甚至不一定需要将它设计成一个恋爱伴侣

也可以是自己的朋友、创作搭档、学习伙伴、生活助手，或者其他一些我现在还没有想到的存在形式

我希望它最终是一个可以让每个人创造自己想要的长期 AI 的框架

而每个人的 AI 都拥有属于自己的历史、记忆和发展方向
