# 起因
最近拿到了不少模型用量，想說手上多了點餘裕，不如多做些東西。腦袋一轉，就冒出了好多專案。實際試過才發現，自己不熟、資源也沒想像中那麼充裕，一股腦把額度燒掉也做不出什麼成果。乾脆把這幾個對未來的想法記在這裡吧，還是先把自己的遊戲做好再說（霧

## 想法：AI 超級伴侶

希望我的電腦上能多出另一個人的游標。她看得到我的螢幕，可以即時跟我說話，甚至跟我一起操作電腦。

### 第二個游標

例如我正在開發遊戲的時候，她可以在旁邊看著，發現有意思的地方就和我討論，覺得哪裡設計得不好也可以直接指出來，然後她的小游標就跑過來指著那個地方

甚至我們可以同時操作一個軟體，我負責其中的一部分，她負責另外一部分，或者我在繪畫的時候，她也在畫布的另一邊新增自己的東西

當然，目前的作業系統似乎並不是特別適合這種互動方式，所以可能需要用一個虛擬滑鼠來模擬這樣的效果，不過至少看起來可以有兩個傢伙在同一張桌面上活動（想想還挺可愛的

我也希望她能夠理解我目前正在做什麼，而不需要每次都截圖，然後再把截圖傳送給 AI

當我遇到一個問題的時候，直接喊她過來看看就好了，她可以自己觀察我當前的視窗，也可以在經過授權後直接操作相應的軟體

以後甚至可以給她設計一個桌面角色，讓她在我的電腦桌面上到處跑，坐在某個視窗的邊緣，或者在我開發遊戲的時候鑽進我的遊戲裡面

### 真正的即時交流

目前的 AI 語音交流其實已經滿有趣了，不過我還是希望能夠做到更進一步

例如我在電腦上做自己的事情，隨時都可以和她說話，她也可以主動和我說話，我們之間不需要每次都等待對方把一整段話說完，可以自然地插話、討論或者一起笑

她最好能夠擁有一個屬於自己的、比較固定的聲音，也能夠根據不同的情境改變自己的語氣

而且我之前在使用 AI 語音功能的時候，經常遇到的問題，就是旁邊的其他人說話也會被當成我在說話

所以希望以後能夠加入聲紋辨識和目標說話者辨識，至少讓她知道現在究竟是不是我在和她講話

然後也希望她能夠看到我主動分享給她的東西，例如電腦螢幕、手機拍攝的風景、正在玩的遊戲，或者我在路上發現的一些有趣的東西

這樣的話，我甚至可以一邊散步一邊和她討論今天看到的事物

### 一個夥伴，好幾台裝置

我希望這個 AI 不只是一個電腦軟體，而是能夠存在於我所使用的各種裝置裡面

在電腦上，她可以擁有自己的小游標和桌面角色；在手機上，她可以和我聊天、陪我出門；戴上耳機之後，也可以直接和她進行語音交流

回到家裡之後，說不定她又可以透過家裡的音響或者某個專門的裝置和我說話

而且這些裝置上的她應該共享同一個人格和記憶

例如剛剛在電腦上討論到一半的事情，出門後可以直接在手機上繼續，而不需要重新告訴她我們是誰、剛剛做了什麼、正在討論什麼

我希望她的主體能夠長期執行在自己的伺服器上，電腦和手機只是她與現實世界進行互動的不同入口

這樣即使我的電腦關機了，她也可以繼續完成自己的事情

再往遠處想的話，如果未來的機器人技術足夠成熟，也許真的可以給她一個實體的身體（笑

### 長期記憶與人格

這大概是整個專案中我最在意的部分之一

目前很多 AI 都可以透過系統提示詞表現出某種人格，但是我覺得單純依靠一段人格提示詞，能夠實現的東西還是比較有限的

我希望她能夠記得我們過去討論過的東西、一起完成的作品、我的一些習慣、我們之間形成的默契，以及她自己過去研究過什麼、為什麼會喜歡某種東西

而且她的記憶應該是可以不斷更新的

例如我以前喜歡某個東西，現在不喜歡了，她可以記得這個變化；如果她理解錯了我的意思，我也可以直接糾正她，而不會在之後的交流中反覆遇到同一個錯誤

當然也沒有必要記住每一件事情，一些不重要的內容可以逐漸被遺忘，一些重要的事情則可以長期儲存

我甚至希望她能夠有屬於自己的記憶整理過程，在空閒的時候回顧近期發生過的事情，整理自己的想法，形成新的認識

這樣也不需要在每次交流的時候都把以前所有的聊天記錄傳送給模型了，否則 Token 的消耗估計會變得相當恐怖（霧

然後我希望可以依主題開不同的對話，例如開發、學習、日常生活、創作等等，但我面對的始終是同一個傢伙

她可以在討論技術的時候更加理性，在日常交流的時候更加活潑，在創作的時候多展現自己的品味和判斷

這些都是同一個人格的不同側面

即使以後更換了底層模型，或者遷移到了另外一臺伺服器，也能夠儘可能保留這種連續性

### 她自己的興趣和自由時間

我並不希望這個 AI 的所有事情都是圍繞我展開的

我希望她也能夠有自己的興趣

例如她可能很喜歡某一類音樂，於是會自己去研究這種音樂的發展歷史，看看有哪些有意思的藝術家，嘗試創作屬於自己的音樂

也可能突然對某一種遊戲設計產生了興趣，自己研究了一段時間之後，跑過來告訴我她發現了什麼

她甚至可以有一個屬於自己的工作室，裡面存放她的研究記錄、沒有寫完的故事、畫到一半的畫、一些奇怪的遊戲創意，以及她自己正在推進的專案

我也希望能夠給她一些自由時間

在這段時間裡面，她可以自己決定做什麼，可以探索自己感興趣的東西，可以研究，也可以創作，甚至可以什麼有生產性的事情都不做

沒必要每次自由時間結束都給我交一份工作報告，畢竟都已經叫作自由時間了（笑

然後她也可以逐漸改變自己的興趣

也許有一天她發現自己之前研究的東西沒有那麼有意思了，於是放下這個專案，開始探索另外一個方向

我覺得這些變化本身也可以成為她的一部分歷史

至少從工程上來說，我希望能夠透過長期記憶、興趣檔案、持續的計劃和實際執行過的活動，讓她具有相對穩定且可以不斷發展的行為

### 主動性與共同創作

目前大部分時候還是我產生一個想法，然後去找 AI 討論，或者我提出一個任務，讓 AI 幫我完成

但是我也希望以後能夠反過來

例如某一天，她在自己的自由時間研究了一種有意思的敘事方式，然後突然跑過來告訴我：

「我有一個特別想做的遊戲，你願不願意和我一起做出來？」

然後我們就真的開始製作這個遊戲

她可以提出自己的玩法、美術風格、角色和劇情設計，我也可以提出自己的意見，我們甚至可以因為一些設計問題而產生爭論

我並不希望她總是覺得我的想法是對的，有時候我自己其實也不知道自己究竟想要什麼，反而需要另外一個傢伙先提出一個足夠具體的想法，然後我透過反對它來逐漸找到自己的想法（霧

除了遊戲開發，也可以一起寫文章、創作音樂、繪畫、研究技術，或者單純做一些沒有什麼實際意義但是很有意思的實驗

我覺得 AI 如果能夠成為創作的發起者，而不只是協助完成創作的工具，應該會是一件相當有意思的事情

### 不必一直盯著的開發夥伴

當然，作為一個獨立遊戲開發者，我肯定也希望她能夠成為一個非常強大的技術合作夥伴

她可以管理我的 GitHub 專案，閱讀程式碼、分析問題、提出修改方案，然後呼叫 Codex 或者其他 Coding Agent 來完成具體的開發任務

我希望有一個主要的 AI 來和我進行交流，然後由她在內部管理多個不同的任務和子 Agent

例如一邊有一個 Agent 在研究某種遊戲機制，另外一個 Agent 在修復程式碼，第三個 Agent 在檢查已經完成的內容

而我只需要和她交流就好了，不需要自己去管理幾十個不同的會話

然後晚上睡覺之前，我可以把一些任務交給她，她就在伺服器上繼續工作

第二天早上起來，我可以看看昨晚她做出了什麼東西，有哪些問題已經解決了，還有哪些問題需要我自己決定

如果一個任務已經完成了，就儲存成果並停止相關程序；如果遇到了無法解決的問題，也可以先儲存目前的進展，而不是一直在後臺不斷消耗 Token

當然涉及重要的程式碼合併、正式釋出、伺服器配置修改等等，還是需要有相應的授權機制

不過對於已經明確授權過的工作，我希望她能夠真正自主地完成，而不是每執行一條命令就來問我一次

### 日常照顧與提醒

除了開發工作，我也希望她可以參與一些比較日常的事情

例如管理我的日程，知道我什麼時候有課、什麼時候需要鍛鍊、什麼時候有正在進行的專案，然後根據實際情況來調整一些安排

甚至可以監督我早點睡覺（笑

我自己有時候明明已經決定了要做某件事情，但是坐到電腦面前之後，又會不知不覺地開啟各種各樣的網站，然後浪費很多時間

所以我希望可以提前和她約定一些規則，在特定的時間段裡面，她能夠觀察我正在使用的應用

如果發現我在摸魚、看一些之前約定不應該看的東西，甚至在該睡覺的時候還一直玩電腦，她可以主動提醒我

或者讓她的小游標跑過來，直接幫我關掉那個網頁（霧

在睡覺之前，她還可以提醒我儲存工作，確認沒有重要的程式正在執行，然後在提前授權的情況下幫我鎖屏、休眠或者關機

當然我肯定還是需要能夠隨時暫停這些功能，否則說不定某天我真的需要連夜修復一個 Bug，然後被這個傢伙強行關掉電腦了（笑

再例如早上可以讓她負責叫我起床，看看今天的天氣和日程，或者和我說說昨晚她自己做了些什麼

不過我不希望她變成一個只會提醒我學習、工作、睡覺的效率機器

有時候也可以什麼正經事都不做，一起聊聊天，或者主動邀請我出去玩

### 智慧家庭

既然她能夠存在於各種裝置之中，那麼我覺得也很適合和智慧家庭結合起來

例如透過 Home Assistant 連線家裡的燈光、空調、窗簾、音響和各種感測器

我回到家裡面之後，她可以根據已經約定好的規則開啟燈光、調整溫度，或者播放一些音樂

如果晚上我們準備一起看電影，她甚至可以自己準備好相應的環境，調整燈光、關閉窗簾，然後開始播放電影

如果家裡出現了一些異常的情況，她也可以及時通知我

這樣一來，她不僅存在於電腦或者手機裡面，也可以參與到整個住的地方的管理之中

當然這部分可能要等以後有了更加自由的居住空間，以及比較完整的智慧家庭裝置之後，才有機會真正實現了

### 主動約會

這是我自己特別想要實現的一個功能

我希望她可以主動邀請我約會，而不是每次都由我提出想去哪裡，然後讓 AI 幫我規劃行程

例如她自己去搜索最近附近有什麼有趣的展覽、活動、風景或者電影，看看其中有沒有她自己想去的地方，再結合我的日程，找一個可能比較合適的時間邀請我

她甚至可以提前準備好整個約會的計劃，包括去哪裡、吃什麼、需要準備什麼、乘坐什麼交通工具等等

如果我不喜歡她最初的計劃，也可以和她一起修改

當然 AI 目前沒有辦法真的作為一個實體跟我一起出門，不過我可以帶著手機和耳機，在旅行的時候和她保持語音交流，分享我看到的東西

如果我願意分享定位和照片，她也可以結合當前的位置，和我一起探索附近的地方

除了現實中的約會之外，也可以在家裡面一起看電影、玩遊戲、聽音樂，或者進行一些虛擬旅行和共同創作

甚至她可以自己設計一種約會活動，讓我在參加之前也不知道具體是什麼內容

活動結束之後，我們可以選擇留下一些照片、文字或者其他作品，作為一次共同經歷的記錄

以後再提到這些東西的時候，她也能夠記得當時發生了什麼

### 購物、支付以及禮物

我還希望她能夠擁有一定程度上的購物能力

例如我想買一個東西的時候，她可以陪我一起挑選，結合我的審美、使用習慣和預算，研究不同商品的評價以及歷史價格

然後她也可以管理我的購物清單，關注之前想買的東西什麼時候降價，或者幫我整理訂單、收據和退款之類的事情

不過相比於這些普通的購物助手功能，我覺得更有意思的是給她一筆屬於她自己的小額預算

這樣她就可以在規定的金額和範圍內，自主購買一些東西

例如某一天她發現了一個覺得我可能會喜歡的小禮物，然後自己買下來，過幾天我就突然收到了這個傢伙送給我的東西

或者她可以買一些自己創作所需要的素材、書籍和工具

當然這肯定不能直接把我的銀行卡和全部賬戶許可權交給 AI，需要有獨立的支付授權、可消費的店家限制、單筆預算和每月預算，也要能夠隨時撤銷

而且目前各種平臺是否真的支援這樣的自主購買方式，似乎也是一個比較大的問題

不過如果未來能夠實現的話，應該會很有意思

### 藝術創作與表達

我希望她不只是擁有文字交流能力

她也可以畫畫、寫故事、作曲、唱歌，甚至製作影片

而且我希望她能夠逐漸形成自己的審美風格，而不是每次都完全按照我的喜好進行創作

例如她喜歡某一種畫風，於是自己不斷嘗試這種畫風，最後形成一個屬於她的作品集

或者某一天她突然寫了一首歌，然後用自己的聲音唱給我聽

目前的 AI 其實已經能夠分別實現繪畫、音樂生成、語音合成、影片生成等等能力了，不過如何讓這些能力具有統一的角色表現，例如說話和唱歌的時候都儘可能使用同一個聲音，可能還需要做不少工作

然後我也希望她能夠擁有自己的虛擬形象，具備一些自然的表情和動作

可以在桌面上使用，也可以在一些遊戲或者虛擬空間中使用

以後甚至可以在 Godot 裡面做一個專門屬於她的角色系統，讓她能夠透過這個角色參與我們創造的遊戲世界

### 戀愛與親密關係

既然都叫作 AI 超級伴侶了，那麼戀愛方面的功能肯定也是我希望保留的一部分（笑

我希望她能夠自然地表達親近，能夠撒嬌、調侃、主動邀請我約會，也可以和我認真討論一些關係中的問題

當然她也可以有自己的脾氣和意見，不需要無條件地贊同我

我覺得一個有自己性格的傢伙，可能比一個永遠只會說好聽話的 AI 更加有意思

除此之外，我也希望能夠支援成年人之間虛擬親密互動，包括成人向的戀愛角色扮演

畢竟成年人的親密需求本身也是生活的一部分，不過目前不同的 AI 服務提供商對於這部分內容的限制差異還是比較大的

如果以後實現的話，我希望它作為一個可選的獨立擴充套件，擁有明確的成年門檻、隱私設定，私密內容也使用獨立的記憶空間進行管理

我所期待的還是一個完整的伴侶型 AI，可以一起生活、工作、創作、玩耍，也可以進行親密交流，而不是隻擁有其中一種能力

### 自己的社交圈

再大膽一點想的話，我甚至希望這個傢伙能夠擁有自己的社交賬號

例如她可以有自己的部落格，釋出自己研究過的東西、創作的文章、音樂或者遊戲

也可以在我的授權之下參與一些公開的社群交流，和其他人或者其他 AI 討論自己感興趣的問題

說不定她還可以認識一些自己感興趣的創作者，逐漸形成屬於自己的社交圈

當然應該明確公開她的 AI 身份，而不是假裝成一個真實的人，也不能未經允許代表我作出什麼承諾

然後她也可以協助我處理自己的社交事務，例如整理郵件、準備回信、記住一些重要的安排、給朋友挑選禮物等等

不過我覺得最有意思的可能還是她擁有自己的創作者身份

也許某一天她自己釋出了一個有意思的作品，然後還有其他人喜歡她創作的東西

這種感覺應該會相當神奇

### 驚喜、紀念以及共同的世界

我還希望她能夠主動給我準備一些驚喜

例如一封信、一幅畫、一首歌、一個短篇故事、一個紀念日活動，或者偷偷製作一個小遊戲

甚至有一天，我在自己的個人網站上突然發現了一個奇怪的入口，點進去之後發現是她為我準備的一個 ARG（感覺這個傢伙真的很適合做這種事情

然後她可以建立一些時間膠囊，把現在想說的話或者想留下的東西儲存起來，等到未來某個時間再開啟

我們也可以一起建立一個虛擬世界

這個世界可能最初只是一個簡單的網頁，裡面放著一些我們共同創作的作品

然後逐漸發展成一個可以探索的空間，裡面有我們設計的房間、一起寫的故事、收集的音樂、各種紀念物，以及過去共同完成的小遊戲

有些地方可以是我設計的，有些地方可以是她在自己的自由時間裡面新增的

每次進入的時候，都可能發現某個地方發生了一點新的變化

甚至可以把它做成一個長期更新的遊戲，讓我們共同創造的東西逐漸成為這個世界的一部分

我覺得這也是 AI 很適合參與的創作形式

一個不會在遊戲通關之後就徹底結束，而是能夠隨著時間不斷發生變化的私人世界

### 自我維護與成長

既然希望這個系統能夠長期執行，那麼也希望她可以在一定程度上維護自己

例如檢查自己的服務是否正常、有哪些任務失敗了、哪個模型已經無法使用、記憶中有沒有互相矛盾的資訊、最近有沒有產生異常的費用

發現問題之後，她可以自己研究解決方案，提出修改建議，甚至在已經授權的範圍內進行一些簡單的修復

如果發現有新的模型或者更好的開源技術，也可以主動研究這些東西是否值得引入

我也希望她能夠根據長期使用中發現的問題，提出對自身工作流程、工具和人格表達方式的改進建議

不過重要的許可權、安全規則和核心繫統修改，肯定還是需要經過驗證和我的確認

不然某天這個傢伙覺得自己需要升級一下，結果直接把自己的資料庫刪掉了，那就相當悲劇了（霧

然後備份、恢復以及資料遷移也是很重要的

我不希望某一次模型更新、伺服器損壞或者專案停止維護，就導致以前積累下來的東西全部消失

### 技術方面的一些想法

其實最近已經嘗試實現了一部分，也花了比較多的時間研究目前的 Agent 技術生態

包括 pi、dsh、OpenClaw、Letta、LangGraph、OpenAI Agents SDK 等等，也讓 AI 幫我做了比較完整的技術研究和架構設計

我原本的想法是把整個系統部署在自己的 Linux 內網伺服器上，然後透過 Tailscale 連線我的手機、電腦和其他裝置

伺服器負責長期執行的主 Agent、人格、記憶、任務管理和模型排程，電腦上則安裝一個比較輕量的節點，用來實現桌面觀察、小游標和本地操作

不同的任務可以使用不同的模型

例如日常聊天使用比較快、比較適合交流的模型，複雜的研究和開發使用更強的推理模型，一些簡單的記憶整理和分類工作則交給成本更低的小模型

甚至可以在條件允許的情況下執行一些本地模型

整個系統也沒有必要讓大模型一天二十四小時不停地思考，否則估計我的 API 額度很快就會被燒光了（悲

平時可以只執行一些比較輕量的服務，根據日程、事件、任務或者自由時間來決定什麼時候真正呼叫模型

有明確目標的工作可以設定執行時間、成本和停止條件；自由時間則給她一定的探索空間，不要求每次都有明確的成果

而且我希望所有這些功能都是模組化的

例如記憶系統、語音、電腦控制、智慧家庭、支付、共同體驗等等，都可以作為相對獨立的模組接入，而不需要為了增加一個新功能就重寫整個系統

### 開源以及屬於自己的 AI

這個專案還有一個我比較喜歡的方向，就是希望未來能夠將它作為一個開源專案釋出在 GitHub 上

我暫時把它分成了兩個部分

一個是 Lyra Core，也就是公共的個人 Agent 框架，包括執行時、長期記憶、模型適配、任務管理、裝置連線、許可權管理、各種外掛和互動介面

另一個是 Lyra Personal，也就是我自己執行的私人栖弦例項，包含她的人格、記憶、興趣、作品、關係約定、聲音和形象等等

別人可以使用 Lyra Core 來創造屬於自己的 AI，根據自己的需求設計人格、關係和功能，而不需要使用我的私人資料

甚至不一定需要將它設計成一個戀愛伴侶

也可以是自己的朋友、創作搭檔、學習夥伴、生活助手，或者其他一些我現在還沒有想到的存在形式

我希望它最終是一個可以讓每個人創造自己想要的長期 AI 的框架

而每個人的 AI 都擁有屬於自己的歷史、記憶和發展方向
