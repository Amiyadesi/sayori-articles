## はじめに：この物語はどこから始まるのか

自己紹介ストーリー

私の話を聞いてみる気はありませんか（笑）

といっても物語に大した起伏はなく、むしろ私の18歳までの人生には転機がひとつしかありません

16歳までは基本的にぼーっと過ごしていました

昔から話を聞くのも話すのも大好きで、中毒レベルでした。そうすることでこの世界がよりリアルに感じられ、誰もがひとりの生身の人間なんだと実感できたからです

当時の私は子どもの頃からずっと太っていて、変わろうとも思わず「まあこれでいいか」と、ただゲームや動画に浸る日々。唯一変わらなかったのは、相変わらずのコミュ障だったことですね（笑）

## 16歳のある日、ダイエットを決意した

転機が訪れたのは16歳のとある午後。階段を上るのがしんどくて色々考えたせいかもしれませんが、ダイエットしようと決意しました ^af4158

不思議なことに、高1の頃は人から侮辱的なあだ名をつけられたこともありましたが、当時は特に気にも留めず、むしろ周りに合わせるために自分で自虐ネタにしていたくらいでした。何度か小さく爆発したこともありましたが大して意味はなく、それに高2の文理・専攻分けのクラス替えでそういうのも全部なくなりました

それなのに、高2のときに階段を上っていたある瞬間、急にダイエットをやり抜こうと決心したんです。誰かに外から急かされたわけでもなく、それまでダイエット動画なんて一度も見たことがありませんでした

そこからはすぐ行動に移し、友達を誘って走り始めました。何回か走っているうちに、クラスの運動神経抜群な子に目をつけられました

しかもその子がすごくいいやつで、夜間の自習時間にわざわざ「一緒に走ってあげるよ」とメモを渡してくれたんです

## ランニングから筋トレへ

こうして最初はただひたすら走るだけでダイエットを始め、数周から3キロ、5キロ、10キロへと距離を伸ばしていきました

体重も半年ほどで25キロくらい落ちました。今思えば本当に不思議ですが、ネットでは失敗しやすいとよく聞くのに、一発で成功してしまったんです

ただ、やり方を調べる術を知らなかったせいで良くない点もありました。筋トレをせずランニングだけしていたため筋肉が少し落ちてしまい、減った25キロもほとんどが水分だったのです。元の体重が大きいと痩せやすいというのはこういう理屈ですね

その後、高2の後半になると、高1の頃から知り合いだった別の体育会系のすごい人にジムへ誘われました

序盤のダイエット法があまり適切ではなかったせいで、筋トレはかなりきつかったです。重いウェイトは全然上がらず、少しずつ筋肉を取り戻すしかありませんでした

それに、最初ずっと走り続けていたせいで膝も少し痛めていたようで……ただ、高2の後半からは筋トレ中心になり、走る頻度が減ったおかげで膝も少し回復しました

こうして筋トレも半年ほど続けました。見た目は半年鍛えたようには全然見えませんでしたが、確かに半年やり遂げましたし、落とした体重もきちんとキープできました

その後も同じように運動を続け、科学的なトレーニング動画も見始めながら、高3前期の「首考」が終わるまで続けました

「首考」というのは浙江省特有の大学入試制度で、選択科目3つと英語を前倒しで受験するものです。確かこの試験が終わったあと、2週間ほど国語と数学の授業がありました

## 高3の試験後、初めて本気でゲーム制作を学ぶ

首考が終わったあとは時間にも余裕ができ、ゲーム制作を学んでみようという気持ちが芽生えました。そして今回は、やってみようと自分自身を納得させることができました

ゲームを作りたいという思い自体はかなり昔からあり、おそらく小学生の頃まで遡ります

当時、『Undertale』を紹介する動画を見たんです。インディー開発者が作ったゲームで、すべての要素をたった一人で書き上げたという話でした（実際には誇張気味の紹介動画で、作者本人の後ろにはチームもいたのですが、彼自身がコアメンバーとして開発の大部分を担っていたのは確かです）

たぶんそのとき、私の中に「ゲームを作りたい」という芽が植えられたのだと思います。ただ惜しいことに、ずっとそれを育てる根気がありませんでした

中学時代はそのゲームの二次創作にどっぷりハマり、自分でも参加してみようとノートに設定を書き連ねていました。今でいう「オリキャラ（OC）」みたいなものですね

ネットに投稿する勇気すらありませんでした

そして高3のあのとき、運動と筋トレをやり抜いた実績をもって自分自身を説得し、ついにずっと前に植えたその種へ最初の一杯の水をやったのです

その期間には図書館で本を借りてPythonを勉強したり、ノートに設定を書き出したりしていました

## チュートリアル実践、環境構築、そして初めての Game Jam

高3の十数日間の冬休みには、Bilibiliでチュートリアル動画を探して見始めました

最初はいろんな概念を解説するだけの動画を見ていたのですが、あまり興味が湧きませんでした。それでも探し続けた結果

海外の有名なゲーム制作系投稿者が作った、初心者向けの1時間ハンズオンチュートリアルを見つけたんです

実際に手を動かしながら学ぶスタイルだと吸収が早く、すごく楽しくて、自分の最初の小さな完成品を作ることができました

それをやり終えたあと、最初に見始めていた理論中心のチュートリアルは思い切って切り捨て、実践一本に切り替えました

そのハンズオンを終えた次は、かなり有名な中級者向けの実践チュートリアルに挑戦しました。あれが私にとって「初心者脱皮の分岐点」だったと言えます

有限ステートマシン、シリアライズとデシリアライズ、タイルマップや地形生成など、高度な概念やシステム構築をたくさん解説してくれる内容でした

私は真正面から食らいつき、残りの冬休みをすべてそれに注ぎ込みました

最終的にはチュートリアル通りに作り切ることができました。概念の理解はまだ少し曖昧な部分もありましたが、それでも構いませんでした

新学期が始まってからも毎週末新しいチュートリアルを探しては手を動かす習慣を続けました

そうして数をこなすうちに、異なるジャンルのゲームを作るチュートリアルでも、根底には共通する開発思想がたくさんあることに気づきました

こうした高度な概念も実践の中で少しずつ身につき、同時にデザインパターンやコンポーネント指向開発、オブジェクト指向プログラミングなど、さらに多くの知識にも触れるようになりました

そうして大学入試後の夏休みを迎え、ついにたっぷりの自由時間と自分専用のパソコンを手に入れました

パソコンが届いた初日から開発環境の構築方法を調べ始め、3日かけて環境を整えました

それまではずっと母のパソコンで開発していたので、ゲームエンジン以外の開発環境を一切入れられず、ずっとうずうずしていたんです

自分のパソコンを手に入れてからは興奮しながらネットの世界を探検し、GitHubなどのアカウントも登録して大量のリソースを集めたり、PCの基本操作を覚えたり、便利なソフトをインストールしたりしました

当時はまだAIがそれほど発達していなかったので、全部Bilibiliの動画を見ながら手作業で設定しました（笑）。今でもよく覚えています

そこから一気にいくつものチュートリアルをこなしましたが、なんというか、もうチュートリアルだけではあまり成長を感じられなくなっていました。もちろん、見ていたのがほぼ2Dゲーム系のチュートリアルばかりだったせいもあると思います

私は2Dゲームを作りたかったのでずっと2Dに絞って学んでいたのですが、その頃にはすでにいろんなタイプのチュートリアルをやり終えていて、これ以上続けても伸び悩む気がしたんです

そこで開発者コミュニティに「この先どう成長すればいいか」と質問してみたところ、チュートリアルを続ける以外の選択肢として「コンテストに出てみるといい」という回答をもらいました

さっそく Game Jam について調べてみると、ちょうどそのコミュニティでも開催中だったので参加してみることにしました

初めての Game Jam のテーマは「wake」で、このテーマに沿ってゲームを1本制作するというものでした

期間はかなり長めだった記憶があります。1か月半あり、後からさらに半月延長されました。おそらくより多くの人に参加してもらうためだったのだと思います

私はテーマ発表と同時に制作を始め、人生で初めてゼロからゲームの企画を練り、素材を探し、自分のゲームのスクリプトを書きました

この作品では、今後踏みうる地雷をほぼ一通り踏み抜いたと言えます（笑）。私にとって特に学びが多く、記念すべき一本になりました

## 最初のゲーム制作で踏んだ地雷

まずひとつ目は、バージョン管理、つまり開発中の進捗セーブをきちんと行うことです。これには Git というツールを使ってローカルに保存し、GitHub を使えばクラウドにも保存できるのでとても便利です

当時、私は開発初期にまだ未熟だったAIをゲーム制作に使っていました

最初の何回かがうまくいったせいで味を占め、数日間ずっとAI任せでコードを書かせてしまったんです

結果、やればやるほどぐちゃぐちゃになり、スクリプトにも想定外の不具合が山ほど出て、ロジックも破綻しました

泣く泣く数日前のセーブポイントまで巻き戻す羽目になり、最初にAIがうまく直してくれた部分すら残せませんでした

これは今の時代でもAI開発における大きなタブーですが、AIを使うならこまめなバックアップが絶対条件です

その後、そのプロジェクトは完全な手書きコードになり、私にとって唯一の「純粋な人力コード作品」になりました（笑）

さらに後になるとAIも賢くなり、無料のAIツールも出てきたので、効率を上げられるところではやはり使っていますが、プロンプトで制約をかけるなど慎重に扱うようにしています

ふたつ目は、成熟したプラグインがあるなら素直にそれを使うべきで、車輪の再発明をする必要はないということです

最初、そのプロジェクトの会話システムとクエストシステムは、チュートリアルを見ながら3日かけて自分で実装しました

しかし所詮はチュートリアル製のシステムなので、基本機能はあっても高度な機能がまるで足りず、しばらく使っているうちにどうにもストレスが溜まってきました

そこで、すでに完成度の高い既存の会話システムプラグインを試してみることにしました

半日もあれば使いこなせるうえに便利な機能がたくさん詰まっており、外部向けのカスタムインターフェースまで用意されていました

なんなら自分の開発フローに合わせてプラグインのソースコードを直接書き換えることもできます

プラグイン自体もオープンソースでした

今でも私のプロジェクトの会話システムはこのプラグインを使っています

自分なりに高度な設定もたくさんカスタマイズしたので、より手に馴染みましたしプラグインへの理解も深まりました。しかも作者さんが今もアップデートを続けてくれています

そしてもうひとつは、よく分からないボタンを興味本位で押さないこと。本当にろくなことになりません

開発終盤、数日かけてプロトタイプの全フローを一気に作り上げたものの、まだ Git にコミットできていない状態でした

そんなとき、初めてGUIツールでコミットしようとして面白いボタンがたくさん並んでいるのを見つけ、「プル（pull）」がどういう意味か試してみようとクリックしてしまったんです

それまではずっとコマンドラインでコミットしていたのですが、確か動画でGUIコミットができると見て設定してみたばかりでした

その結果、その「プル」によってリモートの進捗がローカルに上書きされ、リモートより3日分進んでいたローカルの作業データが丸ごと消えてしまいました！

あのときは心が折れて制作をやめそうになりましたが、捨てる神あれば拾う神ありです

上書きしてしまう前の晩、自分で遊んでみるためにテスト版をビルドして書き出していたのです

そこで、リバースエンジニアリング（アンパック）で開発進捗を復元することを思いつきました

使っていたのがオープンソースのゲームエンジンだったおかげで、アンパックはかなり簡単でした。ソースコードもすべて GitHub に公開されています

しかも誰かがワンクリックで展開できるアンパックツールまで作ってくれていたので、スマホに入っていた APK ファイルをパソコンに送り返し、ツールを使ってプロジェクトの進捗を復元しました

丸一日無駄にはなりましたが、3日分の進捗を取り戻せたので本当に助かりました

この3つの大きな地雷を踏み抜いたあと、なんとかかんとか最初のゲームを完成させました。実際のところ初期バージョンの制作自体は14日ほどで、その後1週間ほど間を空けてから、さらに8日かけて新要素や設定を追加してブラッシュアップしました

最終的に8月1日の提出開始と同時に初期バージョンを提出しました

その後1週間休んでからまた1週間開発を続けましたが、正直あの1週間あまりにもダラダラ過ごしすぎたと感じて、自分を追い込むために1週間ちょっと追加アップデートをした感じです

そして当初の締切だった8月15日前後に提出しました。提出直前になって半月の延長が発表されてはいましたが

## 作り終えて、本当に学んだこと

初めて1本作り切ったことで、ゼロから素材や効果音を探し、シナリオやスクリプトを書くという一連の工程すべてを経験でき、本当に興奮しました

作り終えて気づいたのは、全体のフローを一通り形にすることはできても、パーティクルやUI、モーション演出といった細部の作り込みがまだ全然できていないこと、そして後半になるにつれてコード構成がかなり散らかってしまうことでした（今はAIの力を借りればかなり綺麗に整理できますが）

そこで次の1か月はそれらの弱点補強に充て、モーション演出と Game Jam 体験に特化したチュートリアルや、C# での開発を教える別のチュートリアルに取り組みました。途中で8月31日が初音ミクの誕生日だと思い出し、数日時間を割いてミクのミニゲームも作りました。Bilibiliにも投稿してあります（笑）
