# 我做了一個小型論壇列表倉庫

我之前一直想整理一張互聯網社區地圖

這裏說的不是 X、Instagram、貼吧、小紅書、小黑盒這種明面上的大平臺，而是那些你不主動搜索、不混相關圈子，基本不會自然刷到的論壇和社區

這件事現在已經從一篇文章，變成了一個可以長期維護的獨立倉庫和在線頁面：

- GitHub 倉庫：[https://github.com/Amiyadesi/small-forums-list](https://github.com/Amiyadesi/small-forums-list)
- 在線頁面：[https://forums.cc.cd/](https://forums.cc.cd/)

現在這個站更接近 wiki 或 docs 的形態：左邊是分類和社區目錄，中間是具體條目，每個社區都有自己的頁面，頁面底部也接了 Giscus 評論區

目前首版收了 49 個社區。後面如果有人補充、糾錯或者提交 PR，這個數字還會繼續變

## 這個倉庫收什麼

這裏的“小型”不是嚴格按用戶數算，而是按接觸路徑算

如果一個社區不主動搜基本接觸不到，或者只有混主機圈、ACG 圈、安全圈、硬件圈、站長圈、資源圈的人才會經常看到，那它就可能適合收錄

目前大概分成這些類：

- 技術 / AI / 開發者
- 主機 / VPS / 站長 / 獨立站
- 搜索 / 資源 / 知識工具
- 安全 / 逆向 / 系統 / 軟件
- ACG / 遊戲 / 小圈子
- 硬件 / 電子 / Homelab
- 成人 / 資源 / 灰區
- 海外老論壇 / 泛興趣

雖然AI分的感覺有些怪，但是沒辦法就先這樣好了

## 現在的頁面長什麼樣

之前它更像一份 README 長列表，現在已經拆成了站點。

首頁會保留分類速覽，適合快速看有哪些社區；左側目錄適合按分類跳轉；每個社區也有單獨頁面，方便別人直接指出某個社區寫錯了、入口變了、註冊規則變了

我一開始想做的是“互聯網社區地圖”，但越寫越發現，地圖最難的不是畫出來，而是持續維護

論壇入口會變，註冊方式會變，社區氛圍也會變。主機圈會因爲商家、線路和活動不斷出現新信息，ACG 和資源社區也經常因爲域名、權限、版規變化而過時

所以現在的思路是：倉庫負責做目錄和事實記錄，博客負責寫個人體驗

如果我真的長期混過某個社區，就單獨寫文章。如果只是公開資料整理，就留在列表裏

## 每個社區會寫什麼

倉庫裏每個條目會盡量寫這些信息：

- 入口
- 定位和社區氛圍
- 註冊方式或門檻
- 裏面主要有什麼
- 適合看什麼
- 注意事項
- 公開來源
- 最後覈驗日期

我長期進去體驗過的社區，會寫得更像真實感受。

比如 Linux.do 和 NodeLoc，我會參考自己之前那篇[[internet-community-1|互联网社区记录1]]裏的體驗去寫：Linux.do 的規則、新手任務、公益站、福利羊毛、開發調優、文檔共建、LDC；NodeLoc 的自由氛圍、子論壇、電池積分、AFF 和站長活躍度

沒有長期使用過的社區，就只按公開頁面和圈內說法整理，不僞裝成親身體驗

## 爲什麼歡迎 PR

這類列表靠一個人肯定會錯

有些社區外人只能看到門口，看不到真實氛圍。有些論壇註冊規則會階段性開放，有些域名會漂，有些舊稱和新稱很容易混在一起

所以這個倉庫最需要的不是更漂亮的介紹，而是社區真實成員來修正

如果你是某個社區的老用戶，或者只是發現某個條目寫錯了，可以直接提 PR。最有價值的補充通常是這些：

- 註冊現在是開放、邀請制，還是階段性開放？
- 新人進去應該先看哪個版規或公告？
- 社區真實氛圍偏技術、偏灌水、偏交易，還是偏資源？
- 裏面最有價值的板塊是什麼？
- 入口是否變了，舊域名是否已經不穩定？
- 某些描述是否太像 AI 總結，需要改成真實用戶口吻？

如果不想提 PR，也可以直接在對應社區頁面下面留言。站點現在接了 Giscus，評論會落到 GitHub Discussions 裏

## 如何協助整理

新增或修改社區時，優先改倉庫裏的結構化數據：

```bash
data/communities.json
```

改完之後運行：

```bash
node scripts/generate-readme.mjs
node scripts/build-site.mjs
```

前者會同步 README，後者會生成在線頁面

如果只是改分類說明，可以看：

```bash
docs/categories.md
```

如果是補充單個社區，最好同時給公開來源。來源可以是官網、註冊頁、站內公告、關於頁面、版規頁面，或者其它能公開訪問的說明

## 目前的整理原則

這個項目目前主要由 AI 根據公開資料、站點頁面和少量個人體驗整理。只有一部分社區是我真實長期進入體驗過的

所以我希望後面每個社區都能慢慢被真實用戶修過一遍

成人、資源、破解、逆向、安全、刷機、交易這些社區也會收，但會按大類寫清楚：裏面大概有什麼、適合觀察什麼、有什麼坑。具體是否進入、是否參與、怎麼判斷風險，都需要讀者自己負責

我現在更想把它做成一份能長期改的公共目錄，而不是一篇寫完就過時的博客文章

如果你發現有我沒寫到的論壇，或者某個條目寫得很外行，歡迎直接去倉庫提 PR：

[https://github.com/Amiyadesi/small-forums-list](https://github.com/Amiyadesi/small-forums-list)
