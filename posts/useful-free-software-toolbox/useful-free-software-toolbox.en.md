# NetEase UU Remote
Official website [https://uuyc.163.com/](https://uuyc.163.com/)

If you just want to remotely connect to your own computer, this is quite convenient. Install it, log in, bind your device, and you're good to go.

But don't enable unattended access for others casually.

# File Converter
Website [https://file-converter.io/](https://file-converter.io/)

An online file conversion site. It can handle image, document, audio, video, and other format conversions.

It's great for temporary emergencies, but don't upload sensitive files to sites like this.

# LocalSend
Official website [https://localsend.org/zh-CN](https://localsend.org/zh-CN)

This is very comfortable for cross-device file transfers. It supports Windows, Android, Linux, and more, allowing direct transfers within the local network.

If you often transfer files to yourself via WeChat, I recommend giving this a try.

# Obsidian
Official website [https://obsidian.md/](https://obsidian.md/)

A local note-taking software where notes are just plain Markdown files, which I've always liked.

Many of my articles are first written in Obsidian before being organized for the blog.

# OBS
Official website [https://obsproject.com/](https://obsproject.com/)

It's pretty much indispensable for recording videos and live streaming. It's free and powerful enough.

After the first installation, remember to record ten seconds to check the screen and microphone, otherwise, you might end up recording nothing useful.

# Aseprite
Official website [https://www.aseprite.org/](https://www.aseprite.org/)

Great for drawing pixel art and making pixel animations, and it's a common recommendation.

The official installer is paid. If you mind, you can compile it yourself, for example, using this repository: [a1393323447/aseprite-builder](https://github.com/a1393323447/aseprite-builder)
