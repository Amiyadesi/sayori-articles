이 글에는 소프트웨어만 담았습니다.

브라우저 확장 프로그램은 [[useful-browser-extensions-toolbox|무료 유용한 브라우저 확장 프로그램 목록]]을 참고하세요.

사이트 내 관련 글은 [[site-article-index|본 사이트 글 색인]]을 참고하세요.

# 넷이즈 UU 원격
공식 홈페이지 [https://uuyc.163.com/](https://uuyc.163.com/)

그냥 내 컴퓨터에 원격으로 접속하고 싶을 때 정말 간편합니다. 설치하고 로그인해서 기기 연동만 하면 바로 쓸 수 있어요.

하지만 다른 사람에게 무인 원격 접속을 함부로 열어주지는 마세요.

# File Converter
웹페이지 [https://file-converter.io/](https://file-converter.io/)

온라인 파일 변환 사이트입니다. 이미지, 문서, 오디오, 비디오 같은 포맷 변환이 필요할 때 대타로 쓰기 좋습니다.

급할 때 임시로 쓰기엔 아주 편하지만, 민감한 파일은 이런 사이트에 올리지 마세요.

# LocalSend
공식 홈페이지 [https://localsend.org/zh-CN](https://localsend.org/zh-CN)

기기 간에 파일을 전송할 때 아주 편합니다. Windows, 안드로이드, Linux 등에서 서로 주고받을 수 있고 로컬 네트워크 안에서 바로 보낼 수 있어요.

만약 카카오톡이나 위챗으로 나 자신에게 파일을 자주 보낸다면, 이거 하나 설치해 보는 걸 추천합니다.

# Obsidian
공식 홈페이지 [https://obsidian.md/](https://obsidian.md/)

로컬 노트 앱입니다. 노트가 일반 Markdown 파일이라는 점이 전 예전부터 참 마음에 들더라고요.

지금 제 글 중 상당수도 Obsidian에서 먼저 쓴 다음에 블로그에 천천히 정리해 올리고 있습니다.

# OBS
공식 홈페이지 [https://obsproject.com/](https://obsproject.com/)

영상을 녹화하거나 방송을 켤 때 거의 필수적으로 거쳐 가는 프로그램입니다. 무료이면서도 성능이 확실하죠.

처음 설치가 끝나면 화면과 마이크가 잘 나오는지 10초 정도 먼저 녹화해 보세요. 안 그러면 헛고생하기 딱 좋습니다.

# Aseprite
공식 홈페이지 [https://www.aseprite.org/](https://www.aseprite.org/)

픽셀 아트를 그리고 픽셀 애니메이션을 만들 때 아주 좋습니다. 다들 기본으로 한 번씩 언급하는 프로그램이기도 해요.

공식 설치 파일은 유료입니다. 신경 쓰인다면 직접 컴파일해서 쓸 수도 있는데, 예를 들어 이 저장소[a1393323447/aseprite-builder](https://github.com/a1393323447/aseprite-builder)를 참고해 보세요.

## 계속 읽기

Obsidian으로 작성한 노트는 [[fast-note-sync-on-student-server|Fast Note Sync]]를 사용해 기기 간에 동기화할 수 있고, 공개 글러 발행하고 싶다면 [[astro-mizuki-blog-from-zero|제로베이스 블로그 구축]]을 계속 읽어보세요.

저처럼 Aseprite로 게임 리소스를 만들고 계신다면, [[godot-useful-plugins|제가 자주 쓰는 Godot 플러그인]]도 가볍게 참고해서 리소스를 가지고 놀 수 있는 무언가로 마저 만들어 보세요.
