# 网易 UU 远程
Site officiel [https://uuyc.163.com/](https://uuyc.163.com/)

Si vous voulez juste prendre la main à distance sur votre propre PC, c'est franchement pratique : on installe, on se connecte, on associe l'appareil et c'est parti.

Mais n'activez pas l'accès sans surveillance à la légère pour n'importe qui.

# File Converter
Site web [https://file-converter.io/](https://file-converter.io/)

Un convertisseur de fichiers en ligne qui peut dépanner pour les images, documents, audio, vidéo et compagnie.

Très pratique pour un dépannage rapide, mais évitez d'y envoyer des fichiers sensibles.

# LocalSend
Site officiel [https://localsend.org/zh-CN](https://localsend.org/zh-CN)

Super agréable pour transférer des fichiers entre appareils : Windows, Android, Linux s'envoient des trucs directement en réseau local.

Si vous vous envoyez souvent des fichiers via WeChat, ça vaut le coup d'essayer de l'installer.

# Obsidian
Site officiel [https://obsidian.md/](https://obsidian.md/)

Une appli de notes en local où les notes sont de simples fichiers Markdown — ce point m'a toujours bien plu.

En ce moment, j'écris d'ailleurs beaucoup de mes articles d'abord dans Obsidian avant de les mettre au propre pour le blog.

# OBS
Site officiel [https://obsproject.com/](https://obsproject.com/)

Difficile de passer à côté pour enregistrer des vidéos ou lancer un live : c'est gratuit et largement à la hauteur.

Après la première installation, pensez à enregistrer dix secondes pour vérifier l'image et le micro, sinon on a vite fait d'enregistrer dans le vide.

# Aseprite
Site officiel [https://www.aseprite.org/](https://www.aseprite.org/)

Très pratique pour le pixel art et l'animation en pixel, et c'est aussi celui que beaucoup citent par réflexe.

L'installateur officiel est payant ; si ça vous gêne, vous pouvez le compiler vous-même, par exemple avec ce dépôt [a1393323447/aseprite-builder](https://github.com/a1393323447/aseprite-builder)

## Pour aller plus loin

Les notes écrites dans Obsidian peuvent être synchronisées entre appareils avec [[fast-note-sync-on-student-server|Fast Note Sync]], et si vous voulez en faire des articles publics, jetez un œil à [[astro-mizuki-blog-from-zero|Monter un blog de zéro]]

Si, comme moi, vous utilisez Aseprite pour dessiner des assets de jeu, vous pouvez aussi regarder [[godot-useful-plugins|Mes plugins Godot habituels]] pour transformer tout ça en quelque chose de jouable.
