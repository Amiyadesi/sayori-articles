# 网易 UU 远程
Sitio oficial [https://uuyc.163.com/](https://uuyc.163.com/)

Si solo quieres conectarte en remoto a tu propia computadora, la verdad es que ahorra bastante lío: instalas, inicias sesión, vinculas el equipo y listo.

Eso sí, no actives el acceso desatendido para cualquiera así como así.

# File Converter
Web [https://file-converter.io/](https://file-converter.io/)

Un conversor de archivos online que saca del apuro para cambiar formatos de imágenes, documentos, audio, video y cosas por el estilo.

Muy práctico para emergencias puntuales, pero no subas archivos sensibles a sitios así.

# LocalSend
Sitio oficial [https://localsend.org/zh-CN](https://localsend.org/zh-CN)

Va súper cómodo para pasar archivos entre dispositivos: Windows, Android, Linux y compañía se envían cosas entre sí directo por la red local.

Si sueles mandarte archivos por WeChat a ti mismo, te recomiendo probarlo.

# Obsidian
Sitio oficial [https://obsidian.md/](https://obsidian.md/)

App de notas en local donde las notas son simples archivos Markdown, algo que siempre me ha gustado bastante.

Hoy en día también escribo muchos artículos primero en Obsidian y luego los voy puliendo para el blog.

# OBS
Sitio oficial [https://obsproject.com/](https://obsproject.com/)

Para grabar video o hacer directos es casi inevitable; es gratis y rinde de sobra.

Cuando lo instales por primera vez, acuérdate de grabar diez segundos antes para revisar imagen y micrófono, si no es fácil grabarlo todo en vano.

# Aseprite
Sitio oficial [https://www.aseprite.org/](https://www.aseprite.org/)

Muy bueno para pixel art y animaciones en píxeles, y también uno de los que casi todo el mundo menciona por defecto.

El instalador oficial es de pago; si te pesa, puedes compilarlo tú mismo, por ejemplo usando este repo [a1393323447/aseprite-builder](https://github.com/a1393323447/aseprite-builder)
