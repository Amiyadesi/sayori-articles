# 网易 UU 远程
Site oficial [https://uuyc.163.com/](https://uuyc.163.com/)

Se você só quer acessar seu próprio computador remotamente, ele quebra um galho enorme: instalou, logou, vinculou os dispositivos e já era

Só não saia ativando acesso sem supervisão para qualquer um

# File Converter
Página [https://file-converter.io/](https://file-converter.io/)

Um conversor de arquivos online que dá conta do recado para converter formatos de imagem, documento, áudio, vídeo e afins

Ótimo para apagar incêndio na hora, mas não jogue arquivo sensível nesse tipo de site

# LocalSend
Site oficial [https://localsend.org/zh-CN](https://localsend.org/zh-CN)

Muito bom para mandar arquivo entre aparelhos — funciona bem entre Windows, Android, Linux e companhia, direto na rede local

Se você vive mandando arquivo para si mesmo no WeChat, vale a pena testar

# Obsidian
Site oficial [https://obsidian.md/](https://obsidian.md/)

App de notas local em que cada nota é só um arquivo Markdown comum — algo que eu sempre curti bastante

Hoje em dia boa parte dos meus textos também começa no Obsidian, para depois ir virando post aos poucos

# OBS
Site oficial [https://obsproject.com/](https://obsproject.com/)

Para gravar vídeo ou fazer live, quase sempre acaba caindo nele: é gratuito e dá conta com folga

Assim que instalar pela primeira vez, lembre de gravar uns dez segundos para checar imagem e microfone, senão é bem fácil perder a gravação à toa

# Aseprite
Site oficial [https://www.aseprite.org/](https://www.aseprite.org/)

Muito bom para pixel art e animação em pixel, daqueles que o pessoal costuma lembrar de cara

O instalador oficial é pago; se isso pesar para você, dá para compilar na mão, tipo usando o repositório [a1393323447/aseprite-builder](https://github.com/a1393323447/aseprite-builder)
