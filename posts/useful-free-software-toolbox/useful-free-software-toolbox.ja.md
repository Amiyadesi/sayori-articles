# 网易 UU 远程
公式サイト [https://uuyc.163.com/](https://uuyc.163.com/)

自分のPCにちょっとリモート接続したいだけなら、正直かなり手軽。入れてログインして端末を紐づければすぐ使える

ただし、他人に無人アクセスを安易に渡すのはやめておいたほうがいい

# File Converter
Webページ [https://file-converter.io/](https://file-converter.io/)

オンラインのファイル変換サイト。画像やドキュメント、音声、動画などのフォーマット変換をこれでサッと済ませられる

ちょっとした緊急回避にはすごく便利だけど、機密性の高いファイルはこういうサイトに上げないこと

# LocalSend
公式サイト [https://localsend.org/zh-CN](https://localsend.org/zh-CN)

端末をまたいだファイル送信がかなり快適。Windows、Android、Linux などの間でローカルネットワーク経由で直接送れる

普段 WeChat とかで自分にファイルを送りがちなら、一回入れてみるのをすすめたい

# Obsidian
公式サイト [https://obsidian.md/](https://obsidian.md/)

ローカルのメモアプリ。ノートがただの Markdown ファイルとして保存されるところがずっと気に入っている

今の自分も、記事の多くはまず Obsidian に書いてから、少しずつブログ用に整えている

# OBS
公式サイト [https://obsproject.com/](https://obsproject.com/)

録画や配信をするならまず外せない存在。無料で、実用面も十分すぎる

最初にインストールしたら、まずは10秒だけ録画して画面とマイクを確認しておくのがおすすめ。そうしないと録り直しになりがち

# Aseprite
公式サイト [https://www.aseprite.org/](https://www.aseprite.org/)

ドット絵やピクセルアニメを描くのにすごく使いやすく、定番として挙がりやすい一本

公式インストーラーは有料なので、気になるなら自分でビルドする手もある。たとえばこのリポジトリ [a1393323447/aseprite-builder](https://github.com/a1393323447/aseprite-builder) を使うとか

## 続きを読む

Obsidian で書いたメモは [[fast-note-sync-on-student-server|Fast Note Sync]] で複数端末に同期でき、記事として公開したいなら [[astro-mizuki-blog-from-zero|ゼロからブログを作る]] も続けてどうぞ

自分と同じく Aseprite でゲーム素材を描いているなら、[[godot-useful-plugins|よく使う Godot プラグイン]] もついでに見て、素材を遊べる形にしていくのもあり
