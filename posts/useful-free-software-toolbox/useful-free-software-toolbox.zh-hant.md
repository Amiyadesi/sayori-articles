# 網易 UU 遠程
官網 [https://uuyc.163.com/](https://uuyc.163.com/)

如果你只是想遠程連一下自己電腦，這個確實挺省事，裝完登錄綁定設備就能用

但不要隨便給別人開無人值守

# File Converter
網頁 [https://file-converter.io/](https://file-converter.io/)

一個在線文件轉換站，圖片、文檔、音頻、視頻之類的格式轉換都能拿它頂一下

臨時救急很好用，但敏感文件別往這種網站傳

# LocalSend
官網 [https://localsend.org/zh-CN](https://localsend.org/zh-CN)

這個拿來跨端傳文件很舒服，Windows、安卓、Linux 這些都能互傳，局域網內直接發

如果你經常微信傳文件給自己，建議裝一個試試

# Obsidian
官網 [https://obsidian.md/](https://obsidian.md/)

本地筆記軟件，筆記就是普通 Markdown 文件，這點我一直挺喜歡

我現在很多文章也是先在 Obsidian 裏寫，再慢慢整理到博客

# OBS
官網 [https://obsproject.com/](https://obsproject.com/)

錄視頻和開直播基本繞不過它，免費，而且足夠能打

第一次裝好後記得先錄十秒看看畫面和麥克風，不然很容易白錄

# Aseprite
官網 [https://www.aseprite.org/](https://www.aseprite.org/)

畫像素畫和做像素動畫很好用，也是很多人默認會提的一款

官方安裝包是付費的，介意的話可以自己編譯，比如用這個倉庫[a1393323447/aseprite-builder](https://github.com/a1393323447/aseprite-builder)
