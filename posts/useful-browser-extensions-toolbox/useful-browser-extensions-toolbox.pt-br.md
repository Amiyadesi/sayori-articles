# O que são extensões

![[Pasted image 20260703114150.png|width=560|align=center|caption=浏览器插件入口]]
É só clicar naquela peça de quebra-cabeça ali na direita para ir à loja de extensões e baixar. Falando de forma simples, uma extensão de navegador é um trecho extra de script injetado na página, então ela consegue fazer muita coisa. Por isso, é melhor não baixar extensões de origem duvidosa; dê preferência às mais oficiais — o que tem na loja já dá conta do recado.

# AdGuard
![[Pasted image 20260703123311.png|width=520|align=center|caption=AdGuard 插件面板]]
Dá para baixar direto na loja oficial de extensões. É um bloqueador de anúncios absurdamente bom, praticamente item obrigatório no navegador. Depois de instalar, dá para deixar ligado direto sem precisar mexer em nada.

# Tampermonkey
O famosíssimo Tampermonkey dispensa apresentações — é praticamente uma extensão para rodar extensões personalizadas. [https://www.youxiaohou.com/](https://www.youxiaohou.com/), recomendo usar os recursos desse site para baixar vários scripts e afins. Deixo aqui um que uso bastante: [hmjz100/LinkSwift: Uma ferramenta baseada em JavaScript para obter links diretos de download de discos na nuvem. Modificada a partir do 【网盘直链下载助手】, com suporte a oito serviços: Baidu Netdisk / Aliyun Drive / China Mobile Cloud / Tianyi Cloud / Xunlei Cloud / Quark Cloud / UC Cloud / 123 Cloud](https://github.com/hmjz100/LinkSwift), além de vários outros scripts práticos. E, como estudante, dá para fazer muita coisa com isso, mas não vou entrar em detalhes, hehe.

# ~~Immersive Translate~~ —— Read Frog 🐸
![[Pasted image 20260718200848.png|width=560|align=center|caption=陪读蛙插件]]
Você encontra na loja de extensões; é muito confortável para fazer tradução bilíngue e coisas do tipo, e os canais gratuitos que já vêm nele são bem decentes. Se você for mais exigente, dá para colocar créditos na API oficial do DeepSeek ou usar os [[anyrouter-sharedchat-cc-switch-student-guide|créditos oficiais de IA para estudantes]] para conectar um modelo grande e traduzir de forma estável por bastante tempo.

Recentemente testei o Read Frog e descobri que tradução pode ser tão rápida assim! Immersive Translate, quem é você? Nem conheço, não atrapalhe a minha vida feliz com o Read Frog.

# Bitwarden
![[Pasted image 20260703121438.png|width=560|align=center|caption=Bitwarden 插件]]
Também está na loja de extensões. Os recursos nativos já permitem salvar identidades, cartões bancários, senhas, contas e chaves de acesso (passkeys), além de preencher tudo automaticamente. Dá para dizer que é item essencial para sobreviver na internet: quanto antes você começar a usar, melhor — depois que pega o jeito, não larga mais. Para um nível mais avançado com salvamento de 2FA, recomendo hospedar seu próprio Vaultwarden [[selfhost-vaultwarden-on-2c2g|hospedar seu próprio Vaultwarden]], ou procurar algum pronto, como o da [[disroot-open-services-note|Apresentação do Disroot]], uma organização que oferece Vaultwarden gratuito.
