# Was sind Erweiterungen?

![[Pasted image 20260703114150.png|width=560|align=center|caption=浏览器插件入口]]
Klick einfach auf das Puzzleteil rechts, um zum Add-on-Store zu gelangen und sie herunterzuladen. Kurz gesagt sind Browser-Erweiterungen einfach zusätzliche Skripte, die in Webseiten eingefügt werden. Deshalb können sie eine ganze Menge anstellen – aus unbekannten Quellen sollte man sie also besser nicht installieren. Haltet euch lieber an seriöse Anbieter, die Sachen aus den offiziellen Stores reichen völlig aus.

# AdGuard
![[Pasted image 20260703123311.png|width=520|align=center|caption=AdGuard 插件面板]]
Gibt es direkt im offiziellen Add-on-Store – ein extrem guter Werbeblocker und quasi ein Muss für jeden Browser. Einmal installiert, kann man ihn im Grunde einfach dauerhaft laufen lassen, ohne sich weiter drum zu kümmern.

# Tampermonkey
Den legendären Tampermonkey-Skriptmanager muss man wohl kaum noch vorstellen – das ist quasi die Erweiterung für benutzerdefinierte Erweiterungen. Unter [https://www.youxiaohou.com/](https://www.youxiaohou.com/) findet ihr jede Menge Skripte und andere Ressourcen zum Herunterladen. Hier noch eines, das ich selbst ziemlich oft nutze: [hmjz100/LinkSwift: Ein JavaScript-basiertes Tool zum Abrufen von Download-Links für Cloud-Speicher. Basiert auf „网盘直链下载助手“ und unterstützt die acht großen Cloud-Dienste Baidu Netdisk / Aliyun Drive / China Mobile Cloud / Tianyi Cloud / Xunlei Cloud / Quark Cloud / UC Cloud / 123 Cloud](https://github.com/hmjz100/LinkSwift). Dazu gibt es noch unzählige weitere praktische Skripte – und als Student kann man damit auch so einiges anstellen, aber dazu sage ich mal nichts weiter, hehe.

# ~~Immersive Translate~~——Read Frog 🐸
![[Pasted image 20260718200848.png|width=560|align=center|caption=陪读蛙插件]]
Gibt es im Add-on-Store und ist für zweisprachige Übersetzungen echt angenehm – schon die kostenlosen Standard-Quellen taugen was. Wer höhere Ansprüche hat, kann sich Guthaben für die offizielle DeepSeek-API aufladen oder über [[anyrouter-sharedchat-cc-switch-student-guide|offizielle KI-Kontingente für Studierende]] ein großes Sprachmodell anbinden, das läuft dann ewig stabil.

Neulich habe ich Read Frog ausprobiert und erst da gemerkt, wie unfassbar schnell Übersetzungen sein können! Immersive Translate, wer bist du? Kenn ich nicht, stör bitte nicht mein glückliches Zusammenleben mit Read Frog.

# Bitwarden
![[Pasted image 20260703121438.png|width=560|align=center|caption=Bitwarden 插件]]
Ebenfalls im Add-on-Store zu finden. Schon die integrierten Funktionen speichern Identitäten, Bankkarten, Passwörter, Konten sowie Passkeys und füllen alles automatisch aus – für jeden, der sich im Internet herumtreibt, ein absolutes Muss. Je früher man damit anfängt, desto besser; hat man es einmal genutzt, kommt man nicht mehr davon los. Für fortgeschrittene 2FA-Speicherung empfiehlt es sich, selbst eine Vaultwarden-Instanz aufzusetzen [[selfhost-vaultwarden-on-2c2g|Vaultwarden selbst hosten]] oder sich eine zu suchen – die Organisation [[disroot-open-services-note|Vorstellung von Disroot]] bietet zum Beispiel kostenloses Vaultwarden an.

# GlobalSpeed
![[Pasted image 20260703121741.png|width=560|align=center|caption=GlobalSpeed 插件]]
Gibt es auch im Add-on-Store, damit lässt sich die Wiedergabegeschwindigkeit bequem anpassen – ~~sehr praktisch, um Online-Kurse durchzurattern (hust)~~.

# ALL API HUB
![[Pasted image 20260703123412.png|width=560|align=center|caption=ALL API HUB 插件]]
Bündelt verschiedene new-api-Seiten, übernimmt den täglichen Check-in automatisch und zeigt das Guthaben an – endlich muss man sich nicht mehr jeden Tag mühsam selbst einloggen und abholen.

# Superpower Chatgpt
![[Pasted image 20260703125251.png|width=560|align=center|caption=Superpower ChatGPT 插件]]
[https://spchatgpt.com/](https://spchatgpt.com/), hier geht es zur Website. Nach der Installation kann man endlich mit Enter einen Zeilenumbruch machen und mit Strg+Enter absenden! Außerdem lässt sich ein erweiterter Modell-Umschalter für eigene Modelle aktivieren, und die üblichen Features wie Chat-Export, Kategorisierung oder das Speichern von Prompts sind auch alle mit dabei.
