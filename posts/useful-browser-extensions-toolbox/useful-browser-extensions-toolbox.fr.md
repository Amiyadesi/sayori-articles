# Qu'est-ce qu'une extension ?

![[Pasted image 20260703114150.png|width=560|align=center|caption=浏览器插件入口]]
En cliquant sur l'icône en forme de pièce de puzzle à droite, vous accédez à la boutique d'extensions pour les télécharger. En gros, une extension de navigateur est un bout de script supplémentaire injecté dans la page, ce qui lui permet de faire plein de choses. Il vaut donc mieux éviter d'en télécharger d'origines douteuses et s'en tenir aux plus fiables — celles des boutiques officielles suffisent largement.

# AdGuard
![[Pasted image 20260703123311.png|width=520|align=center|caption=AdGuard 插件面板]]
Téléchargeable directement depuis la boutique officielle d'extensions. C'est un bloqueur de publicités super efficace, carrément indispensable sur un navigateur. Une fois installé, on le laisse tourner en arrière-plan sans pratiquement jamais y toucher.

# Tampermonkey
Plus besoin de présenter le célèbre Tampermonkey : c'est un peu l'extension ultime pour personnaliser son navigateur avec des scripts. [https://www.youxiaohou.com/](https://www.youxiaohou.com/), je vous recommande de passer par les ressources de ce site pour télécharger toutes sortes de scripts et autres outils. Voici celui que j'utilise le plus : [hmjz100/LinkSwift : un outil en JavaScript pour récupérer les liens de téléchargement de fichiers sur les clouds. Basé sur « 网盘直链下载助手 », compatible avec Baidu Netdisk / Aliyun Drive / China Mobile Cloud / Tianyi Cloud / Xunlei Cloud / Quark Cloud / UC Cloud / 123 Cloud](https://github.com/hmjz100/LinkSwift). Il existe plein d'autres scripts bien pratiques, et en tant qu'étudiant, on peut faire énormément de choses avec — je n'en dis pas plus, héhé.

# ~~Immersive Translate~~ —— Read Frog 🐸
![[Pasted image 20260718200848.png|width=560|align=center|caption=陪读蛙插件]]
Disponible dans la boutique d'extensions, très agréable pour la traduction bilingue, avec des services gratuits intégrés déjà très corrects. Si vous êtes plus exigeant, vous pouvez recharger l'API officielle de DeepSeek ou utiliser [[anyrouter-sharedchat-cc-switch-student-guide|les crédits IA officiels pour étudiants]] pour brancher un grand modèle de langage et traduire tranquillement pendant longtemps.

J'ai récemment testé Read Frog, et je viens seulement de réaliser qu'une traduction pouvait être aussi rapide ! Immersive Translate, c'est qui ? Je connais pas, ne venez pas troubler ma petite vie avec Read Frog.

# Bitwarden
![[Pasted image 20260703121438.png|width=560|align=center|caption=Bitwarden 插件]]
Également disponible dans la boutique d'extensions. Ses fonctions intégrées permettent déjà d'enregistrer vos identités, cartes bancaires, identifiants et clés d'accès (passkeys), avec remplissage automatique. C'est vraiment un indispensable pour traîner sur Internet : plus tôt on s'y met, mieux c'est, et une fois adopté, impossible de s'en passer. Pour la gestion avancée de la double authentification (2FA), je recommande d'auto-héberger votre propre instance Vaultwarden [[selfhost-vaultwarden-on-2c2g|Auto-héberger son propre Vaultwarden]], ou d'en trouver une gratuite, par exemple chez [[disroot-open-services-note|Présentation de Disroot]], qui propose un Vaultwarden gratuit.

# GlobalSpeed
![[Pasted image 20260703121741.png|width=560|align=center|caption=GlobalSpeed 插件]]
Aussi disponible sur la boutique d'extensions. Permet de régler facilement la vitesse de lecture, ~~super pratique pour expédier les cours en ligne (tousse)~~.

# SimilarSites
![[Pasted image 20260703122818.png|width=560|align=center|caption=SimilarSites 插件]]
[Similarsites.com - Easily Explore alternative websites](https://www.similarsites.com/), téléchargeable ici.
Si on reprend l'exemple du site de scripts mentionné plus haut, cette extension permet de dénicher d'autres sites similaires et intéressants, idéal pour trouver de meilleures ressources et explorer le web.

# ALL API HUB
![[Pasted image 20260703123412.png|width=560|align=center|caption=ALL API HUB 插件]]
Regroupe vos sites basés sur new-api et gère automatiquement les pointages quotidiens ainsi que le suivi des soldes. Enfin fini la corvée de se connecter chaque jour pour réclamer ses crédits !

# Superpower Chatgpt
![[Pasted image 20260703125251.png|width=560|align=center|caption=Superpower ChatGPT 插件]]
[https://spchatgpt.com/](https://spchatgpt.com/), le site est ici. Une fois installé, on peut enfin faire un saut de ligne avec Entrée et envoyer le message avec Ctrl+Entrée ! On peut aussi activer le sélecteur de modèles avancé pour ajouter des modèles personnalisés, sans oublier les fonctions habituelles comme l'export de conversations, le classement et la sauvegarde de prompts.
