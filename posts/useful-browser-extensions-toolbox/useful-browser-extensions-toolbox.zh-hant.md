# 插件是什麼

![[Pasted image 20260703114150.png|width=560|align=center|caption=浏览器插件入口]]
點擊右邊的那個碎片就可以去插件商店下載了，瀏覽器插件簡單來說就是一段額外的插入頁面的腳本，所以能做到很多事情，所以來路不明的插件最好也不要下載，儘量下載一些比較正規的，商店裡的也夠用了

# AdGuard
![[Pasted image 20260703123311.png|width=520|align=center|caption=AdGuard 插件面板]]
在官方插件商店既可下載，超級好用的去廣告插件，瀏覽器必備堪稱，下載了後就可以一直開著不動了基本上

# Tampermonkey
大名鼎鼎的油猴腳本想必不用多說，這相當於插件中的自定義插件了，[https://www.youxiaohou.com/](https://www.youxiaohou.com/)，推薦可以通過這個網站裡面的資源下載各種腳本和其他，然後這裡給一個我用的比較多的[hmjz100/LinkSwift: 一個基於 JavaScript 的網盤文件下載地址獲取工具。基於【網盤直鏈下載助手】修改 ，支持 百度網盤 / 阿里雲盤 / 中國移動雲盤 / 天翼雲盤 / 迅雷雲盤 / 夸克網盤 / UC網盤 / 123雲盤 八大網盤](https://github.com/hmjz100/LinkSwift)，還有其他各種方便的腳本之類的，以及作為學生黨，用這個能做的事也很多，具體就不說了嘻嘻

# ~~沉浸式翻譯~~——陪讀蛙🐸
![[Pasted image 20260718200848.png|width=560|align=center|caption=陪读蛙插件]]
可以在插件商店找到，用於做雙語翻譯之類的很舒服，自帶的免費渠道就不錯。如果要求比較高，可以充值 DeepSeek 官方 API，或者用[[anyrouter-sharedchat-cc-switch-student-guide|官方學生 AI 額度]]接入大模型接口來翻譯，能夠穩定用很久

最近嘗試了陪讀蛙，才發現原來翻譯可以這麼快啊！沉浸式翻譯你是誰，我不認識，不要打擾我和陪讀蛙過日子了

# Bitwarden
![[Pasted image 20260703121438.png|width=560|align=center|caption=Bitwarden 插件]]
也可在插件商店找到，自帶的功能就可以實現保存身份和銀行卡和密碼賬戶還有通行密鑰，並且可以自動填寫，可以說是互聯網混跡必備了，越早接觸越好，接觸了就離不開了，然後進階的2FA保存推薦可以自己搭建一個vaultwarden[[selfhost-vaultwarden-on-2c2g|自己搭建一個vaultwarden]]，或者找一個，比如[[disroot-open-services-note|Disroot介紹]]這這個組織就有免費的vaultwarden

# GlobalSpeed
![[Pasted image 20260703121741.png|width=560|align=center|caption=GlobalSpeed 插件]]
也可在插件商店找到，可以方便的調節速率，~~對於刷課來說十分有用（霧）~~

# SimilarSites
![[Pasted image 20260703122818.png|width=560|align=center|caption=SimilarSites 插件]]
[Similarsites.com - Easily Explore alternative websites](https://www.similarsites.com/)，可以在這裡下載
拿上面的油小猴舉例子，就可以通過這個插件來探索更多類似有趣的網站了，能夠更好的找到資源和探索互聯網
