# Qué es una extensión

![[Pasted image 20260703114150.png|width=560|align=center|caption=浏览器插件入口]]
Haciendo clic en esa pieza de rompecabezas de la derecha puedes ir a la tienda de extensiones a descargarlas. En pocas palabras, una extensión de navegador es un fragmento de script adicional que se inserta en la página, por lo que puede hacer muchas cosas. Por eso mismo, mejor no descargar extensiones de origen dudoso; intenta instalar las que sean más oficiales o conocidas, con las de la tienda suele bastar.

# AdGuard
![[Pasted image 20260703123311.png|width=520|align=center|caption=AdGuard 插件面板]]
Se puede descargar directamente en la tienda oficial de extensiones. Es un bloqueador de anuncios buenísimo, casi imprescindible para cualquier navegador; una vez instalado, básicamente lo dejas encendido y te olvidas.

# Tampermonkey
El famosísimo gestor de scripts Tampermonkey no necesita mucha presentación, viene a ser como una extensión para personalizar extensiones, [https://www.youxiaohou.com/](https://www.youxiaohou.com/), recomiendo usar los recursos de esta web para descargar todo tipo de scripts y demás. Por aquí dejo uno que uso bastante: [hmjz100/LinkSwift: Una herramienta basada en JavaScript para obtener enlaces de descarga directa de servicios en la nube. Modificada a partir de 【网盘直链下载助手】, compatible con ocho grandes servicios: Baidu Netdisk / Aliyun Drive / China Mobile Cloud / Tianyi Cloud / Xunlei Cloud / Quark Cloud / UC Cloud / 123 Cloud](https://github.com/hmjz100/LinkSwift), además de otros scripts súper prácticos. Y siendo estudiante, se pueden hacer muchas cosas con esto, pero mejor no doy detalles, jeje.

# ~~Immersive Translate~~——Read Frog🐸
![[Pasted image 20260718200848.png|width=560|align=center|caption=陪读蛙插件]]
La encuentras en la tienda de extensiones y es comodísima para hacer traducciones bilingües y cosas por el estilo; los canales gratuitos que trae por defecto ya van bastante bien. Si eres más exigente, puedes recargar saldo en la API oficial de DeepSeek o usar los [[anyrouter-sharedchat-cc-switch-student-guide|créditos oficiales de IA para estudiantes]] para conectarla a modelos grandes y tener traducción estable para rato.

Hace poco probé Read Frog y me di cuenta de lo rápido que puede ir una traducción. ¿Immersive Translate? Quién te conoce, no me molestes mientras hago vida con Read Frog.

# Bitwarden
![[Pasted image 20260703121438.png|width=560|align=center|caption=Bitwarden 插件]]
También está en la tienda de extensiones. Sus funciones integradas permiten guardar identidades, tarjetas bancarias, cuentas con contraseña y llaves de acceso (passkeys), además de autocompletarlas. Se podría decir que es indispensable para sobrevivir en internet: cuanto antes lo empieces a usar, mejor, porque una vez lo pruebas ya no puedes vivir sin él. Para funciones avanzadas como guardar códigos 2FA, recomiendo montar tu propio servidor con [[selfhost-vaultwarden-on-2c2g|autoalojar Vaultwarden]], o buscar una instancia pública, por ejemplo la organización de [[disroot-open-services-note|presentación de Disroot]] ofrece Vaultwarden gratis.

# GlobalSpeed
![[Pasted image 20260703121741.png|width=560|align=center|caption=GlobalSpeed 插件]]
También disponible en la tienda de extensiones, permite ajustar la velocidad de reproducción muy cómodamente, ~~súper útil para pasarse rápido las clases online (ejem)~~.

# SimilarSites
![[Pasted image 20260703122818.png|width=560|align=center|caption=SimilarSites 插件]]
[Similarsites.com - Easily Explore alternative websites](https://www.similarsites.com/), se puede descargar aquí.
Tomando como ejemplo la web de scripts de arriba, con esta extensión puedes descubrir más páginas similares e interesantes, lo que ayuda mucho a encontrar buenos recursos y explorar internet.

# Superpower Chatgpt
![[Pasted image 20260703125251.png|width=560|align=center|caption=Superpower ChatGPT 插件]]
[https://spchatgpt.com/](https://spchatgpt.com/), aquí está su web. Al instalarla por fin puedes hacer saltos de línea con Enter y enviar con Ctrl+Enter.
