# What are Extensions?

![[Pasted image 20260703114150.png|width=560|align=center|caption=Browser Extension Entry Point]]
Clicking the puzzle piece on the right takes you to the extension store for downloads. Browser extensions are basically extra scripts injected into pages, so they can do a lot. That's why it's best not to download extensions from unknown sources; try to stick to more reputable ones. The ones in the store are usually sufficient.

# AdGuard
![[Pasted image 20260703123311.png|width=520|align=center|caption=AdGuard Extension Panel]]
Downloadable from the official extension store, this is a super useful ad-blocking extension, practically a browser essential. Once downloaded, you can pretty much just leave it on.

# Tampermonkey
Tampermonkey scripts, famous as they are, probably need no introduction. They're like custom extensions within extensions. [https://www.youxiaohou.com/](https://www.youxiaohou.com/) is a recommended site where you can download various scripts and more. Here's one I use quite often: [hmjz100/LinkSwift: A JavaScript-based tool for obtaining cloud drive file download links. Modified from [Cloud Drive Direct Link Download Assistant], supports Baidu Netdisk / Alibaba Cloud Drive / China Mobile Cloud Drive / Tianyi Cloud Drive / Xunlei Cloud Drive / Quark Cloud Drive / UC Cloud Drive / 123 Cloud Drive, eight major cloud drives](https://github.com/hmjz100/LinkSwift). There are also all sorts of other convenient scripts. And as a student, there's a lot you can do with this, but I won't go into details, hehe.

# Bitwarden
![[Pasted image 20260703121438.png|width=560|align=center|caption=Bitwarden Extension]]
Also found in the extension store, its built-in features allow you to save identities, bank cards, password accounts, and passkeys, and it can autofill them. It's practically essential for anyone navigating the internet. The sooner you start using it, the better; once you do, you won't be able to live without it. For advanced 2FA storage, I recommend self-hosting a Vaultwarden [[selfhost-vaultwarden-on-2c2g|Self-hosting a Vaultwarden]], or finding one, for example, the organization [[disroot-open-services-note|Disroot Introduction]] offers a free Vaultwarden.
