> **유지보수 중단**: 이 리소스 인덱스는 더 이상 업데이트되지 않으며, 아카이브 용도로만 남겨둡니다. 새로운 리소스와 이후 업데이트는 주로 [리소스 내비게이션 사이트](https://nav.sayori.org/)에 정리하고 있으니 그쪽을 확인해 주세요.

이 글은 Chrome / Edge 두 곳의 북마크 바에서 내보낸 공개 버전 리소스 인덱스로, 외부 창작 리소스와 도구 모음을 주로 다룹니다.

정리 규칙:

- 두 북마크 원본은 총 285개였고, URL 기준으로 중복을 제거해 212개가 되었습니다.
- 공개 버전에는 창작, 학습, 도구, 에셋, 커뮤니티 관련 링크만 남겼습니다.
- 라이선스 및 상업적 이용 제한은 각 사이트 해당 페이지의 안내를 기준으로 합니다. 에셋을 다운로드할 때는 제작자, 출처 URL, License, 다운로드 날짜를 따로 기록해 두는 것을 권장합니다.
