Les règles et les quotas gratuits peuvent changer, pensez à jeter un œil à la doc officielle avant de vous inscrire.

## Dépôts de listes GitHub
- [Free for Developers](https://free-for.dev/#/) : compilation de services gratuits pour développeurs, plus de 100k étoiles sur GitHub
- [awesome-cloudflare](https://github.com/zhuima/awesome-cloudflare) : compilation d'astuces avec Cloudflare, plus de 10k étoiles sur GitHub
- [sindresorhus/awesome: 😎 Awesome lists about all kinds of interesting topics](https://github.com/sindresorhus/awesome#readme) : la référence des listes awesome, plus de 400k étoiles sur GitHub

## Domaines gratuits et points d'entrée temporaires

- [DNSHE](https://my.dnshe.com/) : sous-domaine gratuit, pratique pour se faire la main sur le DNS
- [eu.org](https://nic.eu.org/) : domaine gratuit classique, mais la validation est souvent assez lente
- [us.kg](https://nic.us.kg/) : assez répandu aussi, vérifiez les règles actuelles avant de vous inscrire
- [pp.ua](https://nic.ua/) : l'un des anciens bons plans de domaine gratuit
- [GitHub Pages](https://pages.github.com/) : vous donne un `github.io`
- [Cloudflare Pages](https://pages.cloudflare.com/) : vous donne un `pages.dev`

Si vous débutez tout juste dans la création de site, ceux-là suffisent déjà largement pour bricoler un bon moment.

## Achat de nom de domaine officiel

- [Namesilo](https://www.namesilo.com/)
- [Porkbun](https://porkbun.com/)
- [Cloudflare Registrar](https://www.cloudflare.com/products/registrar/)

Perso, je regarde d'abord le prix de la première année et celui du renouvellement, sinon on se fait vite avoir par un tarif d'appel tout doux.

## Hébergement statique

- [Cloudflare Pages](https://pages.cloudflare.com/) : c'est celui que j'utilise en ce moment

- [Netlify](https://www.netlify.com/)
- [GitHub Pages](https://pages.github.com/)
- [Render](https://render.com/)

Pour un blog purement statique, Cloudflare Pages et GitHub Pages suffisent en général.
