Las reglas y las cuotas gratuitas pueden cambiar, así que échale un vistazo a la descripción de la página oficial antes de registrarte

## Repositorios de GitHub
- [Free for Developers](https://free-for.dev/#/): recopilación de servicios gratuitos para desarrolladores, más de 100 mil estrellas en GitHub
- [awesome-cloudflare](https://github.com/zhuima/awesome-cloudflare): recopilación de usos de Cloudflare, más de 10 mil estrellas en GitHub
- [sindresorhus/awesome: 😎 Awesome lists about all kinds of interesting topics](https://github.com/sindresorhus/awesome#readme): publicaciones de listas awesome, más de 400 mil estrellas en GitHub

## Dominios gratuitos y accesos temporales

- [DNSHE](https://my.dnshe.com/): subdominio gratuito, ideal para practicar con DNS primero
- [eu.org](https://nic.eu.org/): dominio gratuito clásico, aunque la revisión suele ser bastante lenta
- [us.kg](https://nic.us.kg/): también bastante común, revisa las reglas actuales antes de registrarte
- [pp.ua](https://nic.ua/): uno de los accesos a dominios gratuitos más veteranos
- [GitHub Pages](https://pages.github.com/): te dará un `github.io`
- [Cloudflare Pages](https://pages.cloudflare.com/): te dará un `pages.dev`

Si estás empezando a crear tu sitio web, con estos pocos tendrás entretenimiento para rato

## Registro de dominios oficiales

- [Namesilo](https://www.namesilo.com/)
- [Porkbun](https://porkbun.com/)
- [Cloudflare Registrar](https://www.cloudflare.com/products/registrar/)
