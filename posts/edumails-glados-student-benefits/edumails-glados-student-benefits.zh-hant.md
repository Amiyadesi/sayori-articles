## 先拿開發工具

[GitHub Student Developer Pack](https://education.github.com/pack) 放在第一位

認證通過後有 GitHub Pro 和一大批只能通過 GitHub 學生包領取的合作權益，登錄自己的 Pack 頁面看即可

[JetBrains 學生授權](https://www.jetbrains.com/community/education/#students) 如果你想體驗一下jetbrain家的東西也可以用教育郵箱來註冊看看了

Zed 這裡有兩個條件，GitHub 賬號要超過 30 天，學校郵箱域名在 [JetBrains/swot](https://github.com/JetBrains/swot) 裡

### Azure：每年 100 美元，先看資格

[Azure for Students](https://azure.microsoft.com/en-us/free/students/) 是最值得補上的一項，不用綁信用卡，100 美元可以在 12 個月內用於大部分 Azure 服務

“每年 100 美元”更準確的說法是：仍符合條件的學生，可以逐年續訂學生訂閱。需要重新確認資格，不保證到期自動發下一筆

[官方條款](https://azure.microsoft.com/en-us/pricing/offers/ms-azr-0170p/) 要求年滿 18 歲、就讀符合條件的全日制高校，並通過學校郵箱驗證。Azure for Students Starter 是另一種方案，不要把它當同樣的 100 美元套餐

適合拿來練一個小 API、課程項目或雲部署。地區、服務和資源配額仍有限制，不要理解成所有 AI 模型、GPU 或 Marketplace 商品都能買

額度用完後，學生訂閱會被禁用；主動升級到按量付費之後，賬單規則就變了

領取、免費規格和日區開機步驟放在 [[azure-students-100-credit-guide|Azure 學生服務器教程]]，網頁和 PowerShell 兩種方法都有

## GitHub Student Developer Pack 專屬權益（需通過學生包領取）

下面這些雲服務、開發環境、域名與課程都綁在 [GitHub Student Developer Pack](https://education.github.com/pack) 裡面，只有先通過 GitHub 學生認證才能激活：

### 1. Heroku：每月 13 美元，不是一口氣花 312 美元

[Heroku 學生入口和 FAQ](https://www.heroku.com/github-students) 要先通過 GitHub Student Developer Pack，並且年滿 18 歲

額度是每月 13 美元，持續 24 個月，合計最多 312 美元。沒用完的當月額度月底過期，不能攢到下個月，也不能再申請同一輪 24 個月權益。額度從獲批當月第一天開始算，月初申請更划算

可以抵扣 Heroku 自家的應用容器（Eco / Basic dynos）、Postgres 和 Key-Value Store，第三方付費 Add-ons 不在裡面

這個需要有效的信用卡或借記卡，超過每月抵扣額度的消費會直接扣款。適合跑一個輕量課程後端或小 API，不適合領完以後忘記賬單

### 2. MongoDB：50 美元數據庫額度，認證另算

[MongoDB 學生入口](https://www.mongodb.com/students) 通過 GitHub 學生認證領取，50 美元是 Atlas 數據庫額度，不是雲服務器額度

頁面說的 200 美元權益，是 50 美元 Atlas 額度加上標價 150 美元的認證權益，不能當成 200 美元數據庫餘額。認證需要先完成並通過對應學習路徑，不是領券就直接得到證書

兌換 Atlas 額度需要有效信用卡或 PayPal。兌換碼生成後 90 天內要應用到選定的組織，每個碼只能兌換一次；到賬後的到期日和使用範圍在 Billing 裡確認

只做小練習時，先看 Atlas 免費集群（M0）是否夠用，不必為了花額度立即升級付費集群

### 3. Codespaces 和 Camber：按用量算的開發環境

[Codespaces 計費說明](https://docs.github.com/en/billing/concepts/product-billing/github-codespaces) 的 Pro 檔是每月 180 核時與 20 GB-month 存儲，學生 Pack 直接提供 Pro 檔訪問

180 核時不是任意配置都能開 180 小時：2 核環境用一小時消耗 2 核時（約能運行 90 小時），4 核消耗 4 核時（約 45 小時），8 核消耗 8 核時（約 22.5 小時）

停止環境可以停止計算用量，但保留的環境仍佔存儲。用完不想佔存儲的 Codespace 記得先 `git push` 再刪掉環境。沒有綁定支付方式時超出配額會自動阻止繼續使用

[Camber 的學生權益](https://education.github.com/pack#cambercloud) 偏數據分析和 AI 實驗。官方 Pack 列出每月 40 CPU 小時、5 GPU 小時、50 GB 存儲、50 條 agent 消息。這不是固定型號 GPU 永久免費，具體規格和倍率看 [Camber 文檔](https://docs.cambercloud.com/) 和控制台

### 4. GitHub 學生包裡的 AI、域名與學習工具

- GitHub Copilot Student：已認證學生可申請，包含不限量代碼補全，以及有限的聊天、agent 和 GitHub AI Credits；模型通過自動選擇提供，不等於所有高級模型無限用
- Namecheap：一個 `.me` 域名首年註冊和一年 SSL 證書，續費不是永久免費
- Name.com：指定域名後綴中的免費首年域名，包含 `.app`、`.dev` 等；名稱、資格、續費價看領取和結算頁
- Educative：70 多門指定實操課程的 6 個月訪問，不是整個課程庫永久解鎖
- Boot.dev：完整互動會員 3 個月，適合集中學後端和 DevOps
- 1Password：個人會員 1 年，領取前看後續續費方式

### 5. 這些學生額度怎麼組合做一個真實項目

不用為了“價值幾百美元”把每一個限時權益同時激活。最穩的用法是先定一個能收尾的小項目（比如課程作業展示站、個人小 API 或工具），再按需領對應的一兩項：

- **前端展示 / 博客**：照著 [[astro-mizuki-blog-from-zero|簡潔博客教程]] 放到 Cloudflare Pages，再配一個 [[free-domain-and-web-community|免費域名]]
- **臨時寫代碼環境**：電腦配置不夠或多設備切換時開 GitHub Codespaces（2 核機器，用完隨手停機）
- **輕量後端 / 數據庫**：先用 MongoDB Atlas 免費層或 50 美元額度，後端選 Azure（不用信用卡）或 Heroku（每月 13 美元以內）
- **24 小時常駐自託管服務**：用 [[aliyun-student-300-voucher-guide|阿里雲學生券]] 或 [[azure-students-100-credit-guide|Azure 學生額度]] 開機，再按 [[2c2g-server-service-index|小服務器服務清單]] 挑一個用途
