### Azure: 100 USD al año, revisa primero los requisitos

[Azure for Students](https://azure.microsoft.com/en-us/free/students/) es uno de los beneficios que más merece la pena añadir: no pide vincular tarjeta de crédito y los 100 USD se pueden usar durante 12 meses en la mayoría de los servicios de Azure

La forma más precisa de entender esos "100 USD al año" es que los estudiantes que sigan cumpliendo los requisitos pueden renovar su suscripción estudiantil año tras año. Hay que volver a confirmar la elegibilidad y no está garantizado que al vencer te abonen automáticamente otra recarga

Los [términos oficiales](https://azure.microsoft.com/en-us/pricing/offers/ms-azr-0170p/) exigen tener al menos 18 años, cursar estudios a tiempo completo en una institución educativa elegible y verificarse mediante el correo universitario. Azure for Students Starter es otro plan distinto; no lo confundas con este paquete de 100 USD

Viene muy bien para practicar con una API pequeña, un proyecto de clase o un despliegue en la nube. Sigue habiendo límites de región, servicios y cuotas de recursos, así que no des por hecho que puedas comprar cualquier modelo de IA, GPU o producto del Marketplace

Cuando se agota el crédito, la suscripción estudiantil se desactiva; si decides pasarla manualmente a pago por uso, las reglas de facturación cambian por completo

Los pasos para reclamarlo, las especificaciones gratuitas y cómo levantar una instancia en la región de Japón están en [[azure-students-100-credit-guide|Tutorial del servidor estudiantil de Azure]], tanto por interfaz web como con PowerShell

## Beneficios exclusivos del GitHub Student Developer Pack (se reclaman a través del paquete)

Los siguientes servicios en la nube, entornos de desarrollo, dominios y cursos están vinculados al [GitHub Student Developer Pack](https://education.github.com/pack), y solo se pueden activar tras superar la verificación estudiantil de GitHub:

### 1. Heroku: 13 USD al mes, no 312 USD para gastar de golpe

El [portal estudiantil y FAQ de Heroku](https://www.heroku.com/github-students) exige haber aprobado primero el GitHub Student Developer Pack y tener al menos 18 años

El crédito es de 13 USD al mes durante 24 meses, hasta un máximo acumulado de 312 USD. Lo que no gastes dentro del mes caduca al terminar ese mes: no se acumula para el siguiente ni puedes volver a solicitar el mismo ciclo de 24 meses. El crédito empieza a contar desde el primer día del mes en que te lo aprueban, así que conviene pedirlo a principios de mes

Sirve para cubrir contenedores de aplicaciones propios de Heroku (Eco / Basic dynos), Postgres y Key-Value Store; los Add-ons de pago de terceros quedan fuera

Aquí sí necesitas una tarjeta de crédito o débito válida, y cualquier consumo que supere el crédito mensual se cargará directamente. Sirve para mantener un backend ligero de clase o una API pequeña, pero no para reclamarlo y olvidarte de la factura

### 2. MongoDB: 50 USD para base de datos; la certificación va aparte

El [portal estudiantil de MongoDB](https://www.mongodb.com/students) se reclama tras la verificación estudiantil de GitHub, y esos 50 USD son crédito para bases de datos Atlas, no crédito para servidores en la nube

Los 200 USD que menciona la página corresponden a 50 USD de crédito en Atlas más un beneficio de certificación valorado en 150 USD; no se puede tomar como un saldo de 200 USD para base de datos. Para la certificación hay que completar y aprobar primero la ruta de aprendizaje correspondiente; no te dan el certificado solo por canjear un cupón

Para canjear el crédito de Atlas necesitas una tarjeta de crédito válida o PayPal. Una vez generado el código, tienes 90 días para aplicarlo a la organización elegida, y cada código solo se canjea una vez; la fecha de caducidad y el alcance tras acreditarse se consultan en Billing

Si solo vas a hacer prácticas pequeñas, mira primero si te basta con el clúster gratuito de Atlas (M0); no hace falta saltar de inmediato a un clúster de pago solo por gastar el crédito

### 3. Codespaces y Camber: entornos de desarrollo medidos por consumo

Según la [documentación de facturación de Codespaces](https://docs.github.com/en/billing/concepts/product-billing/github-codespaces), el plan Pro incluye 180 horas-núcleo y 20 GB-mes de almacenamiento al mes, y el paquete estudiantil da acceso directo a ese nivel Pro

180 horas-núcleo no significan 180 horas con cualquier configuración: un entorno de 2 núcleos consume 2 horas-núcleo por cada hora de uso (da para unas 90 horas), uno de 4 núcleos consume 4 horas-núcleo (unas 45 horas) y uno de 8 núcleos consume 8 horas-núcleo (unas 22,5 horas)

Detener el entorno frena el consumo de cómputo, pero un entorno conservado sigue ocupando almacenamiento. Cuando termines con un Codespace y no quieras que consuma espacio, recuerda hacer primero `git push` y luego eliminar el entorno. Si no tienes un método de pago vinculado, al superar la cuota se bloquea automáticamente el uso adicional

Los [beneficios estudiantiles de Camber](https://education.github.com/pack#cambercloud) están más orientados al análisis de datos y experimentos de IA. La página oficial del Pack lista 40 horas de CPU, 5 horas de GPU, 50 GB de almacenamiento y 50 mensajes de agente al mes. Esto no equivale a tener un modelo concreto de GPU gratis de forma permanente; las especificaciones exactas y multiplicadores se consultan en la [documentación de Camber](https://docs.cambercloud.com/) y en su consola

### 4. IA, dominios y herramientas de aprendizaje dentro del GitHub Student Pack

- GitHub Copilot Student: disponible para estudiantes verificados; incluye autocompletado de código ilimitado junto con uso limitado de chat, agente y GitHub AI Credits; los modelos se asignan mediante selección automática, lo que no equivale a uso ilimitado de todos los modelos avanzados
- Namecheap: registro del primer año de un dominio `.me` y un certificado SSL por un año; la renovación no es gratuita de por vida
- Name.com: primer año gratuito para una selección de extensiones de dominio, incluidas `.app`, `.dev` y otras; el nombre, los requisitos y el precio de renovación se ven en las páginas de canje y pago
- Educative: 6 meses de acceso a más de 70 cursos prácticos seleccionados; no desbloquea de por vida todo el catálogo
- Boot.dev: 3 meses de membresía interactiva completa, ideal para estudiar backend y DevOps de forma intensiva
- 1Password: 1 año de membresía individual; revisa antes cómo funciona la renovación posterior

### 5. Cómo combinar estos créditos estudiantiles para sacar adelante un proyecto real

No hace falta activar a la vez todos los beneficios con límite de tiempo solo porque "valen varios cientos de dólares". Lo más sensato es definir primero un proyecto pequeño que puedas terminar (por ejemplo, una web de presentación para una asignatura, una API personal pequeña o una utilidad) y reclamar solo el par de cosas que realmente necesites:

- **Frontend / blog**: sigue el [[astro-mizuki-blog-from-zero|tutorial de blog minimalista]] para subirlo a Cloudflare Pages y añádele un [[free-domain-and-web-community|dominio gratuito]]
- **Entorno temporal para programar**: cuando tu ordenador se quede corto o cambies entre varios equipos, abre GitHub Codespaces (máquina de 2 núcleos, y acuérdate de detenerla al terminar)
- **Backend ligero / base de datos**: empieza con la capa gratuita de MongoDB Atlas o el crédito de 50 USD, y para el backend elige Azure (sin tarjeta de crédito) o Heroku (manteniéndote dentro de los 13 USD mensuales)
- **Servicios autoalojados 24/7**: levanta una máquina con el [[aliyun-student-300-voucher-guide|cupón estudiantil de Alibaba Cloud]] o el [[azure-students-100-credit-guide|crédito estudiantil de Azure]], y luego elige qué montar según esta [[2c2g-server-service-index|lista de servicios para servidores pequeños]]
