## 개발 도구부터 챙기기

[GitHub Student Developer Pack](https://education.github.com/pack)이 1순위다

인증을 통과하면 GitHub Pro는 물론이고 GitHub 학생 팩을 통해서만 받을 수 있는 수많은 제휴 혜택이 열린다. 본인 Pack 페이지에 로그인해서 확인하면 된다

[JetBrains 학생 라이선스](https://www.jetbrains.com/community/education/#students)는 JetBrains 제품군을 써 보고 싶다면 교육용 이메일로 등록해서 한번 경험해 볼 만하다

[Zed Education](https://zed.dev/education)도 신청해 봤는데, 1년짜리 Student 플랜을 받았고 Agent용으로 매달 10달러어치 토큰과 무제한 편집 예측 기능이 추가됐다

완전한 Pro 플랜은 아니라 Claude Opus는 빠져 있다

Zed는 조건이 두 가지 있다. GitHub 계정을 만든 지 30일이 넘어야 하고, 학교 이메일 도메인이 [JetBrains/swot](https://github.com/JetBrains/swot) 목록에 들어 있어야 한다

### Azure: 연간 100달러, 자격 조건부터 확인

[Azure for Students](https://azure.microsoft.com/en-us/free/students/)는 가장 먼저 챙길 만한 항목이다. 신용카드를 등록할 필요가 없고, 100달러 크레딧을 12개월 동안 대부분의 Azure 서비스에 쓸 수 있다

"연간 100달러"를 더 정확히 말하자면, 자격을 계속 충족하는 학생은 학생 구독을 매년 갱신할 수 있다는 뜻이다. 자격을 다시 인증해야 하며 만료 시 다음 크레딧이 자동으로 들어온다는 보장은 없다

[공식 약관](https://azure.microsoft.com/en-us/pricing/offers/ms-azr-0170p/)상 만 18세 이상이어야 하고, 조건에 맞는 정규 대학에 재학 중이며 학교 이메일 인증을 통과해야 한다. Azure for Students Starter는 다른 플랜이니 똑같은 100달러 패키지로 착각하면 안 된다

작은 API나 수업 프로젝트, 클라우드 배포 연습용으로 쓰기 좋다. 리전, 서비스, 리소스 할당량 제한이 여전히 존재하므로 모든 AI 모델이나 GPU, Marketplace 상품을 다 살 수 있다고 생각하면 곤란하다

크레딧을 다 쓰면 학생 구독은 비활성화된다. 직접 종량제(Pay-As-You-Go)로 업그레이드하는 순간부터는 과금 규칙이 달라진다

신청 방법, 무료 사양, 일본 리전 인스턴스 생성 과정은 [[azure-students-100-credit-guide|Azure 학생 서버 튜토리얼]]에 정리해 두었다. 웹 콘솔과 PowerShell 두 가지 방법 모두 있다

## GitHub Student Developer Pack 전용 혜택 (학생 팩을 거쳐야 신청 가능)

아래의 클라우드 서비스, 개발 환경, 도메인, 강의 혜택들은 모두 [GitHub Student Developer Pack](https://education.github.com/pack)에 묶여 있어서 GitHub 학생 인증을 먼저 통과해야 활성화할 수 있다:

### 1. Heroku: 매월 13달러씩 지급, 한 번에 312달러를 쓰는 구조가 아니다

[Heroku 학생 입구 및 FAQ](https://www.heroku.com/github-students)는 먼저 GitHub Student Developer Pack을 통과해야 하고 만 18세 이상이어야 한다

크레딧은 매월 13달러씩 24개월 동안 지급되어 합계 최대 312달러다. 그달에 다 쓰지 못한 크레딧은 월말에 소멸하며 다음 달로 이월되지 않는다. 같은 24개월 혜택을 다시 신청할 수도 없다. 크레딧은 승인된 달의 1일부터 계산되므로 월초에 신청하는 편이 이득이다

Heroku 자체 앱 컨테이너(Eco / Basic dynos), Postgres, Key-Value Store 비용을 차감할 수 있으며, 서드파티 유료 Add-ons는 제외된다

유효한 신용카드나 체크카드를 등록해야 하고, 월간 공제 한도를 넘겨 사용하면 바로 청구된다. 가벼운 수업용 백엔드나 작은 API를 돌리기엔 적당하지만, 받아 놓고 청구서를 까먹기 쉬운 사람에겐 맞지 않는다

### 2. MongoDB: 데이터베이스 크레딧 50달러, 자격증 혜택은 별도

[MongoDB 학생 입구](https://www.mongodb.com/students)에서 GitHub 학생 인증을 통해 받을 수 있다. 50달러는 Atlas 데이터베이스 크레딧이지 클라우드 서버 크레딧이 아니다

페이지에 적힌 200달러 혜택은 50달러 Atlas 크레딧에 정가 150달러 상당의 자격증 응시 혜택을 더한 금액이므로, 200달러어치 데이터베이스 잔액으로 생각하면 안 된다. 자격증 역시 해당 학습 경로를 먼저 수료하고 통과해야 하므로 쿠폰만 받는다고 바로 자격증이 나오지 않는다

Atlas 크레딧을 적용하려면 유효한 신용카드나 PayPal이 필요하다. 리딤 코드는 생성 후 90일 이내에 선택한 조직(Organization)에 적용해야 하며 코드당 1회만 사용할 수 있다. 등록 후 만료일과 사용 범위는 Billing 메뉴에서 확인한다

가벼운 연습만 할 생각이라면 먼저 Atlas 무료 클러스터(M0)로 충분한지 보고, 크레딧을 쓰겠다고 굳이 유료 클러스터로 바로 올릴 필요는 없다

### 3. Codespaces와 Camber: 사용량 기준으로 계산되는 개발 환경

[Codespaces 과금 안내](https://docs.github.com/en/billing/concepts/product-billing/github-codespaces) 기준 Pro 등급은 매월 180코어 시간과 20 GB-month 스토리지를 제공하며, 학생 Pack을 통해 Pro 등급을 바로 쓸 수 있다

180코어 시간이라고 해서 어떤 사양이든 180시간을 돌릴 수 있는 건 아니다. 2코어 환경을 1시간 쓰면 2코어 시간이 차감되고(약 90시간 실행 가능), 4코어는 4코어 시간(약 45시간), 8코어는 8코어 시간(약 22.5시간)이 소모된다

환경을 중지하면 연산 시간 차감은 멈추지만, 남겨 둔 환경은 계속 스토리지를 차지한다. 다 쓰고 나서 스토리지를 차지하지 않게 하려면 먼저 `git push` 한 다음 환경을 삭제해야 한다. 결제 수단을 등록하지 않은 상태라면 할당량을 초과할 때 자동으로 사용이 차단된다

[Camber의 학생 혜택](https://education.github.com/pack#cambercloud)은 데이터 분석과 AI 실험 쪽에 맞춰져 있다. 공식 Pack에는 매월 40 CPU 시간, 5 GPU 시간, 50 GB 스토리지, agent 메시지 50건이 명시되어 있다. 고정된 모델의 GPU를 평생 무료로 주는 게 아니니 구체적인 사양과 차감 배율은 [Camber 문서](https://docs.cambercloud.com/)와 콘솔에서 확인해야 한다

### 4. GitHub 학생 팩에 포함된 AI, 도메인, 학습 도구

- GitHub Copilot Student: 인증된 학생이 신청할 수 있으며, 무제한 코드 자동 완성과 제한된 횟수의 채팅, agent, GitHub AI Credits가 포함된다. 모델은 자동 선택으로 제공되므로 모든 상위 모델을 무제한으로 쓸 수 있는 건 아니다
- Namecheap: `.me` 도메인 첫해 등록 및 1년 SSL 인증서를 제공하며, 갱신 비용까지 평생 무료인 것은 아니다
- Name.com: 지정된 도메인 확장자 중 첫해 무료 도메인을 제공하며 `.app`, `.dev` 등이 포함된다. 도메인명, 자격 조건, 갱신 가격은 신청 및 결제 페이지에서 확인한다
- Educative: 지정된 70여 개 실습 강의에 대한 6개월 이용권으로, 전체 강의 라이브러리가 영구 해제되는 것은 아니다
- Boot.dev: 전체 인터랙티브 멤버십 3개월 이용권으로, 백엔드와 DevOps를 집중적으로 공부하기 좋다
- 1Password: 개인 멤버십 1년 이용권이며, 신청 전에 추후 갱신 방식을 확인해 두는 것이 좋다

### 5. 이 학생 크레딧들을 조합해 실제 프로젝트 하나 만들기

"수백 달러 가치"라는 말에 휩쓸려 기간 제한이 있는 혜택을 한꺼번에 다 활성화할 필요는 없다. 가장 안정적인 방법은 끝까지 마무리할 수 있는 작은 프로젝트(예: 수업 과제 전시 사이트, 개인용 소형 API나 툴)를 먼저 정한 뒤, 필요한 항목 한두 개만 골라 신청하는 것이다:

- **프론트엔드 전시 / 블로그**: [[astro-mizuki-blog-from-zero|심플 블로그 튜토리얼]]을 따라 Cloudflare Pages에 올리고 [[free-domain-and-web-community|무료 도메인]]을 연결한다
