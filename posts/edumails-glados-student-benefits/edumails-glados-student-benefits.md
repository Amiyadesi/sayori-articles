### Azure：每年 100 美元，先看资格

[Azure for Students](https://azure.microsoft.com/en-us/free/students/) 是最值得补上的一项，不用绑信用卡，100 美元可以在 12 个月内用于大部分 Azure 服务

“每年 100 美元”更准确的说法是：仍符合条件的学生，可以逐年续订学生订阅。需要重新确认资格，不保证到期自动发下一笔

[官方条款](https://azure.microsoft.com/en-us/pricing/offers/ms-azr-0170p/) 要求年满 18 岁、就读符合条件的全日制高校，并通过学校邮箱验证。Azure for Students Starter 是另一种方案，不要把它当同样的 100 美元套餐

适合拿来练一个小 API、课程项目或云部署。地区、服务和资源配额仍有限制，不要理解成所有 AI 模型、GPU 或 Marketplace 商品都能买

额度用完后，学生订阅会被禁用；主动升级到按量付费之后，账单规则就变了

领取、免费规格和日区开机步骤放在 [[azure-students-100-credit-guide|Azure 学生服务器教程]]，网页和 PowerShell 两种方法都有

## GitHub Student Developer Pack 专属权益（需通过学生包领取）

下面这些云服务、开发环境、域名与课程都绑在 [GitHub Student Developer Pack](https://education.github.com/pack) 里面，只有先通过 GitHub 学生认证才能激活：

### 1. Heroku：每月 13 美元，不是一口气花 312 美元

[Heroku 学生入口和 FAQ](https://www.heroku.com/github-students) 要先通过 GitHub Student Developer Pack，并且年满 18 岁

额度是每月 13 美元，持续 24 个月，合计最多 312 美元。没用完的当月额度月底过期，不能攒到下个月，也不能再申请同一轮 24 个月权益。额度从获批当月第一天开始算，月初申请更划算

可以抵扣 Heroku 自家的应用容器（Eco / Basic dynos）、Postgres 和 Key-Value Store，第三方付费 Add-ons 不在里面

这个需要有效的信用卡或借记卡，超过每月抵扣额度的消费会直接扣款。适合跑一个轻量课程后端或小 API，不适合领完以后忘记账单

### 2. MongoDB：50 美元数据库额度，认证另算

[MongoDB 学生入口](https://www.mongodb.com/students) 通过 GitHub 学生认证领取，50 美元是 Atlas 数据库额度，不是云服务器额度

页面说的 200 美元权益，是 50 美元 Atlas 额度加上标价 150 美元的认证权益，不能当成 200 美元数据库余额。认证需要先完成并通过对应学习路径，不是领券就直接得到证书

兑换 Atlas 额度需要有效信用卡或 PayPal。兑换码生成后 90 天内要应用到选定的组织，每个码只能兑换一次；到账后的到期日和使用范围在 Billing 里确认

只做小练习时，先看 Atlas 免费集群（M0）是否够用，不必为了花额度立即升级付费集群

### 3. Codespaces 和 Camber：按用量算的开发环境

[Codespaces 计费说明](https://docs.github.com/en/billing/concepts/product-billing/github-codespaces) 的 Pro 档是每月 180 核时与 20 GB-month 存储，学生 Pack 直接提供 Pro 档访问

180 核时不是任意配置都能开 180 小时：2 核环境用一小时消耗 2 核时（约能运行 90 小时），4 核消耗 4 核时（约 45 小时），8 核消耗 8 核时（约 22.5 小时）

停止环境可以停止计算用量，但保留的环境仍占存储。用完不想占存储的 Codespace 记得先 `git push` 再删掉环境。没有绑定支付方式时超出配额会自动阻止继续使用

[Camber 的学生权益](https://education.github.com/pack#cambercloud) 偏数据分析和 AI 实验。官方 Pack 列出每月 40 CPU 小时、5 GPU 小时、50 GB 存储、50 条 agent 消息。这不是固定型号 GPU 永久免费，具体规格和倍率看 [Camber 文档](https://docs.cambercloud.com/) 和控制台

### 4. GitHub 学生包里的 AI、域名与学习工具

- GitHub Copilot Student：已认证学生可申请，包含不限量代码补全，以及有限的聊天、agent 和 GitHub AI Credits；模型通过自动选择提供，不等于所有高级模型无限用
- Namecheap：一个 `.me` 域名首年注册和一年 SSL 证书，续费不是永久免费
- Name.com：指定域名后缀中的免费首年域名，包含 `.app`、`.dev` 等；名称、资格、续费价看领取和结算页
- Educative：70 多门指定实操课程的 6 个月访问，不是整个课程库永久解锁
- Boot.dev：完整互动会员 3 个月，适合集中学后端和 DevOps
- 1Password：个人会员 1 年，领取前看后续续费方式

### 5. 这些学生额度怎么组合做一个真实项目

不用为了“价值几百美元”把每一个限时权益同时激活。最稳的用法是先定一个能收尾的小项目（比如课程作业展示站、个人小 API 或工具），再按需领对应的一两项：

- **前端展示 / 博客**：照着 [[astro-mizuki-blog-from-zero|简洁博客教程]] 放到 Cloudflare Pages，再配一个 [[free-domain-and-web-community|免费域名]]
- **临时写代码环境**：电脑配置不够或多设备切换时开 GitHub Codespaces（2 核机器，用完随手停机）
- **轻量后端 / 数据库**：先用 MongoDB Atlas 免费层或 50 美元额度，后端选 Azure（不用信用卡）或 Heroku（每月 13 美元以内）
- **24 小时常驻自托管服务**：用 [[aliyun-student-300-voucher-guide|阿里云学生券]] 或 [[azure-students-100-credit-guide|Azure 学生额度]] 开机，再按 [[2c2g-server-service-index|小服务器服务清单]] 挑一个用途
