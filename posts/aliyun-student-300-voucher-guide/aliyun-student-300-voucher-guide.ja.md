> この記事にまとめているのは、2026年6月時点で実際に有効と確認できた方法です。Alibaba Cloudのバウチャー対象範囲は変動しますし、最終的に適用されるかどうかは決済画面がすべてなので、永久保存版の攻略法だとは思わないでください。これから申し込む場合は、まず決済画面で割引が適用されるか確認してから注文しましょう。

ご存じの通り、Alibaba Cloud（阿里雲）の「雲工開物」プログラムでは、学生認証を通過した中国の大学等の在学生に向けて、300元分の学生限定クーポンを配布しています。

公式ルールはかなりはっきりしていて、学生認証を保持している期間中、1人につき12ヶ月ごとに1枚受け取れます。同一ユーザーの関連アカウントでの重複受け取りはできません。各クーポンの有効期限は1年間で、期限切れになった未使用分は失効し、次のクーポンへ自動的に繰り越されることもありません。対象商品はAlibaba Cloud中国サイトの指定パブリッククラウド製品に限られ、特記がない限り製品割引や他のクーポンとの併用は不可。実際に割引できるかはすべて注文時の決済画面の表示が基準になります。

それに、このクーポンの適用範囲は動的に調整されるため、去年そのまま使えたスペックが今年も対象とは限りません。受け取る前に、これから1年間で自分が本当に動かしたいプロジェクトは何なのかを考えておくのがベストです。

入り口はこちら：[学生特典の受け取りリンク](https://university.aliyun.com/course/promotion25-activity?clubTaskBiz=subTask..12655012..10273..&userCode=gv5jbukv)

## 受け取り方

手順はとてもシンプルです：

1. 実名認証済みのAlibaba Cloud中国サイトアカウントを用意する
2. Alibaba Cloud「雲工開物」の大学生向けページを開く
3. 学信網（CHSI）または大学の教育用メールアドレスで学生認証を完了する
4. 学生特典エリアで300元の条件なしクーポンを受け取る

認証が通ると、クーポン一覧に表示されます。有効期限は受け取った日から1年間です。

まだAlibaba Cloudのアカウントを持っていないなら、ついでに作っておきましょう。今後サーバーを使わなくなったとしても、Alibaba Cloud Bailian（百煉）のLLM APIの支払いにもこのクーポンを充てられます。


# 何に使えるか

## 1つ目：中国本土リージョンの年額契約 ECS

掲示板などで一番よく見かける使い方は、中国本土リージョンの 2C2G（2コア2GB）ECS を1年間契約するパターンです。このクーポンは毎年1枚もらえるので、大学に通っている間はずっと使い続けられる計算になります。

参考スレッド：

[https://linux.do/t/topic/2258128](https://linux.do/t/topic/2258128?u=amiya_desi)

大まかな流れは以下の通りです：

1. ECS のカスタム購入ページに入る
2. 2C2G 前後の e インスタンスを選ぶ
3. リージョンは中国本土を選択し、すでに特別キャンペーン割引が付いているリージョンは避ける（学生クーポンは通常、キャンペーン割引と併用できないため）
4. トラフィック課金方式で CDT 従量課金を選ぶ
5. 決済画面でクーポンが適用されるか確認する

ECS カスタム購入ページ：

[https://ecs-buy.aliyun.com/ecs/#/custom/](https://ecs-buy.aliyun.com/ecs/#/custom/)

掲示板で動作検証済みの主要構成：

```text
实例规格：ecs.e-c1m1.large（2C2G）
付费模式：包年包月，一年
流量计费方式：CDT 按量计费
```

正しく選べていれば、決済画面の合計が300元以下になり、クーポンで全額相殺されて追加の出費はゼロになるはずです。

もし自分の画面でクーポンが使えないと表示されたら、別のリージョンを試してみてください。掲示板では「青島なら使えた」という人もいれば「華南なら使えた」という人もいて、時期によってルールが変わります。大事なのは「推測せず決済画面を見ること」です。

CDT を有効にすると、毎月約20GBの無料トラフィック枠が付きます。ブログやBot、小さなAPIを動かす分には十分すぎますが、大容量のダウンロードサイトや画像の直リンク倉庫、動画配信などには使わないでください。

購入後にまずやるべきことは、管理パネルを入れることではなく、料金アラートの設定です。CDT 従量課金ということは、無料枠を超えると課金が発生します。たとえ1元でも通知が来るようにしきい値を設定しておけば、攻撃を受けたり設定をミスしたりしてもすぐに気づけます。

## 2つ目：軽量アプリケーションサーバー（Simple Application Server）

ECS やセキュリティグループ、Elastic IP、CDT といった仕組みをいちいち調べるのが面倒なら、軽量アプリケーションサーバーのほうが「あらかじめパッケージ化された小さな VPS」という感覚で扱えます。

学生向け割引ページを下にスクロールするか、ページ内で「轻量应用服务器」と検索してみてください：

[https://university.aliyun.com/buycenter/](https://university.aliyun.com/buycenter/)

現在見えているルートはいくつかあります：

**A. そのまま0円で 2C2G 軽量サーバーを半年借りる**

掲示板では、2C2G・200Mbps帯域の軽量サーバーを半年分0円で購入できたという報告があります。メリットは帯域幅固定のためトラフィック量無制限で、CDT の超過を気にしなくていいこと。デメリットは期間が半年しかないことです。

**B. 雲小站の38元タイムセール ＋ クーポンで更新**

まず「雲小站」のタイムセールで、年額38元の軽量アプリケーションサーバーを勝ち取ります：

[https://www.aliyun.com/minisite/goods](https://www.aliyun.com/minisite/goods)

比較的買いやすいと言われています。手に入れたら、300元クーポンを使って半年分更新します。これで合計1年半、総費用は38円（38元）です。

このプランには注意点が2つあります：

- キャンペーン価格と学生クーポンは必ず併用できるとは限りません。実際の支払い画面の表示に従ってください
- 更新時にクーポンが使えなかった場合、38元で買えたのは1年半ではなく1年だけになります

**C. 無料トライアル ECS からの本契約移行**

私自身が選んだのはこのルートです。Alibaba Cloud には無料トライアルの入り口があります：

[https://free.aliyun.com](https://free.aliyun.com)

2C2G の ECS を3ヶ月間無料で試せます。トライアルの期限前または期限後に、300元クーポンを使って年額プランへ移行すれば、トータルで1年3ヶ月かそれ以上使える計算になります。

個人的には、初心者が練習するなら軽量アプリケーションサーバーのほうが好みです。高機能だからではなく、選択肢が少ないぶん、自分で設定をいじりすぎて迷子になる確率が低いからです。

## 3つ目：中国本土以外の軽量サーバー

中国本土以外のリージョンになると、もう少し運ゲー要素が強くなります。

掲示板のフィードバックを見る限り、本土以外の ECS は基本的にクーポンが使いづらいものの、一部の軽量アプリケーションサーバー・一部リージョン・一部スペックなら通ることがあります。例えば、2C2G 汎用型を6ヶ月、あるいは 2C0.5G を1年購入して合計336元になり、クーポン適用後に差額の36元だけ払ったという話や、月単位で更新している人もいます。

ここでは具体的なリージョン名を固定して書くのは控えておきます。

香港、シンガポール、日本、アメリカ、ドイツ、イギリス、東南アジアといった地域のクーポン適用ルールは、今日使えても明日には使えなくなる可能性があります。どうしても海外サーバーが欲しいなら、構成をカートに入れて決済画面を確かめてください。

単にブログを立てたいだけなら、Cloudflare Pages で十分足ります。

## 4つ目：Wuying（無影）クラウドPCと霊豆

Alibaba Cloud の学生割引ページには、現在 Wuying（無影）関連の入り口も並んでいます。

この方向性が向いているのは次の2タイプの人です：

- クラウドPCを体験してみたい、たまにソフトやゲームを動かしたい人
- 自分でグラボを買わずに、一時的に GPU 計算リソースを借りたい人

掲示板では、Wuying 霊豆や Wuying 霊構プラットフォームの活用法として、霊豆を使って RTX5880（VRAM 48GB）の GPU 環境を立ち上げる方法などがまとめられています：

[https://linux.do/t/topic/2219866/60](https://linux.do/t/topic/2219866/60)

この手の投稿はヒントとして見るくらいがちょうどいいです。実際に支払う前は、やはり Alibaba Cloud の決済画面に戻って霊豆やリージョン、利用時間をしっかり確認しましょう。

この遊び方のメリットは爽快なこと、デメリットはポイントを従量課金で燃やしていく感覚に近いことです。サービスを長期間常駐させたいだけなら普通のサーバーには敵いません。研究勢やモデル開発勢で、一時的に大容量 VRAM が必要なら覗いてみる価値があります。

## 5つ目：Bailian（百煉）と LLM API

すでにサーバーを持っている人や、クラウドサーバー自体に興味がない人なら、300元を LLM API のお試しに回すのもアリです。

学生割引ページには LLM サービス、AI アプリ開発、Alibaba Cloud Bailian（百煉）の入り口があります。雲小站でも Bailian や Token Plan、HappyHorse といったモデル関連のキャンペーンが見られます：

[https://www.aliyun.com/minisite/goods](https://www.aliyun.com/minisite/goods)

バウチャーで支払いたい場合は、Alibaba Cloud 公式直販で、公式コンソール内の従量課金モデルを優先して選びましょう。サードパーティの中継サービスやマーケットプレイス商品、特殊キャンペーンパックなどは対象外になる可能性があります。

試せるものの例：

- Qwen（通義千問）シリーズ
- DeepSeek 関連 API
- GLM / Kimi などプラットフォーム内で選択できる公式モデル
- HappyHorse のような動画生成モデル（決済画面で割引適用を確認できることが前提）

ポイントは、呼び出す際に「公式直販モデル」を選ぶことです。Bailian コンソール内には「サードパーティ（三方）」や「マーケット（市场）」と表記されたモデルもあり、それらは今回のクーポンで相殺できない場合があります。

300元で何回叩けるかは、選ぶモデルと入力トークン長次第です。Qwen Turbo のような安価なモデルなら、300元で相当な回数を呼び出せます。ハイエンドな大規模モデルだと一気に高くなるので、まずは安いモデルから試して、全体のパイプラインを通すところから始めるのがおすすめです。

「とにかく API を触ってみたいだけ」という人にとっては、使わないサーバーを1台抱えるよりずっと合っています。

## 6つ目：ACA LLM エンジニア認定資格をタダ取りする

Alibaba Cloud にはもう一つ裏ワザ的な使い道があり、300元クーポンをそのまま ACA 大模型エンジニア認定試験の受験料に充てられます。

定価600元の認定資格が、学生割引価格でちょうど300元になり、クーポン適用で実質0円です。

参考スレッド：

[https://linux.do/t/topic/2456810](https://linux.do/t/topic/2456810)

大まかな流れ：

1. 学生認証を完了し、300元クーポンを受け取る
2. 学生割引ページを下にスクロールし、「大模型认证（LLM認定）」欄を見つける
3. 「立即购买（今すぐ購入）」をクリックし、クーポンで全額相殺する

これは Alibaba Cloud 公式の職種別認定資格で、初心者向けの内容です。市場価値がものすごく高いわけではありませんが、学生の立場なら0円で資格証を1枚手に入れつつ、LLM の基礎知識を一通りおさらいできるので損はありません。

**向いている人：**

- 履歴書の資格欄を少し埋めたい人
- LLM の基礎概念を体系的に学びたい人
- すでにサーバーを持っている、またはサーバーに興味がない人

**向いていない人：**

- すでに LLM エンジニアリングの実務をしていて、初級認定の内容では物足りない人
- このクーポンをサーバーや Bailian API に取っておきたい人

クーポンの有効期限が迫っていて、当面サーバーも API も使う予定がないなら、この認定資格に交換しておくのも悪くありません。

## 私ならどう選ぶか

初めてクラウドを触るなら、私ならこの順番で考えます：

1. まずクーポンを受け取る
2. ECS か軽量アプリケーションサーバーで、クーポンが使える 2C2G があるか探す
3. 0円または少額の差額でサーバーを取れるなら、まずサーバーを確保する
4. サーバーが手に入ったら、すぐに SSH 設定・セキュリティグループ・料金アラートを済ませる
5. その上で Vaultwarden、ntfy、Gatus、Bot、ノート同期といった小さなサービスを動かす

すでに VPS を持っているなら、クーポンを消化するためだけにホコリをかぶるマシンをもう1台増やすのはやめましょう。Bailian API や Wuying 霊豆に回したほうが、よっぽどお金を有効活用している実感があります。

## 注文前チェックリスト

焦って決済ボタンを押す前に、次の項目を確認してください：

- 決済画面に300元クーポンの割引が表示されているか
- 契約形態がサブスクリプション（年額/月額）か、従量課金か
- 期限切れ後に自動更新がオンになっていないか
- トラフィック、帯域幅、パブリック IP の課金体系はどうなっているか
- セキュリティグループがデフォルトで全開放になるリスクはないか
- 料金アラートや利用上限アラームを設定できるか
- 返金した場合、クーポンを同じカテゴリで再利用できるか

特に最後の一点は重要です。公式ルールには、バウチャーを使用した注文を返金した場合、返還されたバウチャーは該当カテゴリの商品に再利用できないと明記されています。軽い気持ちでテスト注文して返金するのは絶対にやめましょう。
