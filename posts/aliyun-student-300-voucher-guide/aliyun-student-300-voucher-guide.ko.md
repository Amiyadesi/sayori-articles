> 이 글은 2026년 6월 직접 테스트해 유효했던 방법을 정리한 것입니다. 알리바바 클라우드 바우처의 적용 범위는 수시로 바뀌며 최종 판단은 결제 페이지 기준이므로, 이 글을 영구 공략집처럼 생각하지 마세요. 앞으로 결제할 때는 먼저 결제 페이지에서 차감 적용이 되는지 확인한 뒤 주문하시기 바랍니다.

다들 아시다시피 알리바바 클라우드 '윈궁카이우(云工开物)' 프로그램에서는 학생 인증을 통과한 중국 대학 재학생에게 300위안 상당의 학생 전용 바우처를 지급합니다.

공식 규칙은 아주 명확합니다. 학생 인증을 유지하는 기간 동안 1인당 12개월마다 1장을 받을 수 있으며, 동일 사용자의 연관 계정으로는 중복 수령할 수 없습니다. 바우처 유효기간은 1년이고 만료 시 미사용 금액은 소멸하며 다음 바우처로 자동 이월되지 않습니다. 구매 범위는 알리바바 클라우드 중국 사이트의 지정된 퍼블릭 클라우드 상품으로 제한되며, 별도 안내가 없는 한 상품 할인이나 다른 쿠폰과 중복 적용되지 않습니다. 구체적인 차감 가능 여부는 전적으로 주문 결제 페이지 표시를 기준으로 합니다.

게다가 이 바우처의 적용 범위는 유동적으로 조정되기 때문에, 작년에 바로 차감되던 스펙이 올해는 안 될 수도 있습니다. 바우처를 받기 전에 앞으로 1년 동안 진짜로 돌릴 프로젝트가 무엇인지 미리 생각해 두는 편이 좋습니다.

신청 입구는 여기입니다: [학생 혜택 수령 링크](https://university.aliyun.com/course/promotion25-activity?clubTaskBiz=subTask..12655012..10273..&userCode=gv5jbukv)

## 어떻게 받나요

절차는 아주 간단합니다.

1. 실명 인증이 완료된 알리바바 클라우드 중국 사이트 계정 준비
2. 알리바바 클라우드 윈궁카이우 대학생 페이지 접속
3. 학신망(CHSI) 또는 대학 교육용 이메일을 통해 학생 인증 완료
4. 학생 혜택 구역에서 300위안 무제한(최소 결제 금액 조건 없음) 쿠폰 수령

인증이 통과되면 쿠폰 목록에 바우처가 들어옵니다. 유효기간은 수령한 날로부터 1년입니다.

아직 알리바바 클라우드 계정이 없다면 일단 하나 만들어 두세요. 나중에 서버를 쓰든 안 쓰든 알리바바 클라우드 Bailian(百炼)의 거대 모델 API 결제에도 이 바우처를 쓸 수 있습니다.


# 어디에 쓸 수 있나요

## 첫 번째: 중국 본토 리전 1년 약정 ECS

포럼에서 가장 흔히 쓰는 방법은 중국 본토 리전의 2C2G ECS를 1년 치 개설하는 것입니다. 이 바우처는 매년 한 장씩 받을 수 있으니 대학에 다니는 동안은 사실상 계속 공짜로 쓸 수 있는 셈입니다.

참고 게시글:

[https://linux.do/t/topic/2258128](https://linux.do/t/topic/2258128?u=amiya_desi)

대략적인 흐름은 다음과 같습니다.

1. ECS 커스텀 구매 페이지 진입
2. 2C2G 전후의 e 인스턴스 선택
3. 리전은 중국 본토로 선택하되, 이미 특별 프로모션 할인이 붙은 리전은 피하기(학생 바우처는 보통 프로모션 할인과 중복 불가)
4. 트래픽 과금 방식은 CDT 종량제 선택
5. 결제 페이지에서 바우처 차감 여부 확인

ECS 커스텀 구매 페이지:

[https://ecs-buy.aliyun.com/ecs/#/custom/](https://ecs-buy.aliyun.com/ecs/#/custom/)

포럼에서 사용 가능함이 검증된 핵심 설정:

```text
实例规格：ecs.e-c1m1.large（2C2G）
付费模式：包年包月，一年
流量计费方式：CDT 按量计费
```

제대로 선택했다면 결제 페이지 금액이 300위안 이하로 뜨면서 바우처로 바로 차감되어 추가 비용이 들지 않을 겁니다.

만약 본인 계정에서 바우처 적용이 안 된다고 뜨면 리전을 바꿔보세요. 포럼을 보면 누군가는 칭다오가 되고 누군가는 화남이 되는 등 시기마다 규칙이 다릅니다. 핵심은 추측하지 말고 결제 페이지를 직접 확인하는 것입니다.

CDT를 개통하면 매달 약 20GB의 무료 트래픽이 제공됩니다. 블로그나 봇, 작은 API를 띄우기엔 차고 넘치지만, 대용량 다운로드 사이트나 이미지 호스팅 핫링크, 동영상 스트리밍 용도로는 쓰지 마세요.

구매 후 가장 먼저 할 일은 패널 설치가 아니라 비용 알림 설정입니다. CDT 종량제는 무료 할당량을 초과하면 요금이 부과된다는 뜻입니다. 단돈 1위안이라도 초과하면 알림이 오도록 임계값을 설정해 두어야 공격을 받거나 설정을 잘못했을 때 바로 알아차릴 수 있습니다.

## 두 번째: 경량 애플리케이션 서버(Simple Application Server)

ECS, 보안 그룹, 탄력적 공용 IP, CDT 같은 개념을 일일이 공부하기 귀찮다면 경량 애플리케이션 서버가 '이미 패키징이 끝난 미니 VPS'에 더 가깝습니다.

학생 혜택 페이지에서 아래로 스크롤하거나 페이지 내에서 '轻量应用服务器(경량 애플리케이션 서버)'를 검색하세요:

[https://university.aliyun.com/buycenter/](https://university.aliyun.com/buycenter/)

현재 확인된 몇 가지 루트는 다음과 같습니다.

**A. 바로 0원으로 2C2G 경량 서버 반년 개설**

포럼에서 2C2G, 200M 대역폭 경량 서버 반년 치를 0원에 구매할 수 있다는 인증이 올라왔습니다. 대역폭 고정 방식이라 트래픽 제한이 없어 CDT 초과 요금을 걱정할 필요가 없다는 게 장점이고, 단점은 기간이 반년뿐이라는 점입니다.

**B. 윈샤오잔(云小站) 38위안 타임세일 + 바우처로 연장**

먼저 윈샤오잔에서 정해진 시간에 풀리는 1년 38위안짜리 경량 애플리케이션 서버를 잡습니다:

[https://www.aliyun.com/minisite/goods](https://www.aliyun.com/minisite/goods)

비교적 잡기 쉬운 편이라고 합니다. 구매에 성공한 뒤 300위안 바우처로 반년을 연장하면 총 1년 반을 38위안에 쓰는 셈이 됩니다.

이 방법은 두 가지를 주의해야 합니다.

- 프로모션 가격과 학생 바우처가 반드시 중복 적용되는 것은 아니므로 결제 시 실제 표시 금액을 기준으로 삼아야 합니다.
- 연장할 때 바우처 차감이 안 되면 38위안으로 1년 반이 아니라 딱 1년만 산 셈이 됩니다.

**C. 무료 체험 ECS 정식 전환**

제가 직접 선택한 루트입니다. 알리바바 클라우드에는 무료 체험 입구가 있습니다:

[https://free.aliyun.com](https://free.aliyun.com)

2C2G ECS를 3개월간 무료로 체험할 수 있습니다. 체험 만료 전이나 만료 후에 300위안 바우처를 써서 1년 약정으로 전환하면 대략 1년 3개월 이상 사용할 수 있습니다.

개인적으로는 입문자 연습용으로 경량 서버를 더 선호합니다. 더 고급스러워서라기보다 옵션이 적어서 스스로 헷갈려 멘붕에 빠질 여지가 적기 때문입니다.

## 세 번째: 중국 본토 외 리전 경량 서버

중국 본토 외 지역은 조금 더 복불복에 가깝습니다.

포럼 후기를 보면 비본토 ECS는 기본적으로 바우처 쓰기가 어렵지만, 일부 경량 애플리케이션 서버의 특정 리전, 특정 스펙은 가능한 경우가 있습니다. 예를 들어 2C2G 범용형 6개월이나 2C0.5G 1년짜리 총액 336위안 상품을 바우처 적용 후 36위안만 추가 결제했다는 사례도 있고, 월 단위로 연장하는 사람도 있습니다.

여기서 특정 리전을 못 박아 추천하지는 않겠습니다.

홍콩, 싱가포르, 일본, 미국, 독일, 영국, 동남아 같은 지역의 바우처 규칙은 오늘 되다가 내일 안 될 수도 있습니다. 해외 서버가 정말 필요하다면 원하는 스펙을 장바구니에 넣고 결제 페이지를 직접 확인해 보세요.

단순히 블로그만 띄울 목적이라면 Cloudflare Pages만으로도 이미 충분합니다.

## 네 번째: Wuying(无影) 클라우드 컴퓨터와 링더우(灵豆)

알리바바 클라우드 학생 혜택 페이지에서 요즘 Wuying 관련 메뉴도 보입니다.

이쪽은 두 부류의 사람에게 적합합니다.

- 클라우드 컴퓨터를 체험해 보면서 가끔 프로그램이나 게임을 돌려보고 싶은 사람
- 그래픽카드를 직접 사지 않고 임시로 GPU 연산 자원을 빌려 쓰고 싶은 사람

포럼에는 Wuying 링더우와 Wuying 링거우(无影灵构) 플랫폼 활용법을 정리한 글이 있는데, 예를 들어 링더우로 RTX5880 48GB VRAM GPU 환경을 띄우는 식입니다:

[https://linux.do/t/topic/2219866/60](https://linux.do/t/topic/2219866/60)

이런 게시글은 단서 정도로만 참고하는 것이 좋습니다. 실제 결제 전에는 반드시 알리바바 클라우드 결제 페이지로 돌아가 링더우 수량, 리전, 사용 시간을 확인해야 합니다.

이 방식의 장점은 쾌적하다는 것이고, 단점은 종량제로 포인트를 태우는 구조에 가깝다는 점입니다. 서비스를 장기간 상시 구동하고 싶다면 일반 서버보다 못하지만, 연구용이나 모델 학습용으로 임시 VRAM이 필요한 사람이라면 한 번쯤 살펴볼 가치가 있습니다.

## 다섯 번째: Bailian(百炼)과 거대 모델 API

이미 서버가 있거나 클라우드 서버에 관심이 없다면 300위안으로 거대 모델 API를 써보는 것도 방법입니다.

학생 혜택 페이지에는 거대 모델 서비스, AI 애플리케이션 개발, 알리바바 클라우드 Bailian 입구가 있습니다. 윈샤오잔에서도 Bailian, Token Plan, HappyHorse 같은 모델 관련 프로모션을 볼 수 있습니다:

[https://www.aliyun.com/minisite/goods](https://www.aliyun.com/minisite/goods)

바우처로 차감받으려면 알리바바 클라우드 공식 직공급 모델이자 공식 콘솔에서 종량제로 과금되는 모델을 우선 선택해야 합니다. 서드파티 중계, 마켓플레이스 상품, 특수 이벤트 패키지는 이 바우처가 적용되지 않을 수 있습니다.

테스트해 볼 수 있는 모델들:

- 통이천원(Qwen) 시리즈
- DeepSeek 관련 API
- GLM / Kimi 등 플랫폼 내에서 선택 가능한 공식 모델
- HappyHorse 같은 비디오 모델(단, 결제 페이지에서 차감 가능 여부 확인 필수)

핵심은 호출할 때 '공식 직공급 모델'을 고르는 것입니다. Bailian 콘솔 내 일부 모델에는 '서드파티(三方)' 또는 '마켓(市场)' 표시가 붙어 있는데, 그런 모델은 이 바우처로 차감되지 않을 수 있습니다.

300위안으로 몇 번이나 호출할 수 있을까요? 선택한 모델과 입력 길이에 달려 있습니다. Qwen Turbo처럼 저렴한 모델은 300위안으로 어마어마하게 많이 호출할 수 있지만, 하이엔드 거대 모델은 훨씬 비쌉니다. 일단 저렴한 모델부터 테스트해서 전체 파이프라인을 돌려본 뒤에 결정하세요.

'나는 그냥 API 테스트만 해보고 싶다'는 사람에게는 놀릴 서버를 한 대 사는 것보다 이쪽이 훨씬 잘 맞습니다.

## 여섯 번째: ACA 거대 모델 엔지니어 자격증 공짜로 따기

알리바바 클라우드에는 300위안 바우처로 ACA 거대 모델 엔지니어 자격증 응시료를 바로 차감하는 꼼수도 있습니다.

정가 600위안짜리 자격증이 학생 할인가로 딱 300위안이라 바우처를 쓰면 0원이 됩니다.

참고 게시글:

[https://linux.do/t/topic/2456810](https://linux.do/t/topic/2456810)

대략적인 절차:

1. 학생 인증을 완료하고 300위안 바우처 수령
2. 학생 혜택 페이지에서 아래로 내려 '거대 모델 인증(大模型认证)' 항목 찾기
3. '지금 구매(立即购买)'를 누르고 바우처로 차감 결제

이 자격증은 입문자를 대상으로 한 알리바바 클라우드 공식 직무 역량 인증입니다. 스펙으로서의 무게감이 엄청나진 않지만, 학생 입장에서는 0원으로 자격증 하나 챙기면서 거대 모델 기초 지식도 한 번 훑을 수 있으니 손해 볼 건 없습니다.

**추천 대상:**

- 이력서 자격증 칸을 채워야 하는 사람
- 거대 모델 기초 개념을 체계적으로 배우고 싶은 사람
- 이미 서버가 있거나 서버에 관심이 없는 사람

**비추천 대상:**

- 이미 LLM 엔지니어링 개발을 하고 있어 초급 인증 내용이 너무 기초적으로 느껴지는 사람
- 이 바우처를 서버나 Bailian API에 아껴 쓰고 싶은 사람

바우처 만료일은 다가오는데 당장 서버나 API를 쓸 일이 없다면 이 자격증으로 바꾸는 것도 나쁘지 않은 선택입니다.

## 저라면 어떻게 고를까요

클라우드를 처음 다뤄본다면 저는 이 순서대로 갈 겁니다.

1. 일단 바우처부터 받기
2. ECS나 경량 서버 중에 바우처가 먹히는 2C2G가 있는지 확인
3. 0원이나 소액 추가 결제로 서버를 구할 수 있다면 서버부터 확보
4. 서버를 받자마자 SSH, 보안 그룹, 비용 알림부터 설정
5. 그다음 Vaultwarden, ntfy, Gatus, 봇, 노트 동기화 같은 작은 서비스 구동

이미 VPS를 가지고 있다면 굳이 바우처 털겠다고 먼지만 쌓일 서버를 한 대 더 사지 마세요. 차라리 Bailian API나 Wuying 링더우에 쓰는 게 진짜 돈을 쓰는 기분이 날 겁니다.

## 주문 전 체크리스트

성급하게 결제하지 말고 다음 항목들을 먼저 확인하세요.

- 결제 페이지에 300위안 바우처 차감이 표시되는가
- 주문 방식이 기간 약정(包年包月)인가, 아니면 종량제(按量付费)인가
- 만료 후 자동 갱신이 켜져 있는가
- 트래픽, 대역폭, 공용 IP 요금은 어떻게 계산되는가
- 보안 그룹 기본 허용으로 인한 보안 위험은 없는가
- 비용 알림 및 한도 경보를 설정할 수 있는가
- 환불 후 바우처를 동일 카테고리에 다시 사용할 수 있는가

특히 마지막 항목이 중요합니다. 공식 규정에 따르면 바우처를 사용한 주문을 환불할 경우, 반환된 바우처는 해당 상품군에 재사용할 수 없습니다. 괜히 테스트 삼아 결제했다가 취소하는 짓은 하지 마세요.
