> [!NOTE]
> 這篇整理的是 2026 年 6 月實測有效的方法。阿里雲券的可用範圍會變，而且是結算頁說了算，所以不要把這篇當永久攻略。往後看的話，先去結算頁確認能抵扣再下單。

衆所周知，阿里雲每年都會給大學生髮 300 元代金券

聽起來很大方。實際點進控制台就會發現，這張券不是 300 元現金，也不是全站隨便買。官方頁面寫得很清楚：通過學生認證的高校學生可以領 300 元無門檻優惠券，有效期 1 年；購買範圍是阿里雲部分公共雲產品，具體以下單購買時抵扣情況爲準

而且這個券的可用範圍還在不斷收縮。去年能用的東西今年可能就不行了。所以我會建議你領完以後不要放着不管，儘早想好怎麼花

入口在這裏[學生權益領取鏈接](https://university.aliyun.com/course/promotion25-activity?clubTaskBiz=subTask..12655012..10273..&userCode=gv5jbukv)

## 怎麼領

流程很短：

1. 有阿里雲賬號（支付寶註冊或手機註冊都行）
2. 打開學生優惠頁面
3. 完成學生認證（一般是學信網驗證或高校郵箱）
4. 找到「我是學生」入口，領取 300 元抵扣券

認證通過後，券會出現在你的優惠券列表裏。有效期一年，從領取那天開始算

如果你還沒有阿里雲賬號，就順手註冊一個，以後不管用不用服務器，阿里雲百鍊的大模型 API 也可以拿券抵扣


# 能用來幹啥

## 第一種：包年大陸地區 ECS

論壇裏最常見的用法是開一臺中國大陸地區的 2C2G ECS，能開一年，加上這個券每年能領一個，你讀多久大學基本上就能用多久

參考貼：

[https://linux.do/t/topic/2258128](https://linux.do/t/topic/2258128?u=amiya_desi)

大致思路是：

1. 進入 ECS 自定義購買頁
2. 選 2C2G 左右的 e 實例
3. 地域選中國大陸（避開那些標註了「優惠」的地區，反而可能用不了券）
4. 流量計費方式選 CDT 按量
5. 結算頁確認券能抵扣

ECS 自定義購買頁：

[https://ecs-buy.aliyun.com/ecs/#/custom/](https://ecs-buy.aliyun.com/ecs/#/custom/)

論壇裏驗證過能用的關鍵配置：

```text
实例规格：ecs.e-c1m1.large（2C2G）
付费模式：包年包月，一年
流量计费方式：CDT 按量计费
```

選對的話，結算頁應該顯示 300 元以下，券直接抵扣，不用額外掏錢

如果你那邊顯示用不了券，換個地域試試。論壇裏有人青島能用，有人華南能用，不同時期規則不一樣。重點是：看支付頁，不要猜

開通 CDT 後，每月有 20GB 左右的免費流量。掛博客、機器人、小 API 完全夠用，但別拿它做大流量下載站、圖牀外鏈、視頻分發

買完第一件事不是裝面板，是去設置費用預警。CDT 按量的意思是超出免費額度後會產生費用。設一個閾值報警，哪怕 1 塊錢也報，這樣被攻擊或者配置錯誤時能及時發現

## 第二種：輕量應用服務器

如果你不想研究 ECS、安全組、彈性公網 IP、CDT 這些東西，輕量應用服務器更像「已經打包好的小 VPS」

學生優惠頁面往下翻，或者直接在頁面裏搜「輕量應用服務器」：

[https://university.aliyun.com/buycenter/](https://university.aliyun.com/buycenter/)

目前看到的幾條路線：

**A. 直接 0 元開半年 2C2G 輕量**

論壇裏有人確認可以 0 元購輕量 2C2G 200M 帶寬半年。優點是不限流量（帶寬固定），不用擔心 CDT 超額。缺點是隻有半年

**B. 雲小站 38 元搶購 + 券續費**

先在雲小站定時搶購 38 元一年的輕量應用服務器：

[https://www.aliyun.com/minisite/goods](https://www.aliyun.com/minisite/goods)

據說比較好搶。搶到後用 300 元券續費半年。這樣加起來一年半，總花費 38 元。

這個方案要小心兩點：

- 活動價和學生券不一定能疊加。以你付款時的實際顯示爲準
- 續費時如果券不能抵扣，那 38 元就只買了一年，不是一年半

**C. 試用 ECS 轉正**

這是我自己走的路線。阿里雲有一個免費試用入口：

[https://free.aliyun.com](https://free.aliyun.com)

可以試用 2C2G 的 ECS 三個月。試用到期前或到期後，用 300 元券轉包年，這樣算下來大概能用一年三個月到更久

我個人更喜歡輕量給新手練手。不是因爲它更高級，而是因爲它少一點選項，少一點把自己繞暈的機會

## 第三種：非大陸輕量

非中國大陸地區就更玄學一點

論壇裏的反饋是，非大陸 ECS 基本不好用券，但部分輕量應用服務器、部分地域、部分配置可能可以。比如有人提過 2C2G 通用型買 6 個月，或者 2C0.5G 買一年，總價 336 元，用券後還要補 36 元；也有人選擇按月續

這裏我不建議把具體地域寫死

香港、新加坡、日本、美國、德國、英國、東南亞，這些地區的券規則可能今天能用，明天就不能。你真要海外機器，就把配置放進購物車，看支付頁

如果你只是爲了搭博客，Cloudflare Pages 已經夠用了

## 第四種：無影雲電腦和靈豆

阿里雲學生優惠頁裏現在也能看到無影相關入口。

這個方向適合兩類人：

- 想體驗雲電腦，偶爾跑跑軟件或者遊戲
- 想臨時租 GPU 算力，不想自己買顯卡

論壇裏有人整理過無影靈豆和無影靈構平臺的玩法，比如用靈豆開 RTX5880 48GB 顯存的 GPU 環境：

[https://linux.do/t/topic/2219866/60](https://linux.do/t/topic/2219866/60)

這類帖子更適合當線索看。真正付款前，還是要回到阿里雲結算頁確認靈豆、地域和時長

這類玩法的好處是爽，壞處是它更像按量燒點數。你如果只是想長期掛一個服務，它不如服務器。你如果是科研黨、模型黨、臨時要顯存，那就值得看看

## 第五種：百鍊和大模型 API

如果你已經有服務器，或者對雲服務器沒興趣，300 元拿去試大模型 API 也可以

學生優惠頁裏有大模型服務、AI 應用開發、阿里雲百鍊的入口。雲小站也能看到百鍊、Token Plan、HappyHorse 等模型相關活動：

[https://www.aliyun.com/minisite/goods](https://www.aliyun.com/minisite/goods)

如果你想讓代金券抵扣，優先選阿里雲官方直供、官方控制台裏按量計費的模型。第三方中轉、市場商品、特殊活動包，可能就不走這張券

可以拿來試：

- 通義千問系列（Qwen）
- DeepSeek 相關 API
- GLM / Kimi 等平臺裏能選到的官方模型
- HappyHorse 這類視頻模型，前提是確認結算頁能抵扣

關鍵是調用時選「官方直供模型」。百鍊控制台裏有些模型標註了「三方」或「市場」，那些不一定能用這張券抵扣

300 元能調多少次？這取決於你選的模型和輸入長度。通義千問 Turbo 這類便宜的，300 元可以調非常多次。如果是高端大模型，就會貴很多。先從便宜模型試起，把流程跑通再說

這比買一臺閒置服務器更適合「我就是想拿來試 API」的人

## 第六種：白嫖 ACA 大模型工程師認證

阿里雲還有一個騷操作：用 300 元券直接抵扣 ACA 大模型工程師認證費用。

原價 600 元的認證，學生優惠價剛好 300 元，用券後 0 元

參考帖：

[https://linux.do/t/topic/2456810](https://linux.do/t/topic/2456810)

大致流程：

1. 完成學生認證，領取 300 元券
2. 在學生優惠頁往下滑，找到「大模型認證」欄目
3. 點擊「立即購買」，用券抵扣

這個認證是阿里雲官方的職業崗位認證，面向初學者。雖然含金量不高，但對學生來說，0 元拿一張證書、順便學一遍大模型基礎知識，不虧

**適合誰：**

- 簡歷需要補充認證欄
- 想系統學習大模型基礎概念
- 已經有服務器或者對服務器沒興趣

**不適合誰：**

- 已經在做大模型開發的人（太基礎）
- 更想拿券換服務器的人（機會成本）

如果你的券快過期了，又暫時用不到服務器和 API，拿來換這個認證也不錯

## 我會怎麼選

如果是第一次玩雲，我會這樣排：

1. 先領券
2. 看 ECS 或輕量有沒有 2C2G 能用券
3. 能 0 元或少量補差價拿服務器，就先拿服務器
4. 服務器到手後立刻做 SSH、安全組、費用預警
5. 再跑 Vaultwarden、ntfy、Gatus、機器人、筆記同步之類的小服務

如果你已經有 VPS，那就別爲了花券再買一臺喫灰機器。拿去試百鍊 API 或無影靈豆，反而更像在用錢

## 下單前檢查

別急着付款，先看這幾個：

- 支付頁有沒有出現 300 元券抵扣
- 訂單是不是包年包月，還是按量付費
- 到期後會不會自動續費
- 流量、帶寬、公網 IP 怎麼算錢
- 是否有安全組默認放行風險
- 是否能設置費用預警和額度報警
- 退款後券還能不能重新用於同品類

尤其是最後一條。官方規則裏提到，使用代金券的訂單退款後，退回的代金券對應品類不可二次使用。不要拿它亂試單
