# To Start
Since I've got some time on my hands, I thought I'd collect some of the feedback I've received so far...

[Chrono Link - Game Reviews - TapTap](https://www.taptap.cn/app/834133/review?os=pc), I really didn't expect this. I only uploaded it after feeling pretty disheartened, but I actually got some real feedback. It seems like putting things out there is necessary after all, to make better games!

[Mio’s Window Wanderer by Amiya_desi, LaoZhaoofGod, kazeyoxing, owo23333 for thatgamejam #01 🩵 - itch.io](https://itch.io/jam/thatgamejam01/rate/4134738), this one's a similar story, haha. I thought of a gameplay mechanic that seemed really interesting and even managed to build a bit of it, but in the end, the game just wasn't fun, sigh... I'm suddenly realizing I might be pretty good at making these kinds of games, huh?

[Vision Window](https://www.gcores.com/games/179905), yep, it's true. Ever since TGJ, pretty much every game I've come up with has been like this (((φ(◎ロ◎;)φ))). I'm way too into novel ideas, but I just don't have the skill to polish them properly... And I've noticed a common theme: they all use a lot of AI... wait, isn't that just a given? haha
