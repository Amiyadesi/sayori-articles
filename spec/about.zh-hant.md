# About

這裡是 Amiya_desi 的個人博客。

關於我: 目前19歲大學生，夢想是成為獨立遊戲開發Master，最喜歡的遊戲類別是 meta 獨立遊戲，也想親手做出一個有“屏幕外一層意義”的 meta 獨立遊戲。

平時還喜歡折騰東西，比如說這個博客，今後會在這裡分享一些遊戲開發、學習、工具和日常思考等內容，我期待數據能擬合出我，幫我解決那些我一個人想不明白的東西，所以我要把這些都記錄下來

覺得博客就是用來承載文章的，於是在做出思想鬥爭後果斷換成簡潔體，確保閱讀體驗，改變的心路歷程也就在[[blog-style-change|這裡]]

目前能公開放出來的作品和項目主要在 GitHub：

- [WakeUpAtTheBorder](https://github.com/Amiyadesi/Wake-up-at-the-border)：Godot 2D 橫版敘事遊戲，GodotHub 第三屆開發大賽二等獎
- [TimeRuner](https://github.com/Amiyadesi/time-runner)：C# 動作平臺跳躍，5 秒時間回溯，034GameJam 最佳時間題材遊戲獎
- [EnhanceSaveSystem](https://github.com/Amiyadesi/enahnce_save_system)：Godot 存檔插件，支持 AES-GCM、gzip、原子寫入和版本遷移
- [Mio's Windowanderer](https://github.com/Amiyadesi/ThatGameJam) / [少女們的假面舞會](https://github.com/Amiyadesi/ggj)：GameJam 裡做過的多窗口解謎和文字解謎嘗試
