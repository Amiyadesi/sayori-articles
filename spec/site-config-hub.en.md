# Blog Site Config Hub

From now on, if you need to change blog site info, start here:

- [spec/about.md](about.md): About page content
- [spec/friends.md](friends.md): Friends page content and application instructions
- [site/profile.json](../site/profile.json): Avatar, nickname, bio, social links
- [site/navigation.json](../site/navigation.json): Navigation bar
- [site/banner.json](../site/banner.json): Homepage Banner and copy
- [site/announcement.json](../site/announcement.json): Announcement bar
- [site/music.json](../site/music.json): Music player configuration
- [friends/](../friends/): Friend link cards
- [assets/](../assets/): Assets like avatars, Banners, music, friend link avatars, etc.

To write posts, still go to:

- [posts/](../posts/)

To preview the blog, click the plugin button on the left: `Start Blog Preview`. Click it again to `Stop Blog Preview`.
